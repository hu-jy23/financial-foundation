# 华尔街见闻本地材料库：调查与采集方案

2026-11-04。范围为现有清单的206篇公开文章，保存正文、正文图表及来源信息，提供离线阅读和检索。

## 抽样结果

抽取8篇：AI CDS（3784900，9图）、美债基差交易（3744871，5图）、Circle（3750108，4图）、大漂亮法案（3748815，11图）、中金黄金（3764710，33图）、中金市场见底（3784961，32图）、CoreWeave（3783944，2图）、电力长约（3763449，2图）。实际查看AI CDS、Circle、基差交易、中金黄金的图像，并单独核看回归表和历史比较表。

- 正文是HTML片段，包含标题、段落、加粗、引用、列表和链接。图表按论述顺序穿插在段落之间。
- 样本没有HTML `table`；回归表、比较表也是图片。图题、来源、注释可能在图片内，也可能在图片前后的独立段落中。仅提取文字会丢掉这些证据。
- AI CDS的9图包括信用利差、基差、成交量、未平仓量和曲线比较；保存时应保留每张图的位置及邻近文字。
- 部分微信公众号转载文章直接使用`img`；另一些内容接口会把图片替换成`<!--image#0-->`，地址放在`content_args`。`images`字段主要是封面信息，不能用来枚举正文图表。
- 实测文章网页直接请求返回403；同站公开内容接口可匿名返回文章。`extract=0`返回带正文`img`的内容，`extract=1`可能需要根据`content_args`恢复占位符。样本均标为无需付费，取得正文不需要token或登录。
- 接口中另有平台配音MP3，它与文章正文分开。本次保存文字和正文插图；不收平台配音、作者头像、封面、广告和评论。若正文自身含音视频、动态组件等，单列处理，不能漏掉后仍算图文完整。

样本原文：[AI CDS](https://wallstreetcn.com/articles/3784900)、[基差交易](https://wallstreetcn.com/articles/3744871)、[Circle](https://wallstreetcn.com/articles/3750108)、[中金黄金](https://wallstreetcn.com/articles/3764710)。

## 保存形式

采用每篇一个文件夹，HTML用于浏览器阅读，Markdown用于agent阅读和检索，两者共用本地图片。使用文章标题作为目录名，ID保留在元数据和检索库中。标题需要改名时，同步更新本地引用与索引。

| 形式 | 判断 |
| --- | --- |
| Markdown＋图片 | 本次采用。保存标题、引用、列表及本地图片链接；转换后独立解析，逐篇核对文字、层级与图文位置。本批表格均为图片，保持原图。 |
| HTML＋图片 | 本次采用。浏览器直接打开，保留段落、表格和图文顺序；图片可独立核读，后续web app可直接复用。 |
| 单文件HTML／MHTML | 方便单篇传递，但内嵌图片会增大文本，MHTML对解析工具和浏览器的兼容性有限。需要传递时可打包文章文件夹。 |
| PDF | 便于打印，分页可能切断图表，搜索和结构提取不便；暂不批量生成。 |
| EPUB | 适合长篇连续阅读，单篇更新和程序定位较绕；暂不采用。 |

```text
materials/wallstreetcn/
  README.md                    使用说明
  CATALOG.md / index.html       目录和浏览器入口
  SourcePost/<文章标题>/
    article.html / article.md   浏览器阅读与agent阅读
    raw.json / metadata.json    正文原件、来源与资源记录
    assets/                    正文图表
  维护/
    library.py                 采集、建索引、验证、检索
    selection.json / 选文清单.md  选文信息
    screening_audit.json        选文审计
    manifest.json              保存状态与路径
    library.sqlite             全文检索库
    validation.json            文件及浏览器检查
    PROPOSAL.md                本方案
```

原始响应是取得版本；HTML、Markdown、SQLite均为派生产物。图片序号按出现顺序添加，本库序号与图内原有编号分别保留。图片中的表格仍保存为图片，不擅自OCR成数据。中文正文保持中文。

## 采集与验收

1. 先在8篇样本上生成离线阅读版，用浏览器检查正文、图表和表格显示，再扩展到206篇。复用本次抽样取得的原件。
2. 逐篇记录公开访问标记、原文URL、接口URL、抓取时间、页面显示日期、署名和页面标注来源；保留原索引中的优先级和阅读价值。来源机构与编辑署名分开。
3. 保存`extract=0`原响应并枚举正文资源；遇占位符按接口映射恢复。下载全部正文图片，保留图题、来源、注释及原位置，消除阅读版对远程图片与样式的依赖。正文中的其他文章链接保留原地址，库内文章加本地阅读入口。
4. 四路并发、有限重试、支持续传。已有成功原件不重复请求；失败项明确记录，后续可按ID重试。访问变更或仅返回摘要的文章不能记作取得全文。
5. 将图片数量与旧清单对照；核查未恢复占位符、外部资源依赖、正文长度明显缩水、异常媒体、损坏文件与SHA-256。逐篇验证原文与阅读版的文字、图片顺序一致，目录中完整/缺件/失败分别显示。
6. 建立本地目录和SQLite全文索引。清单的“下载完整”只表示本次取得版本的图文资源齐备，精读、逐图理解及事实核验另行开展。

此次执行不制作正式Concept、Mechanism或Event，不改动旧来源原件。`Source`位于现有Git仓库外，本次只建立本地材料库。
