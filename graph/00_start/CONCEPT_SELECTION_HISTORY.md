# 对象目录形成记录

本页回溯对象目录的筛选与调整。当前使用[正式对象目录](CONCEPT_IMPORT_LIST.md)，取舍方法见[节点选取原则](NODE_SELECTION_GUIDE.md)。

## 经过

1. 原候选目录共有349项，混合了具体金融对象、基础口径、一般分析变量及部分关系过程。
2. 2026-10-24，主agent依据用户对平凡性和独立研究价值的要求重新审阅，提出保留159项、排除190项的方案。
3. 用户进一步限定回补、删除、迁移与拆分范围：回补5项，移出1项对象；确认5项转机制、3组拆分，并拒绝额外扩展建议。最终对象数为159＋5－1＝163。
4. 2026-10-25确认163项对象。迁移、拆分按各自ID处理，不能在上述加减之外重复计数。

## 取舍中明确的思想

- 独立节点需要有值得持续积累的对象知识及具体金融联系。新闻重要性、数据可得性或可扩写篇幅都不足以单独确立资格。
- 定义、计算口径和一般背景可以在正文解释；排除独立建页不等于删除知识内容。
- 回补净息差、金融周期、农产品、社融和宽基ETF，说明判断须落到具体对象；不能按“指标”“统计量”“资产分类”整类接纳或排除。
- 对象与机制按解释职责区分；拆分限于明确采纳的条目，不能把所有复合名称或交易策略一律拆开。
- 用户指定的回补与调整有明确边界，不能顺带恢复相近对象。
