# 金融认知 Map：节点纵深研究

## 引子

之前都是沿着source 来制作和丰富graph的，现在已经积累了比较多的source，也做了一共275个节点。我在想，是否可以逐个节点进行一个纵深方向的丰富？idea的来源是看到《信用违约互换CDS》这个条目，他的历史竟然没有08年次贷危机的详细分析，以及次贷危机居然没有作为一个概念/关系/事件 被引入graph，让我感觉这个graph 比较单薄。因为次贷危机的严重性，典型性，以及CDS在次贷危机种的标志性演变，后面许多相应标的新情况的分析都应用了大量的和历史经典的对比。这个方法不只是CDS，对于其他大量的经典历史事件，他们带来的影响力仍然不断地在现在的时政金融里起作用。

## 分支目的

本分支探索以已有节点为起点的纵深研究。沿source制作已经积累了工具、机制和近期案例；沿节点回看，可以主动寻找理解这些知识所必需的经典历史、制度变化与解释争议。两条路径交替推进，历史研究发现的缺口也可以改变现有节点的内容和结构。

目前《信用违约互换CDS》的历史入口集中于近期AI融资案例，正式目录与事件库尚无以次贷危机或2008年金融危机命名的独立条目。其他页中的零散危机材料，需要围绕完整问题串联。这个缺口提示我们：节点数量、定义齐全和近期案例丰富，仍不足以说明一项知识已有充分的历史纵深。

要积累的是可反复用于理解现实的历史认识：一种工具怎样被使用，风险怎样积累，冲击怎样沿合同和资产负债表传播，哪些判断失效，以及这些经历怎样改变后来的制度与市场行为。

## 怎样选择纵深问题

长期可以逐项回看275个节点，先从解释缺口明显、连接多个机制、又经常被现实讨论引用的节点试起。每个节点所需的历史由其问题决定；不为所有条目安排相同数量的年代、案例或章节。

经典事件的入选理由需要具体：它暴露了哪项平时难以看见的约束，改变了哪种工具、制度或行为，或者形成了今天仍在使用、也需要重新检验的解释。事件的知名度可以引导寻找材料，最终保留哪些内容取决于解释收益。制度建立、正常时期的演变、成功干预与反例同样值得研究，选材不局限于危机。

一次研究可沿相邻对象和机制展开。共同的历史事件统一维护，各节点从自己的问题进入，避免在多个页面反复写同一段危机简史。

## 从历史形成可使用的认识

先把事态的起点和演变讲清，再追踪参与者的合同责任、资金来源、付款与抵押要求、损失和风险承担。区分最初的损失、放大过程、传播路径和干预，说明哪些联系有直接证据，哪些仍有争议。

同时保留当事人当时知道什么、如何判断，以及后来的研究怎样修正解释。事后识别出的机制不能自动成为当时已知的预期；一场危机也可能包含多条并行过程。影响结论的范围、时间和数量需要定位到材料。

回到现实比较时，要逐项说明相似的安排、成立条件和重要差异。面对“2008再现”这样的说法，应能进一步问：相似性位于信用责任、融资、抵押、市场承接还是其他环节？今天的合同、参与者、资金缓冲和制度是否仍支持同样的传播路径？哪些观察会削弱这个类比？这些问题随具体材料选择，无需制成每篇必填的表格。

## 知识怎样进入graph

- 对象页补充影响其身份、用途、风险和观测方式的历史演变，并提供事件入口。
- 机制页展开可以跨事件使用的作用过程，保存历史表现、适用条件和反例。
- 具体危机优先作为事件或连续事件材料集维护，保存共同背景、阶段、争论和结果。需要怎样分期、是否拆页，由阅读后形成的认识决定。
- 新发现的通用对象或机制可以新增、拆分或重组。事件名称不自动成为概念或关系，已有子概念和具体主体的取舍继续按现行原则判断。
- Source保存出处、原件、实际阅读范围和关键核读。正文保留解释，详细校读各有归属；保留原作者、证据时点和后续修订的关系。

纵深研究的验收看它是否改变了理解：读者能解释常态下的工具怎样在具体条件下产生不同后果，能定位关键历史依据，也能指出现实类比成立或失效的位置。篇幅与新增节点数不作为验收目标。

## 首个试点：CDS与次贷危机

从[信用违约互换CDS](graph/10_concepts/信用违约互换CDS.md)出发，联读[证券化与资产支持证券](graph/10_concepts/证券化与资产支持证券.md)、[证券化中的风险转移与激励](graph/20_mechanisms/证券化中的风险转移与激励.md)及相关信用、对手方、保证金和融资机制。

先核定“次贷危机”与更广泛金融危机的研究范围和时间边界。围绕CDS需要核查：各类信用保护对应什么风险，证券化敞口与交易对手怎样相连，信用损失如何进入估值、抵押和现金需求，哪些责任转移又形成了集中，以及后续市场安排发生了什么变化。具体机构和关键事件随材料确认。

材料按问题定向寻找：原始合同和披露、调查与官方回顾、学术研究，以及有解释价值的长文和参与者叙述。关键事实尽量回到原始证据，争议比较各自材料与推断；中文原文保留中文。现有材料库可以复用，也允许为关键历史补充来源。

试点先走完一次“核对现图—提出问题—定向阅读—形成历史解释与关联修改—回看现实类比”的过程，再决定怎样扩展到其他节点。得到的经验用于改进研究方法，避免提前给275个节点制定统一生产模板或批量启动任务。
