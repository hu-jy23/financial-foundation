# 内容审阅报告的增量展示

所有后续内容审阅报告都在正文标出diff，页面上方提供颜色图例：

- **绿色**：新增段落；整篇新增明确标“新增整篇”，正文使用绿色。
- **橙色**：已有段落中改写的文字；格式或链接变化也须有可见标记。
- **红色**：删除或替换前的原文，单列并默认折叠。
- **原色**：保留内容；已有标题不能因整页更新而被标成新增。

使用本轮制作前保存的原稿或明确的Git提交作为基线，并在报告注明。后续graph变化不能改变同一轮报告的比对结果。新建与更新的判断依据交付清单；缺少更新基线时先补齐。

保持段落、列表、图表、链接和锚点可用。颜色只用于审阅展示，知识正文的Markdown保持干净；YAML等元数据修改在需要时单独说明。验收同时检查增量标色、未改内容原色、删除内容可展开及正文未被标注改写。

实现样例见[CDS试点报告生成器](../workspaces/node_depth/build_report.py)。
