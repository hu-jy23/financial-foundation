# 对于正式开始Step1：

我觉得有一个分工的设计更好，将制作和筛选审阅分开两批agent负责。不过这两拨agent都是主agent拉起，具有相同上下文的，可以看到整个仓库和所有文件的subagent。


以book为例：
    制作：
        制作agent要读的重要说明文件就是制作相关的，包括Step0里的说明文件。

        我记得你不是考虑以某种方式对章节进行重组了吗？那么首先是一批负责制作的Agent：先以某种scope，比如一个章节，或者一组，作为一个unit。然后对于每个unit，都必须选取这个unit里最符合要求的内容，同时现有graph没有涉猎/几乎没有涉猎 的【最优质内容】，制作固定数量的concept或者mechanism条目，比如2个。
        
    

    筛选和审阅：

        审阅agent要读的重要说明文件是思想相关的，包括做的东西的要求是什么，为什么要做这个，要做成什么样的，serve as what in 我的设想。

        先是筛选：由于制作agent有硬性要求，所以一定会出现：【多做】目前graph里有但是还做了类似的；【无意义】一些没什么意义的，不符合制作标准要求的，比如“实际利率/名义利率” 这种东西。筛选需要：1、合并与去重（和已有的相比看看有没有什么大不同，如果有多什么重要的性质/逻辑，就补充一下，小不同就弃掉）；2、去掉低质量（许多文件表明了制作标准和要求，不符合的弃掉；低质量的弃掉；不常见/不核心/影响不大/不作为一些分析的主体 的弃掉）


        对于通过筛选的进而评定：这个东西需不需要/适不适合做成一个条目（比如Step0 的Original List就有很多不适合/不需要）；然后是目前做的有什么问题，如何改进/是否保留。对于不太需要保留的（不常见/不核心/影响不大/不作为一些分析的主体等原因），不修改直接弃掉。
        

    重新制作：如果有问题且很需要保留的，才带着意见，重新还给制作agent再制作一次。然后复审。再不行，就弃掉。

    最后，对于没有出现弃用的章节（比如2/2 都入选的），说明可能是什么重要的核心章节，标出来，交给制作agent再看，看看有没有还要做的。

对ppt：

PPT制作与筛选审阅由主agent分别拉起两批继承完整上下文的subagent，先读所有说明文件、Step0思想文件并查看当前repo。

1、浏览与阅读分工

主agent先浏览整套课件的文字及页面缩略图，按原讲次或连续完整主题划分首次阅读任务。同一论证跨页时合在一起，不按单张slide拆分。先理解作者的问题与论证，再确定候选。

制作agent完整读取负责范围，检查前面的假设、脚注、图注，以及后面的反例、限制和结论修正。同一问题在不同设定下得到不同结论时，一起判断。候选确定后，再定向回查其他讲次或相邻页面，并标明实际阅读范围。

2、图表与模型

关键图、坐标、箭头、表格和公式必须查看原页。辨清图示是原始历史序列、统计估计、示意图还是模型模拟；核对单位、样本、时期、基准及代理变量的实际口径。PDF页序与页脚编号不一致时，以PDF页序定位，必要时同时注明页脚编号。

教师／作者特有的toy model默认排除；去掉公式、改写成定性方向后仍须判断其模型依赖。若模型有超出本书的解释与应用价值，或本书首次为该概念建模，拉起三个继承完整上下文的subagent讨论是否保留。模型推导与同段引用的经验研究分别判断，不能将两者整段一起采纳或排除；经验材料也不能自动证明整套模型或政策结论。

3、提出候选

每项阅读任务可交零份、一份或多份候选，数量不固定；没有值得保留的内容就结束。取消每unit固定两份及2/2入选后的追加检查规则。

候选包含核心解释段落、相对现有graph的重要增量、关键条件、来源页码和拟归属，先筛选再写全文。重要的边界修正、反例及结构调整也可提出，价值按项目思想与制作标准判断。

涉及预期时，核对谁在什么时点，对什么对象、哪个期限形成判断；区分当期价格、未来路径预测及未来一段时间的平均值预测。专家预测、居民预期、作者事后解释与本库推演分别归属。历史共变不能直接写成因果，后来结果不能回填为当时已知信息。

4、筛选与定向补证

筛选agent按Step0思想与最新制作标准，和正式图及其他候选对照。内容重要但已有充分解释的，不重复制作；已有条目缺少重要性质或逻辑的，融入原页；解释职责不同的内容单独判断归属。小差异、低价值和不适合保留的直接弃掉。

先判断价值与重复，再按具体缺失环节补查课件引用的教材、论文或原始数据。Slides解释充分时可以直接作为二手来源，不要求每项都追到原文。重要判断所需依据仍不足时弃掉，不用prior补全后冒充材料结论。

5、全文制作与审阅

通过筛选后制作完整条目或已有页更新。图像按解释需要嵌入并注明来源。独立审阅者返回原页，检查条件是否遗漏、图表是否误读、观察与估计是否混用、模型结论是否被泛化，以及补充来源是否支持正文解释。

很需要保留且存在问题的返修一次，再复审；仍不合格直接弃掉。不另建逐讲阅读报告、阅读地图、缺口清单或弃稿归档。

老师PPT保留作Step3测试；本流程用于Step1教学课件材料，不能提前使用留作测试的PPT。
