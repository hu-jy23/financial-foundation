# Step2材料库

收集有主体、有日期的新闻、分析、预测及后续修正，为概念与机制补充时间维度。

- [搜集清单](LIST.md)：资源选择、首轮议题和搜集范围。
- `CATALOG.md`：实际取得的材料及阅读入口。
- `manifest.json`：原地址、发布日期、观察期、取得状态及文件校验。

材料按议题存放。完整文章、报告或公告保留原文；中文原文保留中文。已有共用原件直接引用，每个原件只维护一个位置。网页文本用于检索，图表仍需看原页。下载和初筛不计作精读，也不直接改变正式map。

网页保存此次取得的版本，发布日期不等于已取得当日快照。历史PDF、初次统计发布、后来修订及当前网页版本分别标明；网页版报告按其目录保留各章，附件未取得则如实注明。

每个议题围绕此前判断、新信息、判断修正和后来结果搜集。发言者的预测、政策制定者的意图、研究者的事后解释和事实结果分别记录。调查形成时间与公开时间分开；后来的修订数据不代替当时版本。

同时保留后来得到支持、被修正及仍有争议的判断，避免按事后结果挑选观点。

本轮先建立七个议题的阅读起点。后续选材可以扩展议题，不按现有节点限制材料范围。教师PPT继续留作Step3测试。
