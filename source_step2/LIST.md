# Step2搜集清单

先整理已有适用材料，再取得首轮原文。下列为计划，实际结果以CATALOG和manifest为准。

## 要什么资源

| 资源 | 选择标准 | 首选来源 |
| --- | --- | --- |
| 当时的专业判断与预测 | 署名、日期、对象和期限清楚；保留条件与竞争解释 | NY Fed调查、ECB SMA/SPF、IMF展望；CF40、Carnegie China Financial Markets等完整分析 |
| 新信息与政策行动 | 能恢复当时公开内容及其口径 | BLS、Fed、ECB、BOJ、国新办、央行、财政部、统计局的历史发布 |
| 连续的事件分析 | 解释谁受到什么约束、如何回应；有可定位证据和后续文章 | BIS季度评论及Bulletin、Fed/ECB研究文章、具名专业长文 |
| 预期修正与复盘 | 能与此前同主体、同对象、同期限的判断对照 | 连期预测报告、预测误差评估、后续调查和执行报告 |
| 结果与数据 | 指标、时期、单位及发布版本明确 | 原始统计发布、发行实际表、WGC需求报告；必要时取历史数据文件 |

官方材料提供行动和统计，也可能包含机构判断；具名分析保留作者立场。单次同向变化不足以证明机制。泛泛入门文、重复转载、无日期评论及只有目录的条目不收入本轮正文材料。

## 持续搜集入口

| 来源 | 重点取什么 |
| --- | --- |
| [Fed FOMC历次会议](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm) | 声明、SEP、记者会、纪要；每种材料保留各自公开日 |
| [BLS历史发布](https://www.bls.gov/bls/news-release/home.htm) | 当次CPI与就业发布，保留初值和后来修订的区别 |
| [NY Fed市场预期调查](https://www.newyorkfed.org/markets/market-intelligence/survey-of-market-expectations) | 形成时间、受访群体、问卷及结果；沿历史档案回溯 |
| [美国财政部季度再融资](https://home.treasury.gov/policy-issues/financing-the-government/quarterly-refunding) | 借款估计、发行安排、实际表、TBAC观点 |
| [ECB预测档案](https://www.ecb.europa.eu/press/projections/html/all-releases.en.html)及[SPF档案](https://www.ecb.europa.eu/stats/ecb_surveys/survey_of_professional_forecasters/html/all-releases.en.html) | 同一预测对象的连期版本及修正解释 |
| [ECB SMA](https://www.ecb.europa.eu/stats/ecb_surveys/sma/html/all-releases.en.html)及[Economic Bulletin](https://www.ecb.europa.eu/press/economic-bulletin/html/index.en.html) | 市场分析师判断、当时分析、预测误差复盘 |
| [央行](https://www.pbc.gov.cn/)、[财政部](https://www.mof.gov.cn/)、[统计局](https://www.stats.gov.cn/) | 中文政策原文、执行报告、统计初次发布及答记者问 |
| [CF40](https://www.cf40.org.cn/) | 具名完整论述、季度判断及后续观点；保留作者立场与分歧 |
| [BIS季度评论](https://www.bis.org/publ/qtrpdf/index.htm)及[Bulletin](https://www.bis.org/list/bisbull/index.htm) | 具体市场事件、主体约束、跨期变化及测量限制 |
| [IMF WEO](https://www.imf.org/en/Publications/WEO)及[IMF博客](https://www.imf.org/en/Blogs) | 连期预测与具名解释；工作人员判断和实际结果分开 |
| [BOJ历史政策决定](https://www.boj.or.jp/en/mopo/mpmdeci/index.htm) | 决策、前瞻条件与事件后的政策沟通 |
| [WGC中国研究](https://china.gold.org/goldhub/research) | 展望、调查、需求结果；有官方中文正文时一并取得 |
| [Carnegie China Financial Markets](https://carnegieendowment.org/china-financial-markets) | 贸易、分配、需求与全球失衡的连续具名分析 |
| Reuters、AP、界面新闻、证券时报等事件报道 | 公告前判断、当日反应与受访者分歧；转载注明原媒体，精确时刻未核时不冒充公告前快照 |

本轮以公开可取得全文为先。访问受限的优质原文保留明确地址及状态，不以摘要填充全文库。
