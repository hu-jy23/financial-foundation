# 信用违约互换CDS

> 原执笔：`/root/produce_ai`，2026-11-13。纵深补充：`/root/cds_depth_pilot`，2026-11-17，待审；近期AI证据时点保留。

## 概念定义

信用违约互换（credit default swap，CDS）是一类通过合同转移指定债务信用风险的衍生品。保护买方支付保费，保护卖方按约定条件承担信用损失或结算付款。对企业或主权的单一名称CDS，参考实体是信用风险被观察的企业或政府，交易对手是保护合同的买卖双方；三种身份需要分别识别。

信用保护也可引用指定证券或债务组合。次贷危机中的AIG超级优先CDS，就涉及CDO证券或债务池的特定风险层；其触发、计损、付款与抵押依据具体安排，不能由一份企业单名CDS确认书推断。本页先说明单名工具基础，再解释这些历史用途与差别。[AIG2008年报133—137、143—146页](../40_sources/S-HIST-CDS-CRISIS.md#h02)提供结构化保护的实际例子。

单一名称CDS对应一个参考实体；[CDX信用衍生品指数](CDX信用衍生品指数.md)对应一篮子实体。[主权信用风险与CDS](主权信用风险与CDS.md)保留政府偿付能力、支付制度及主权合同特征；本页提供企业、主权和专题页共同使用的工具基础。

## 概念详解

### 买卖双方分别承担什么

买方以保费支出换取约定事件后的保护，也承担保护卖方履约和交易安排风险。卖方收取保费，承接参考实体的信用风险；若交易需要保证金，其现金需求会随估值变化。名义本金衡量合同规模，通常并不表示买方在成交日交出同额本金。

保护覆盖由参考实体、债务顺位、信用事件定义、保护期限、结算币种及可交割义务共同决定。企业CDS与主权CDS的适用条款可能不同，评级下调、股价下跌或一般经营困难并不自动等于合同触发。结算可按约交付合格债务，或根据拍卖／约定价格现金结算；具体触发与付款沿用适用确认书，不能凭“公司陷入危机”的新闻标题判断。

### 报价与支付

平价利差以年化基点表示；标准化交易也可以采用固定票息加初始价款。固定票息在约定支付日持续支付，初始价款调整成交时两腿的现值差。预付点数（points upfront）以名义本金的百分比表示：在买方支付的报价方向下，15.5点对应每100名义本金先付15.5，仍要连同后续票息理解。[ISDA标准模型说明](../40_sources/S-WS-3784900.md#isda-model)介绍了这种报价及其标准转换目的。

利差与upfront之间的转换依赖期限、票息、曲线与回收等输入；二者不能直接相减。价格隐含的风险调整量也需要与[主观概率与风险中性概率](主观概率与风险中性概率.md)区分。只看到“15.5点”，无法推出年保费15.5%或违约概率15.5%。

<a id="proxy-hedging"></a>
### 没有现金债也可能有需要管理的风险

持债机构可买保护管理债券信用暴露。放贷银行承担贷款损失，股票投资者承担企业剩余收益变化，也可能使用同一企业或关联企业CDS管理部分风险。参考实体或工具不同，就是代理对冲：企业股价、贷款价值与CDS估值不会完全同步，期限、顺位和结算覆盖也可能不同。保护买方可在违约之前通过合约市值变化获得部分抵销；对冲效果仍须匹配实际敞口。

每笔交易同时有买方与卖方。未持债买入保护可以表达观点，也可以管理别处已有的风险；仅凭没有债券无法判断其经济动机。[AI相关企业CDS](AI相关企业CDS.md)记录了2026年10月文章所讨论的银行与股票基金买盘解释。

<a id="measurement"></a>
## 观测与数据口径

读一条CDS价格，先确定参考实体、保护期限、币种、顺位和合同版本，再区分平价利差、固定票息及upfront；还要知道是成交价、买卖报价还是估值。

成交量是一定期间完成交易的名义金额，未平仓名义额是某一时点仍存续的规模。新建、平仓、换手和抵销对它们的影响不同。总名义额、净名义额、合约市场价值和最终损失各有含义，未平仓增加本身没有提供净资金流入方向。

期限曲线比较同一时点、同一参考实体的不同保护期限。本文讨论的3s5s采用五年利差减三年利差；曲线变平既可能与风险期限分布有关，也可能与特定期限对冲需求有关。具体亚马逊／谷歌比较保存在[事件记录](../30_events/AI融资扩张中的CDS价格分化：2026年10月.md#curve)。

## 历史与关系入口

### 2007—2009年：保护责任、现金需求与净结算

[次贷危机与全球金融危机](../30_events/次贷危机与全球金融危机：2007—2009年.md)提供共同阶段，下面沿CDS的合同责任进入其中。

次贷危机把CDS带入多层信用责任。住房贷款先进入RMBS，再被CDO购买或通过合成CDO中的CDS引用；同一证券可以被多个合成交易反复引用，新增合约并不要求新增同额房贷。它扩大了围绕相同风险建立的合约暴露，保护买方的收益与卖方损失相对应。要判断后果，需要追踪风险集中到谁、其资本和现金能否履约，不能把总名义额当成全社会净损失。[结构与原图](../30_events/次贷与金融危机中的CDS：风险集中、现金压力与违约结算.md#structure)。

AIG的典型性在于：保护卖方可能在最终信用损失确定之前，先因估值变化及自身评级下降被要求补交抵押。AIGFP部分多部门CDO保护订立时没有预交抵押，但附带后续追缴条款；2008年9月末，其超级优先信用衍生品抵押存量合计328.14亿美元，其中多部门CDO组合314.69亿美元。这里是年报特定口径的存量，既非全部CDS名义额，也非最终赔付。AIG还同时承受证券借贷现金返还压力；两条渠道要分别识别。认为某一优先层最终不太可能损失，仍不足以证明保护卖方能承受中途现金追缴。[AIG合同、存量表及独立融资链](../30_events/次贷与金融危机中的CDS：风险集中、现金压力与违约结算.md#aig)。

雷曼案例展示另一面。2008年以它为参考实体的CDS拍卖价格为面值的8.625%；据SSG调查，约720亿美元总名义额对应约52亿美元净结算支付，抵销使实际搬运的现金小于总承诺。拍卖价用于当次合约结算，净付款描述相应信用事件；两者都没有统计雷曼作为交易对手倒闭后的全部替换损失，更没有统计整个危机损失。[两种雷曼身份与结算口径](../30_events/次贷与金融危机中的CDS：风险集中、现金压力与违约结算.md#lehman)。

这些经历促使市场更重视交易记录、净额、信用事件处理和清算安排。美国2012年首批强制清算决定覆盖特定非分层指数CDS等类别，并不意味着所有单名或结构化保护都进入CCP。抵押能降低无担保信用敞口，也会要求参与者及时筹集现金；清算与抵押之后，仍应分别识别保护卖方、共同清算节点及客户的资源。[具体历史安排及范围](../30_events/次贷与金融危机中的CDS：风险集中、现金压力与违约结算.md#arrangements)。
