# 次贷与金融危机中的CDS：风险集中、现金压力与违约结算

2007—2009年危机中，CDS至少处在三种不同的关系里：抵押贷款风险可以通过合成结构被重复引用；AIG等保护卖方需要在最终信用损失确定之前筹集抵押现金；雷曼违约后，以它为参考实体的CDS要结算，它作为交易对手的其他合约又需要另行处置。把这些过程分别讲清，才能理解CDS怎样改变危机传播，这些认识为后续信用事件提供历史参照。

本专题从[次贷危机与全球金融危机共同入口](次贷危机与全球金融危机：2007—2009年.md)进入CDS问题。历史事实依据当时披露和事后调查，综合解释由本库于2026-11-17整理。[原件与阅读范围](../40_sources/S-HIST-CDS-CRISIS.md)。

<a id="structure"></a>
## 贷款损失怎样进入证券和信用保护

住房借款人不能按约还款，会使贷款产生损失。贷款进入RMBS后，收回的现金按合同顺序分给各层证券；CDO又可能购买这些证券的某些层，再次分层。[证券化](../10_concepts/证券化与资产支持证券.md)改变投资者承担损失的顺序。底层住房价格和收入受到共同冲击时，看似分散的贷款可能同时恶化；较厚的次级缓冲和较高评级，都依赖损失幅度及相关性的判断。

现金CDO需要购买资产，**合成CDO可以通过CDS引用已有证券的表现**。希望获得保护或表达看空判断的一方支付保费；承担风险的一方取得保费，并在约定损失出现时支付。部分风险承担者先出资购买票据，现金进入载体；另一些保护卖方只在将来符合条件时出钱。不同层损失顺序、是否预先出资，以及谁向谁付款，共同决定结构的风险。

![FCIC图8.2：合成CDO的保护买方、已出资投资者与未出资保护卖方；原报告印刷144页／PDF172页](../../materials/historical/node_depth/CDS/figures/fcic_figure_8_2_pdf172.png)

同一份RMBS可以被多个合成交易引用，因此增加信用保护合约并不需要新发放一笔住房贷款。FCIC报告列举：一层面额约1200万美元的CMLTI 2006-NC2证券，被超过5000万美元的合成押注引用。这里比较的是底层某一层证券面额与围绕它建立的合成风险额；它没有把住房贷款本金变大，也不能被读成最终全社会净损失增加相同金额。保护买方的合约收益与卖方的合约损失相对应，付款压力集中到谁、对方是否有资本和现金履约，才是继续追踪的重点。[FCIC，印刷142—146／PDF170—174，例子在印刷145页](../40_sources/S-HIST-CDS-CRISIS.md#h01)。

风险复制的重要后果，是让同一住房冲击进入更多机构的资产负债表，并可能集中到少数愿意持续卖保护的机构。当这些机构也与银行有大量合同关系时，贷款损失、保护卖方信用恶化和交易对手履约担忧会交织。仅有总名义额不能计算这种网络的最终损失；判断放大效应，需要同时看各机构净敞口、抵押、资本和融资。

对合成交易的评价也有分歧。FCIC在同一节保留了高盛对定制风险暴露和流动性的辩护，以及美联储研究人员关于合成结构放大次贷影响的判断。这些是有归属的解释。合成结构参与危机的证据，不能替代对承保质量、评级、杠杆、融资和监管等其他环节的调查。

<a id="aig"></a>
## AIG：信用保护还没有到最终赔付时，现金已经不够

AIG Financial Products承接过多类信用保护，包括银行为监管资本目的购买的保护，以及针对多部门CDO优先风险层的保护。不能把AIG整个CDS账本都当成美国次级房贷；不同组合的参考资产、抵押安排和损失特征不同。集团信用支持与AIG曾有的高评级，有助于交易对手接受它对未来支付的承诺。FCIC指出，相关业务订立时通常不先交抵押，但约定在参考资产估值下降或AIG被降级后补交。[FCIC，印刷140—141／PDF168—169](../40_sources/S-HIST-CDS-CRISIS.md#h01)；[AIG年报，133—137页](../40_sources/S-HIST-CDS-CRISIS.md#h02)。


### 当时为什么愿意承接这种风险

FCIC后来调查重建的动机是：银行用保护管理信用暴露，部分交易还能获得监管资本缓解；AIG则认为较厚的次级损失缓冲使超级优先层发生最终损失的机会很小，可以持续收取保费。集团曾有的高评级、财务实力和专业声誉，又使交易对手愿意接受它的承诺。这组判断把注意力放在资产最终损失与保护卖方信用上；追加抵押所需的现金另受合同约束。[FCIC，印刷140—141／PDF168—169](../40_sources/S-HIST-CDS-CRISIS.md#h01)。

这里需要分开三笔账：

- **最终信用损失**：参考资产最终没有收回的金额，按结构及保护合同分配。
- **合约估值与抵押**：对手按合同要求担保已有市值敞口。估值变化和抵押阈值变化，可以在最终损失确定之前带来现金需求。
- **筹资能力**：AIG当时能在多短时间内取得多少合格抵押和现金。长期资产可能有回收价值，仍未必能及时卖出或融资。

AIG的2008年报说明，信用支持附件（CSA）需要按主协议、交易组合和具体条款计算。多部门CDO组合的多数协议，抵押与名义额及参考CDO市值差额的修改公式相关，阈值还受评级影响；不能套成“任何一条CDS利差上升，就按统一比例追加保证金”。市场缺乏可观察价格时，AIG与对手的估值可能不同，争议会影响实际追缴。自2007年中起，市场价值恶化和评级变化使这种现金约束显现。[年报143—146页](../40_sources/S-HIST-CDS-CRISIS.md#h02)。


<a id="aig-judgments"></a>
### 2007年：估值争议已经出现，公开判断仍认为可以承受

**7月27日，追缴先于最终损失到来。** FCIC依据往来邮件和调查重建：高盛向AIG发出18亿美元抵押要求，之后下调至12亿美元。AIG用以判断最终信用损失的模型，没有给出同一时点的市场估值；高盛则依据合同要求对市值下跌补抵押。双方争论的是应担保多少当前敞口，预计最终能收回本金并不能使这项付款要求消失。[FCIC，印刷243—244、267／PDF271—272、295](../40_sources/S-HIST-CDS-CRISIS.md#h01)。

**8月9日，对最终损失公开表达信心。** AIG在第二季度业绩会上强调超级优先层下面的损失缓冲、逐项筛选和全存续期压力检验。Cassano在问答中表示，在其认为合理的严厉衰退情景下，未看到这些交易发生最终信用损失。这是公司当时对信用损失的判断。FCIC后来查得，AIG于次日先向高盛支付4.5亿美元抵押，双方仍保留对追缴金额的争议：公司对最终信用损失保持乐观，同时已开始支付现金。[8月9日业绩会，PDF13—15、27页](../40_sources/S-HIST-CDS-CRISIS.md#h10)；[FCIC，印刷268／PDF296](../40_sources/S-HIST-CDS-CRISIS.md#h01)。

**11月8日，现金问题已经进入公开问答。** 分析师Dan Johnson追问对手估值分歧及其流动性影响。Cassano承认对手已提出抵押要求，相关交易估值差异很大；他仍表示公司有足够资源满足可能到来的追缴。这次问答直接讨论了估值、抵押和现金，公司公开判断仍是资源充足。[第三季度业绩会，PDF17页](../40_sources/S-HIST-CDS-CRISIS.md#h11)。

此后抵押存量继续上升。到2008年9月需要紧急融资时，“最终损失概率很低”与“随时有现金履约”这两个判断的差别，已经成为实际的生存约束。

| 时点 | AIGFP超级优先信用衍生品抵押存量合计 | 其中多部门CDO组合 |
|---|---:|---:|
| 2007-12-31 | 28.79亿美元 | 27.18亿美元 |
| 2008-06-30 | 138.19亿美元 | 132.41亿美元 |
| 2008-09-30 | 328.14亿美元 | 314.69亿美元 |

表据AIG年报146页，原单位百万美元，本文换算为亿美元。口径为对其他交易的抵销前抵押存量；这里记录特定组合的时点存量，区别于期间现金流、最终损失和集团全部衍生品抵押。2008年9月末，大部分来自多部门CDO组合。年报指出参考资产市值是后续抵押需求最重要的因素，同时承认危机条件下无法合理估计将来须补多少抵押。

现金紧张还来自**另一条证券借贷链**：AIG的保险机构把收到的借券现金抵押投资于RMBS等资产，借券人归还证券、要求收回现金时，需要出售或融资这些流动性变差的投资。美联储2010年证词把这条渠道与AIGFP的CDS抵押追缴分别列出。因此，“AIG出问题”不能全部记成CDS赔付，证券借贷的现金流也不能与CDS抵押存量直接相加。[Alvarez证词，Role of the Board下“Securities Lending Facility”及“The November 2008 Restructuring”](../40_sources/S-HIST-CDS-CRISIS.md#h06)。

参考资产恶化，使保护卖方要筹资；卖方自身评级下降，又可能压低其免抵押阈值。风险保护者因保护责任而陷入资金压力，买方开始担忧保护是否仍有效。这解释了“承担最终信用风险”与“承受中途现金需求”为什么要一起评估。AIG当时的评级、合同和投资结构构成了具体路径；其他保护卖方是否有相同路径，须核各自安排。

<a id="intervention"></a>
## 救助怎样改变付款链，政策争议在哪里

2008年9月16日，美联储最初授权最高850亿美元担保贷款，以应对AIG可能的无序失败。这是融资安排的额度，不能列为同日已经发生的CDS损失。不断补抵押仍会消耗资金，随后需要处理导致持续追缴的合约。

Maiden Lane III于2008年11—12月从有关对手购买CDO，同时终止相应AIGFP保护。纽约联储2010年说明列示：其向载体提供约243亿美元优先融资，AIG提供50亿美元次级权益；载体向交易对手净付约268亿美元购得面额621亿美元的CDO，对手保留先前约351亿美元抵押，并放弃相应信用保护。资产面额、购入现金、先前抵押与融资额度各有口径，不能合成一个“CDS亏损总额”。[NYFed，“Background to the Maiden Lane III Transaction”](../40_sources/S-HIST-CDS-CRISIS.md#h05)。

这一安排把持续追缴的合约关系，转成载体持有资产、取得现金流并偿还融资的关系。AIG的未来抵押需求相应减少，公共部门承担了相关融资和资产持有风险；贷款优先级和AIG次级出资提供保护，却不能在2008年成交时保证未来无损。2008年末抵押余额下降，也不能单独解释成市场恢复后对手把钱还给AIG，因为终止交易包含交出原有抵押。

**政策争议有两个层次。** SIGTARP在2009年审计中指出，已交抵押加新增购买款，使对手就相关保护获得约面值补偿；纽约联储的谈判选择和对差别待遇、评级及合同权利的顾虑，限制了取得让步的能力。审计认为，这些选择有成本，并质疑谈判策略。纽约联储在2010年回应中强调保护纳税人、终止不断流出的抵押现金，并说明有关补偿安排已披露。二者对交易现金结构大体相容，对可行政策选择与披露适当性的评价不同。[SIGTARP，印刷18—19、29—30／PDF22—23、33—34](../40_sources/S-HIST-CDS-CRISIS.md#h04)；[NYFed，“Disclosure of Par Value Payments…”等节](../40_sources/S-HIST-CDS-CRISIS.md#h05)。



<a id="lehman"></a>
## 雷曼：参考实体违约结算，与交易对手倒闭是两件事

雷曼2008年9月15日破产后，**以雷曼为参考实体**的保护需要确定结算。10月10日拍卖最终价格为面值8.625%；按这一价格现金结算的合格保护，每100名义额对应91.375的保护支付。8.625是该次合约拍卖的结算价格，不能当成以后破产财产最终回收率。[ECB2009，印刷31—33／PDF32—34](../40_sources/S-HIST-CDS-CRISIS.md#h03)。

但一位交易商可能既买了保护又卖了保护，交易对手之间也可能有多笔相反付款。SSG2009年报告记载：约720亿美元总名义额的雷曼信用衍生品，对应约52亿美元净资金支付。DTCC交易记录和净额流程，使方向相反的应收应付减少了需要搬运的现金；不能把720亿乘以91.375%，当成当日全市场净付款。[SSG，印刷3／PDF7页；净额与结算流程见印刷5—6／PDF9—10页](../40_sources/S-HIST-CDS-CRISIS.md#h07)。

52亿美元描述该信用事件的净结算现金，总名义额与实际净付款可以相差很大。SSG访谈12家机构及服务方，受访者认为2008年下半年有关信用事件整体结算有序，未出现重大操作中断；这是对特定结算过程的调查观察。

雷曼还是许多其他衍生品的交易对手。它倒闭会使对手终止或替换合约，涉及担保、法律净额、市场价格和替换交易。参考实体为雷曼的CDS净结算，并未统计雷曼作为交易对手的所有替换损失，更未统计银行、债券持有人和住房资产的全部损失。净付款较小，也不能证明每家机构都容易筹到各自须交的现金，或所有方向相反的交易都能在相同时点、同一法律范围抵销。

AIG案例暴露保护卖方在最终损失之前的现金约束；雷曼拍卖说明违约后统一价格、交易记录与净额流程怎样压低实际结算需求。两者讨论不同风险，合起来才足以反驳“名义额大所以一定同额爆炸”以及“结算小所以CDS无系统意义”的草率判断。

<a id="arrangements"></a>
## 危机后的安排解决了哪些问题

SSG报告认为，拍卖、法律与操作准备、交易仓库及净额流程改善了信用事件处理，同时记录买方公平性、可交割债务确定和处理资源方面的意见。2009年3月报告提出把拍卖写入常规条款，随后在4月落实。交易仓库记录合约、支付系统进行净额和划款，也不等于一个[中央对手方](../10_concepts/中央对手方与集中清算.md)已对全部合约承担履约责任。

2009年4月的后续落实，BIS2010年12月回顾提供了事后证据：ISDA的“Big Bang”把拍卖结算写进常规合同，采用决定委员会统一确定信用事件等事项，并推行标准票息加upfront来调整合同价值。这使相同参考实体的合同更容易比较和抵销，也连接本库[固定票息与初始价款说明](../10_concepts/信用违约互换CDS.md)。拍卖在2009年之前已经使用，这次变化是将程序固化和统一合同条件；它不自动保证对手有现金或资本履约。[BIS2010Q4，印刷65页专栏全文](../40_sources/S-HIST-CDS-CRISIS.md#h09)。

2012年11月，美国CFTC首批强制清算决定覆盖特定利率互换及特定**非分层指数CDS**，包括符合其系列、期限条件的CDX和iTraxx类别，并有分阶段适用和例外。它提供制度改变的具体历史例子，不能外推为所有单名、所有结构化保护、所有参与者都已集中清算。[CFTC2012-11-28公告](../40_sources/S-HIST-CDS-CRISIS.md#h08)。

完整交易记录和可执行净额有助于识别付款方向；预先筹资及抵押有助于减少对卖方未来承诺的依赖。抵押同时要求参与者及时取得现金，集中清算又使共同清算节点及会员的资源重要。历史经验支持逐项检查风险被转到哪里，不能据制度名称推出尾部风险消失。
