先读通用ARTICLE_AUTHORING_CHARTER.md、本目录四份测试版说明及SUBSTRUCTURE_DISCUSSION.md，再读正式00_start中的README、PROJECT_PLAN、CONVERSATION_MEMORY、两份形成记录、正式目录及相关模板与正文；最新用户约定和本轮补充优先。

顺序：全文与图片→重要概念和关系清单→与graph逐项对照→形成基础解释→进一步分析文章的问题与推断→确定内容维护位置→主agent逐项审阅→HTML报告。前轮“少量结构候选＋一段样稿”不能替代本轮知识覆盖。

清单不等于注册：已有知识可引用，新增和重要更新要有实际解释，普通术语可融入正文。子层级仅在有内容后判断。可以定向访问指数发行方、交易所、基金规则等一手资料补必要定义；不要把本轮变成对原新闻的全面事后核验。
