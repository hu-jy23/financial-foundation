# v2：目标页上下文接入修订

v1的《央行资产负债表》更新片段存在同页符号冲突：目标原稿已用\(A\)表示总资产，拟紧接其后的补充又用\(A\)表示自主因素净吸收量。独立审阅据此阻断整合。v2保留三个更新维护位置，只修复接入所需的记号、范围及衔接说明；v0、v1与正式map均未修改。

## 实际修法

| 位置 | v1或目标页情况 | v2处理 |
|---|---|---|
| CBBS自主因素 | 与目标页总资产同用\(A\) | 自主因素统一为\(AF\)；正文、\(AF=N+G-F-I\)、\(R=M-AF\)、\(M=AF+RR\)与证据说明同步 |
| CBBS来源记号 | 容易把自定义公式读成作者原记号 | 明确A1 PDF64使用名称等式；\(AF,N,G,F,I,M,R\)为本稿公式记号；\(AF\)用于区别原页总资产\(A\) |
| CBBS完整报表 | 原页含资本\(K\)、其余负债与调整\(O\)，教材使用简化分类 | 说明\(F,I\)是总资产\(A\)组成、\(M\)是政策用途净额，\(N/G\)与原页\(C/T\)需核统计边界；完整报表须处理\(K,O\)及吸收工具后再应用 |
| 走廊利率 | 原页贷款端\(i_L\)，来源及v1为\(i_B\)；原页市场利率\(i_{ON}\)，模型为\(i\) | 公式和正文统一贷款端\(i_L\)，明确对应来源\(i_B\)；说明\(i\)对应\(i_{ON}\)。存款端\(i_D\)不变 |
| 走廊自主因素与操作量 | 模型用\(B+d\)，CBBS用实际自主因素；事前\(OMO\)和净操作\(M\)口径不同 | 加\(AF=B+d\)衔接；保留事前操作与日终工具净使用的区别，未令两书数量直接同义 |
| LOLR抵押符号 | 原页\(V\)为估值、\(h\)为折扣；模型以\(L,S,h_1,h_2,K\)表示分组金额与容量 | 说明分组对应；目标页未以\(K\)表示其他量，保留此符号。补明金额兼作账表与抵押估值基数且期间固定、初始借款非负且抵押可覆盖、\(0\le d\le D\) |
| LOLR原有案例与机制 | 原页BTFP面值估值、窗口及时可用、道德风险各有位置 | 模型与面值／市值差异分别说明；使用意愿和到账衔接逻辑2，风险激励衔接逻辑3 |

本轮没有用修改记号来解决两书尚存的制度日期、准备金比例或工具定义疑点。这些未决项沿用v1记录。
