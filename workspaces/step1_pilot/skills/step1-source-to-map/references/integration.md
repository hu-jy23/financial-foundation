# 知识归属与跨源整合

## 先判断增量，再决定条目

对重要内容问：读者新增了什么可解释的认识？是否已由现有对象详解或机制承载？新增独立维护单元有什么收益？以下去向均有效：

| 去向 | 合适情形 |
|---|---|
| 补强既有Concept | 对象定义、组成、口径、边界或自身历史获得实质补充 |
| 补强既有Mechanism | 同一过程的中间因果、条件、竞争解释或时间证据更清楚 |
| 提议新Concept | 有独立知识内容与具体联系，现有对象难以承担 |
| 提议新机制／重组 | 有独立过程；或者材料显示原有机制合并、拆分、归属有问题 |
| 保留为案例／算例 | 帮助理解已有知识，但不值得独立成节点 |
| 暂不吸收 | 材料错误、理解不充分、支持不足或只是复述；说明具体原因 |

新节点数量和总认识增量分别报告。更新片段算更新，不同时计成新节点；逻辑组数量也不等同机制节点数量。对“内容稀疏性”的结论只适用于已读单元，不能由两个章节推断所有教材的固定产率。

对照正式图时查相关原稿，不能仅凭标题判重。已有页相同标题也可能缺少本材料的核心解释。单章内同一框架的情景优先对照呈现；当框架包含多个具有独立研究职责的过程时，也允许拆分，给出理由即可。

## 选题与模型怎样进入Map

正式选题说明它能帮助理解什么现实金融问题，以及与其他重要对象／机制有什么联系。章标题和教材篇幅不能决定节点优先级。纯粹用于调试skill的样例单独标明；本轮贸易条件等样例不作为后续选题优先级的示范，也不据用户对该样例的评价排除整个主题。

教材／作者特有、主要为教学推演服务的toy model默认不纳入Map。其方程、参数、特殊偏好、分布设定和推导不因原文篇幅大而获得保留资格，也不默认转存为Map的附录或学习材料。阅读记录可简记排除原因和来源位置，无须为每个被排除的模型发起讨论。课程反复使用一个模型，不构成现实价值的依据。

重点提取与现实世界联系密切的对象、制度、约束、行为过程和证据。教学模型中的结论若依赖专有设定，不将其改写成脱离条件的定性常识。若另有制度或经验依据支持某段解释，可以按该依据吸收，并保留关键条件。

遇到有具体理由认为具有超出单本教材的解释、应用价值，或该来源具有首次为相关概念建模意义的模型，可发起例外讨论：

- 拉起三个继承当前会话上下文的subagent（`fork_turns: all`），提供相同的模型原文、相关原型入口及候选理由，分别形成保留／不保留／待补证的判断。
- 判断须落到现实解释对象、实际用途、跨教材／研究／实践的使用依据、关键局限与维护收益；首次建模的归属需要核实，不能仅据作者自述认定。三个agent共享上下文，不把意见一致误当成三个独立证据。
- 主agent汇总分歧、依据与建议，不以多数票替代证据。未决候选暂不进入正式Map。若保留，说明保留哪些内容、怎样服务定性判断，以及放置位置。

Black–Scholes一类通用模型用于提示这种选材取向；agent已经熟悉某公式不构成排除理由，也不免除来源核验。已经明确属于通用工具的内容不因再次出现在教材中而被当作作者特有toy model。

正文围绕主体、约束、行动、传导与方向组织。通过保留判断的模型，才进一步决定必要公式与支持材料的分工。关键成立条件与可能改变结论方向的因素留在主文。

定量主要服务预期的比较，最终支持上升／下降、增强／减弱等有条件判断。区分观察值、情景假设与估计，不把教学算例当现实弹性。必要的定义、核算关系和数量约束可以保留；不以公式数、推导长度或自行编制的算例展示解释深度。

## 多来源如何合用

先为每个阅读单元完成实际理解，再按同一对象／过程对照。可用简表区分：

- **同义重复**：同一含义与条件。选更清楚的主要解释，保留其他来源的支持位置，不复制两套正文。
- **实质互补**：另一来源补出此前缺少的过程、操作细节、适用条件或例证。吸收到同一解释的相应位置。
- **范围不同**：国家、时期、计价、主体、制度准入、模型边界或参数不同。保留各自范围；需要时形成逻辑分支。
- **实质分歧／错误候选**：在同一含义和条件下陈述冲突。展示分歧及核验路径，无法裁决时保持未决。

不同来源的术语先对齐再比较；同一名称可能指不同量。不要把两本书各写一份近义条目后交给下游猜怎样合并。某来源的假设也不能借另一本书的结论静默补齐。

## 结构修改与正式整合

Toy graph的原排除项可以重新审视。提案说明材料依据、现有结构未解决的问题、备选归属和影响路径。试点只写提案及可读草稿；正式整合时再分配ID、同步链接和目录。

更新稿明确替换／插入到哪个原稿小节，解释对原有结论的影响。新稿可独立学习；更新片段允许依赖被更新页，但应提供该页入口和所需上下文，不能留下无法解释的符号。

## 更新片段的接入检查

单独正确的片段仍可能在目标页产生错误。执笔者读拟插入位置的相邻段落，列出会重复或冲突的定义、符号、口径和模型前提；检查同一个字母是否在原稿表示别的量。重命名自定义符号时说明它与来源记号的对应，并同步公式、算例和证据说明。

检查新片段是否把原稿的跨国／历史范围压成单一模型、是否重复解释同一过程，以及读者是否能从上下文接上论证。交审说明插入／替换位置与必要的衔接修改。无法完成这一检查时，只能把片段称为独立候选，不能声称已经可直接整合。

单独的核算恒等式或可行性约束通常随对象解释；若材料进一步展开独立的主体响应过程，再评估机制职责。分解与约束也可能有独立维护价值，应提出具体理由，不因出现代数推导就自动生成机制。新对象与附属学习材料均可作为备选提案，比较它们的解释收益与维护成本。
