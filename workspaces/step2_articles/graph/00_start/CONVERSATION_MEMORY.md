# 项目约定

整体目的、阶段安排与原型暂定性见[整体规划](PROJECT_PLAN.md)。以下范围决定记录Step0的选择，后续可以依据材料重新审视。本文件仅保留有效的范围决定与协作偏好。内容标准见[制作标准](AUTHORING_STANDARD.md)，选取方法见[节点原则](NODE_SELECTION_GUIDE.md)。

## 范围与归属

Step0原型为163个对象、71个机制；现行范围见正式目录与索引。新增、删除、迁移、拆分或改名须单独提出并明确采纳，再同步目录、索引和引用。

- 净息差、金融周期、农产品、社会融资规模、宽基ETF均在对象范围；宽基ETF不包括行业ETF。战略储备与能源安全保留为一个对象。
- 制裁与资产冻结不独立作为对象节点。
- 美元融资依赖、全球美元体系与美元主导地位、收益率曲线陡峭化与平坦化、人民币国际化、美元信用与储备多元化归入机制。
- 基差／基差交易、准备金利率／利率走廊、金融周期／系统性风险的积累与扩散分别承担对象与机制职责。
- 名义与实际GDP、GDP平减指数、潜在产出、家庭消费、储蓄率、企业投资与资本开支、库存与库存周期、产能利用率、贸易余额与净出口在相关正文中解释，不独立建页。普通变量不会因研究中出现而自动成为节点。

## 协作与文件维护

讨论时简短直接，先理解例子与反问背后的取舍，再执行工作。已确认观点无需反复复述。

模型、档位、执笔、编辑与审阅按实际记录，不猜测；旧批次的作者配额与模型配置不自动适用于新任务。

工作区修改无需反复发送；需要完整包时交付完整包。任务完成后删除临时任务、中间稿和旧过程记录，通过Git追溯历史。
