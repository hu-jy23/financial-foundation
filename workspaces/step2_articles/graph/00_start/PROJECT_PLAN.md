# 项目整体规划与研究思想

本文件记录项目的目的、阶段安排与判断原则，供后续agent理解工作为何这样组织。具体写作与证据要求见[制作标准](AUTHORING_STANDARD.md)，材料路线见[材料候选与阅读路线](../40_sources/ACQUISITION_SHORTLIST.md)。涉及原型是否可调整、如何使用样例及各阶段职责时，以本文件为准。

## 为什么做这个项目

建立能够持续积累金融认识、解释具体事件的map。对象页保存对象的含义、构成、观测与历史；机制页解释对象如何相互作用；事件和来源材料保存具体情境、当时判断与证据。逐步形成概念与时间两个维度相互连接的知识体系，为理解预期的形成、变化与修正提供基础。

原本的路线是用权威、高质量的教材和长文构建基础，再用高质量新闻、事件分析和博客丰富。直接从零阅读并建图存在困难：一个概念往往依赖许多其他概念，尚无起点时，知识边界与组织方式也难以确定。因此增加第零步，先做一个可讨论、可监督的原型。

## 两条上位原则

### Toy graph具有暂定性

Toy graph提供阅读和组织材料的起点。GPT prior不足以保证知识准确、完整或结构恰当；教材可以改写原型的内容与结构，这是后续工作的正常部分。

现有163个对象、71个机制，共234个节点，属于原型阶段的选择。新增、删除、拆分、合并、迁移、改名或重组逻辑都可以由材料阅读提出。说明材料依据、原结构的问题及修改的解释收益，经明确采纳后同步正文、目录、索引和引用。原型的排除清单也可以据此重新审视。

### Alignment保存目的与判断原则

后续agent需要理解用户希望积累什么认识、为什么选择某种知识单位，以及遇到新材料时应如何判断与组织。说明系统保存这些思想，使agent能够处理未在样例中出现的新问题。

Toy case与样例承担具象化和校准作用：展示解释应达到的深度、如何连接理论与情境、怎样处理证据及不确定性。篇幅、段落数、逻辑组数和选材方式依实际问题决定。理解样例时同时理解其组织理由。

## 第零步：从toy case到toy graph

**目的**：把用户脑海中的设想转为可检查的成品，并完成与agent的初步alignment。

先从GPT prior出发，形成一个简小的foundation原型。用户能够细致监督1—2篇条目的制作，在具体修改中明确知识应如何组织、解释到什么程度，以及项目的初衷与判断原则。

在精调样例及原则的基础上，适度扩展为toy graph，使它能够承接后续高质量来源。过程中可以查证和引用外部材料；局部查证不等于已经完成教材层面的系统建基。

**阶段产出**：可用的原型、经过校准的样例、能够传递给后续agent的判断原则。完成数量用于描述原型规模，知识可靠性仍需下一步检验。

## 第一步：以高质量材料建立基础

**目的**：以权威教材、系统课程和高质量长文建立、校正并丰富基础认识。

1. 选择主干材料，确认版本、可取得范围及阅读路线。
2. 按有意义的连续章节、模型推导或完整论证阅读，理解概念依赖、主体、假设和经济过程。
3. 将材料与原型对照：哪些已有解释得到支持，哪些需要纠正，哪些重要内容或关系尚未承载。
4. 根据材料补充正文，并提出必要的结构调整；拆分概念、合并关系、改变逻辑组织均属于正常工作。
5. 用制度材料、专题研究及有实质差异的解释补充和检验认识，保留证据、适用条件与未解决问题。

阅读可以超出已有节点和主题分组。材料中的每个术语也无需自动成为独立节点，应按独立积累价值与解释职责判断。

**阶段产出**：经系统材料检验与修订的基础map，以及可追溯的来源、适用条件和具体缺口。逐项区分下载、抽读、精读与整合，不能以来源数量或已下载文件数量代替理解程度。

## 第二步：积累时间线与具体预期

**目的**：利用高质量新闻、事件博客、专题分析、调查及原始公告，让map逐渐形成概念与时间两个维度。

在相关对象或逻辑下持续积累具体状态、事件、专业判断、新信息及后续结果。预期应落到具体主体和时点：谁根据截至何时的信息，对什么对象、什么期限形成了什么判断，依赖哪些条件。

随着时间线积累，能够比较：此前怎样判断，新信息改变了什么，哪些判断和解释被修正，后来结果如何。保留预测成功、方向正确但解释错误、预测失败，以及相同冲击在不同状态下表现不同的案例，逐步研究预期形成与修正的模式。

历史主体的预期、市场隐含量、模型估计与本库条件推演保留各自归属；后来结果按日期另行记录。机制本身的条件推演与具体主体当时的判断需要分别辨认。

**阶段产出**：可持续更新、能够对照当时信息与后来结果的时间维度，为逐渐形成预期模型提供材料与检验基础。

第一步和第二步可以交叉：教材的历史案例可以丰富时间线，事件研究也可以暴露基础知识缺口。仅在归属明确时标注阶段，无须为每份材料强行指定唯一阶段。

## 第三步：用教师PPT测试

**目的**：检验map对实际课程材料的知识覆盖、解释能力及事件分析能力。

用教师PPT中的概念、论述、事件、图表和判断检查map：能否定位所需认识，展开省略的逻辑，辨认适用条件，理解作者当时的判断，并指出证据不足或尚不能解释之处。

记录缺失知识、结构问题、解释跳跃和时间信息缺口，再回到相应阅读与建图工作。测试用于发现和修正问题。

部分教师课件已参与原型制作。使用时说明哪些内容此前已经接触、哪些是新测试材料，区分对已有内容的复查与对新内容的检验。
