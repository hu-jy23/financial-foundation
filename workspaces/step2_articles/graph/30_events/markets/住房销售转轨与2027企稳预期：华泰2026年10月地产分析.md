# 住房销售转轨与2027企稳预期：华泰2026年10月地产分析

华尔街见闻于2026-10-19 08:46转载华泰睿思《地产或正迈向“中期逻辑”》，页面署名龙玥。文章把两轮政策放在同一条跨期链条中解释：销售制度转轨可能压缩开发商拿地和未来供应，按揭贴息与交付确定性降低部分买方的购房障碍；若低总价二手房先稳定，置换需求再进入改善新房，2027年房价企稳范围可能扩大。这是华泰当时的展望。

下文保留完整分析线索，关键图就近展示，[全部21图](../../40_sources/S-WS-3783877.md#figures)可按图号核读。行业数字和样本估计归属华泰转载；政策核对与条件解释由本库2026-11-16补录，没有加入2027年结果，也未将10月19日随后发布的月度统计回填进作者信息集。[来源与核读范围](../../40_sources/S-WS-3783877.md) · [完整本地原文](<../../../../../materials/wallstreetcn/SourcePost/地产或正迈向“中期逻辑”/article.md>)。

<a id="supply"></a>
## 1. 供给收缩来自资本周转变慢，作用要等到新项目推出

华泰认为828制度重构开发模式：新预售项目的收款、资金释放与现售项目的主要回款向完工阶段靠拢，房企须垫资更久，下一轮拿地能力降低。作者援引其2026-09-13报告测算，在考虑土地分期等缓冲后，新预售／新现售模式下可动用拿地金额分别可能下滑33%／41%，据此推断土地出让金未来或在当前规模上下降30%—40%。本轮未取得该报告现金流底稿，保留测算归属，不将其推广为所有房企的统一比例。

转载报全国9月涉宅用地成交面积同比下降32.3%，8月为下降16.6%；1—9月成交24461.1万平方米、下降22.3%。作者同时提及去年同期高基数与房企观望。9月一线宅地供应宗数同比下降35%；节后首周300城供地环比下降89%、同比下降10%，一线仅广州有5宗待拍。

![图1：全国涉宅用地累计成交面积及累计同比](<../../../../../materials/wallstreetcn/SourcePost/地产或正迈向“中期逻辑”/assets/figure_001.jpg>)

图1是累计成交；补充的[每周供应图2](../../40_sources/S-WS-3783877.md#figure-2)和[一线月度供应图3](../../40_sources/S-WS-3783877.md#figure-3)采用不同窗口，节后环比低点也受供地日历影响。本库据此保留当期缩量与资本周转预期相符的观察，制度的独立作用仍须跟踪同类项目。

[房地产现金流循环](../../20_mechanisms/房地产开发的现金流循环.md#logic-3)解释其时间差：拿地减少要经过开工、建设、推出才减少新增供给。已有库存和二手挂牌仍可继续形成出售压力，因而未来新供给缩量与当前房价下跌能够同时发生。对[土地财政](../../10_concepts/土地财政.md)的影响还要经过价款支付与入库，不能把可动用拿地金额降幅直接写成地方净财力降幅。

## 2. 政策减少购房卡点，先看哪些家庭和项目获得改变

华泰将2024年924以来的政策分为行政、金融和财政三个方向。图4把此前首付、贷款定价、税费优化，与2026年8月销售转轨、9月居民购房贴息连接起来。作者认为，政策同时缓解支付负担和对交付、品质的担忧，有利于本来有能力、有意愿的家庭走出观望。

![图4：2024年924以来全国性房地产政策时间线](<../../../../../materials/wallstreetcn/SourcePost/地产或正迈向“中期逻辑”/assets/figure_004.jpg>)

贴息资格要求住房总价不超过150万元、面积不超过120平方米，并使用符合要求的新发首套商业按揭；100万元另指单户可获贴息的贷款本金上限。房屋资格、贷款额与贴息本金各自影响谁能获得支持、能减多少负担。

图6比较100万元贷款在20／30／40年下的月供：30年从4243元降到3721元，40年从3609元降到3055元。财政成本的情景假设及图注差异另见[来源图5—6](../../40_sources/S-WS-3783877.md#figure-5)。

![图6：贴息前后月供测算，分行期限与240个月注释冲突](<../../../../../materials/wallstreetcn/SourcePost/地产或正迈向“中期逻辑”/assets/figure_006.jpg>)

**本轮制度核对。** 官方929政策的贴息最长五年，并在符合条件的100万元本金上限内按月扣减；图6及正文累计利息52.8万元降至34.0万元的比较，等同于全贷款期按较低利率重算。两种安排的还款和期限不同，18.8万元累计节省不能作为该财政政策的实际效果。完整条件、5万元名义上界及现金核对在[住房按揭页](../../10_concepts/房地产融资与住房按揭.md#mortgage-subsidy-202609)维护。

贴息降低的是前几年的净支付压力。已有首付和长期收入能力、但面临购房初期开支集中的家庭，可能因此把原定稍后的购房提前；这并不自动等于新增同样多的长期需求。补贴退出后还须承担合同负担，若届时收入和还款安排未能衔接，前期现金改善不能证明长期买租成本已持平。[按揭页](../../10_concepts/房地产融资与住房按揭.md#rent-buy-comparison)展开这一时间区别。

现售使购买时能够看到建成的房屋，交付等待与成品信息的不确定性下降；新项目的监管安排也减少了购房款被跨项目占用的空间。这一变化有助于降低买方对未来履约的折价。制度保护范围与存量项目过渡在[预售页](../../10_concepts/房地产预售与保交楼.md#sales-reform-202608)说明，成品可见也不能代替产权、隐蔽质量与配套核验。

作者引用中指调查称，8月底购房意愿强于上月的居民占比升1.2个百分点至16%，半年内计划购房比例升至17%；长江商学院三季度投资者调查中的房价看涨比例从2025年末37%升至56%。两项调查的受访者和问题不同，不能拼成全国购房者共识。本轮只读到转载中的调查结果，没有取得问卷与样本权重。

10月1—13日25城二手房门店成交套数同比增长33%，较9月增速提高14个百分点。图7展示日度七日移动平均，国庆和春节错位都会影响短窗口比较。华泰据此判断转化已提速，并预计潜在买方在未来一年入市；实际是否持续需要更长成交与回款序列。

![图7：25城门店二手成交日度MA7，截至2026-10-13](<../../../../../materials/wallstreetcn/SourcePost/地产或正迈向“中期逻辑”/assets/figure_007.jpg>)

## 3. 租金和融资成本靠近，低总价段可能先出现租转买

截至2026年9月，转载中的百城住宅租金同比下降4.7%，较2025年12月下降8.0%收窄；二线降幅从8.5%收窄到3.9%，一线仍下降6.3%，三线约下降4.9%。按另一租金中位数口径，上海、深圳前9月分别累计上涨2.8%、0.7%；北京、广州累计下降0.7%、0.4%。降幅收窄、累计转正和租金水平回到此前高点，是不同判断。

![图8：百城及各能级城市租金同比](<../../../../../materials/wallstreetcn/SourcePost/地产或正迈向“中期逻辑”/assets/figure_008.jpg>)

华泰以香港作参照：2025年H按融资成本曾随HIBOR下行，住宅价格指数自当年4月低点至2026年2月上涨约7.4%；作者把小户型“供平过租”、租转买和价格回升串为一条解释。[图9](../../40_sources/S-WS-3783877.md#figure-9)同时画租金收益率、HIBOR加130bp与最优惠利率减175bp，理解实际H按还须看具体贷款条款；一段共同变化并未单独识别租转买的因果贡献。

内地部分，作者报百城租金收益率约2.46%，150万元以下房源或高于3%，并以3.05%贷款利率减100bp得到2.05%，认为“月供低于租金”已在政策覆盖客群确立。

![图10：百城住宅租金收益率与房贷利率，末端含作者贴息处理](<../../../../../materials/wallstreetcn/SourcePost/地产或正迈向“中期逻辑”/assets/figure_010.jpg>)

这一步需要同一房屋、同一期限的现金比较：租金收益率以房价为分母，利率以贷款额为分母；月供还含本金，财政贴息又只覆盖有限本金和年限。[按揭页的比较](../../10_concepts/房地产融资与住房按揭.md#rent-buy-comparison)给出不同首付下的结果。材料支持低总价段支付门槛可能下降，尚不足以由两个全国均值确认所有覆盖家庭都已“供平过租”。

<a id="prices"></a>
## 4. 个别城市改善怎样扩展为城市群企稳

文章提出三项条件：置换链条激活、重点城市租金稳定、利率环境改善。其中交易链条最值得持续观察：低总价房源吸纳首套需求，原业主卖旧获得现金，再转向改善新房；若这笔置换资金顺利接续，需求才可能跨价格段、跨新旧房扩散。

华泰报2026年6月70城新房环比上涨城市一度达到20个，8月为15个；二手上涨城市3月为13个，8月回到3个，显示修复仍有反复。文章又称截至8月新房年内累计上涨9城：上海2.0%、杭州1.8%、大连1.0%、宁波0.8%、深圳0.7%、沈阳0.6%、厦门0.5%、广州0.4%、银川0.2%；二手累计上涨5城，其中四个一线城市全部转正。上述累计值保留为作者陈述。

![图12：70城二手房环比上涨、持平与下跌城市数](<../../../../../materials/wallstreetcn/SourcePost/地产或正迈向“中期逻辑”/assets/figure_012.jpg>)

“四个一线二手房年内全部转正”与“出清完成”保留作者归属。[累计图13—14及口径核对](../../40_sources/S-WS-3783877.md#figure-13)存在疑点，未被本库独立确认。已核统计局8月原表中，北京二手房环比下降0.1%，上海上涨0.3%、深圳上涨0.1%、广州持平，提示企稳应明确尺度与期限；[图11、15](../../40_sources/S-WS-3783877.md#figure-11)提供新房城市数量与逐城月度对照。

供需平衡的另一证据是49城挂牌：作者报套数自2025年10月435万高点降至当前428万，同比下降1.5%。挂牌减少可能来自成交、撤牌或样本变化；单凭余额下降无法分清贡献。文章认为这与新供给收缩相叠加，利于更多地区平衡。

作者列出两类价格路径：低总价房源获得财政支持、先吸收租转买；核心区高品质改善房源在后续供给减少、置换需求进入时获得稀缺溢价。截至10月4日，冰山指数中的上海200万元以下房源同比上涨1.9%、年内累计上涨6.3%，文中称苏州、成都、广州低总价段跌幅小于全市。图16也显示深圳、合肥、杭州、北京的低总价段同比表现弱于全市，分化本身值得保存。

上海200万元以下的价格分组含有不满足150万元总价门槛的住房，且未筛选面积、首套和贷款资格；它与补贴覆盖客群不同。该组截至10月4日的价格表现还覆盖政策落地前的大段时期，只能作为分层需求线索，不能直接验证贴息效果。要判断补贴需求是否沿置换链扩散，须先观察匹配资格家庭的交易，再看原业主卖房所得是否进入改善新房；单有低总价房源上涨，尚未走完这条回款链。

![图16：各城市全城与低总价段价格同比，截至2026-10-04](<../../../../../materials/wallstreetcn/SourcePost/地产或正迈向“中期逻辑”/assets/figure_016.jpg>)

<a id="rules"></a>
## 5. 地方过渡条件决定新模式落在哪些项目

华泰认为828政策的股票市场反应已相对充分，后续细则影响趋弱，二三线可能有较强灵活性。[图17完整细则表](../../40_sources/S-WS-3783877.md#figure-17)对照北京、上海、广州、武汉、天津、杭州、深圳的新老划断、地价分期、预售门槛、资金监管、现售定金和配套融资。它表明制度转轨是按具体项目和条件发生的过程，不能只给每个城市贴一个“现售”标签。

本轮另读全国通知与上海原始实施意见，核实了上海新旧项目划分、监管与按揭发放节点；图17其他六地仍按华泰汇编阅读，没有逐项声称独立核对。投资者要观察的是这些安排是否改善交付信用、是否以可获得的开发融资对冲更长垫资，以及未来推盘是否真的收缩。

<a id="equity"></a>
## 6. “低杠杆＋低配”怎样转成地产股中期修复

华泰报2026年二季度公募地产持仓市值276亿元，较一季度减少24%，约为2022年一季度1280亿元峰值的22%；配置0.31%，较标准权重0.84%低0.53个百分点，且连续45个季度低配（[相对配置图19](../../40_sources/S-WS-3783877.md#figure-19)）。持仓市值受股价和持股数量共同影响，权重还受其他持仓变化影响，低配置不能直接计作待回流现金。

![图18：公募房地产持仓市值与配置比例](<../../../../../materials/wallstreetcn/SourcePost/地产或正迈向“中期逻辑”/assets/figure_018.jpg>)

2026年上半年12家重点房企有息负债合计17893亿元、同比下降3.1%；净负债率均值44.6%，较2025年末52.1%下降7.5个百分点。图20原注为“为统一口径，净负债率未考虑货币现金中受限资金影响”，所用现金未按受限用途扣减，44.6%并不直接回答企业有多少现金可用于到期偿债。12家中10家较年末下降，滨江降至−0.5%，建发国际15.7%、中国海外宏洋18.5%、中国海外发展27.2%、华润置地41.3%；仍有个别企业上升，企业差异不能由均值抹平。

![图20：12家重点房企2024—2026上半年净负债率](<../../../../../materials/wallstreetcn/SourcePost/地产或正迈向“中期逻辑”/assets/figure_020.jpg>)

华泰据此认为信用风险收敛、未来减值侵蚀减轻，资金较稳企业保有拿地选择权；若销售恢复，份额与业绩弹性可能更突出。这里的连接是有条件的：净负债率降低需要辨认偿债、现金与权益变化，受限现金也未必能够偿集团债；房价稳定先改善售房收入及资产可实现价值，存货与项目清算结果才决定减值。低配置带来回补空间的前提，是管理人判断改变并形成实际净买入。因此作者的“下行风险有限、上行空间充足”保留为当时投资判断，没有据持仓比例设置股价损失上限。

图21给出另一层结构：2026年前8月重点城市一二手合计成交套数，一线同比正增长，二线及合计仍为负增长。它与“二手交易先恢复、后向新房及更多城市扩散”的预期相连，也显示当时恢复尚未均匀发生。

![图21：重点城市一二手合计成交套数同比，不等同新房销售金额](<../../../../../materials/wallstreetcn/SourcePost/地产或正迈向“中期逻辑”/assets/figure_021.jpg>)

<a id="expectations"></a>
## 7. 留待后来信息检验的当时预期

机构展望保留原归属；表中的后续核对由本库结合上述客群与回款区别提出。

| 判断归属与形成时间 | 对象和期限 | 作者所依赖过程与本库后续核对的观察 |
|---|---|---|
| 华泰，2026-10-19 | 未来两年新房供给收缩 | 新模式资本占用更久，拿地下降经开工和推盘传至供应；同时看开发融资及地价分期能缓冲多少 |
| 华泰，同日 | 未来一年潜在购房群体入市 | 支付门槛、交付担忧降低；按≤150万元、≤120㎡及首套资格匹配家庭，跟踪成交、实际支付与补贴退出后负担 |
| 华泰，同日 | 2027年量价改善、上涨城市从个别扩到城市群 | 低总价二手稳定、卖旧换新接续、租金与融资成本改善、库存消化；区分上海≤200万元价格样本与政策客群，核同质价格及卖旧资金进入新房的回款 |
| 华泰，同日 | 适应新模式房企及地产股进入中期修复 | 经营与信用改善转为盈利，低配置资金实际回补；观察企业现金、减值、拿地和基金净交易 |

**本库于2026-11-16作的条件解释：** 这篇材料的贡献是提出一个阶段衔接假设：降低买方风险的制度，也可能压低开发商资本周转；当需求端改善快于新增供给恢复时，部分细分市场有机会先稳定。检验的核心是各环节能否接上，尤其是低总价二手交易能否带出新房回款、供应收缩能否抵消存量出售，以及有限期补贴结束后的负担。如果价格仍靠降价换量、租金继续走弱、或卖旧资金未再购新，便需下修扩散预期。这里没有给出2027年上涨城市数量或发生概率，原文亦未披露这类预测的区间与底层方案。
