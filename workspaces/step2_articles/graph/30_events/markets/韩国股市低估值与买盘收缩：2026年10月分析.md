# 韩国股市低估值与买盘收缩：2026年10月分析

2026年10月20日，华尔街见闻杨宸转述摩根大通对韩股的研究：预测盈利仍较强、估值已低，企业回购及其他买盘却在减弱，杠杆产品又可能在急跌日减仓。文章要解释的是，为什么“按预测盈利变便宜”尚未转成足够的即时购买，并据此判断后续反弹与再次抛售的条件。

以下保留10月20日的报道和判断；本库展开其作用过程，末节检验为11月16日后补设计，未加入后来结果。[原文](<../../../../../materials/wallstreetcn/SourcePost/韩国跌出“历史级便宜”，为何无人接盘？/article.md>) · [来源及全部8图](../../40_sources/S-WS-3784053.md)。

<a id="valuation"></a>
## 低估值与超卖，为什么仍未带来足够购买

报道称[KOSPI](../../10_concepts/韩国综合股价指数KOSPI.md)当年第三次出现五日跌幅超过15%的重挫。图1给出的8.4倍远期市盈率、第11百分位，属于排除五家大型公司的样本；整个指数另有一条线，不能把这个数直接登记为全指数估值。

![图1：KOSPI及剔除大型公司的远期市盈率；8.4倍、历史第11百分位属于蓝线剔除样本](../../../../../materials/wallstreetcn/SourcePost/%E9%9F%A9%E5%9B%BD%E8%B7%8C%E5%87%BA%E2%80%9C%E5%8E%86%E5%8F%B2%E7%BA%A7%E4%BE%BF%E5%AE%9C%E2%80%9D%EF%BC%8C%E4%B8%BA%E4%BD%95%E6%97%A0%E4%BA%BA%E6%8E%A5%E7%9B%98%EF%BC%9F/assets/figure_001.png)

远期市盈率以预测盈利为分母。价格下降、预测上修都会降低倍数；投资者还要判断预测能否兑现、持有期风险及自己是否有资金和授权买入。历史分位只定位过去分布，未规定未来底部。价格、盈利预测和倍数存在算术联系，不能将三者当成相互独立的证据；[ERP](../../10_concepts/股权风险溢价ERP.md)连接现金流预期与要求回报。

文章另以14日RSI、200日均线和长期趋势线描述超卖。RSI汇总给定回看期的涨跌，均线平滑过去价格，二者反映已经发生的路径；它们没有直接提供买方的执行能力或反转日。技术图及详细样本集中在[来源图读](../../40_sources/S-WS-3784053.md#chart-notes)。

<a id="buyers"></a>
## 买方少买与卖方急售，在同一窗口相遇

报道称，[三星](<../../10_concepts/Samsung Electronics.md>)回购计划已完成、[SK海力士](<../../10_concepts/SK hynix.md>)接近结束，外资持续净卖出，境内机构需求有限。公司计划收尾，减少的是原先持续执行的购买；外资净卖出则需要其他人接手。两者对订单的作用不同，境内机构又未必恰好在同一时点补足缺口。[三大买盘关系](../../20_mechanisms/KOSPI三大买盘与边际承接.md)维护这些行动条件。

![图4：企业每日购股，单位百万美元；调整与购股减速同期出现](../../../../../materials/wallstreetcn/SourcePost/%E9%9F%A9%E5%9B%BD%E8%B7%8C%E5%87%BA%E2%80%9C%E5%8E%86%E5%8F%B2%E7%BA%A7%E4%BE%BF%E5%AE%9C%E2%80%9D%EF%BC%8C%E4%B8%BA%E4%BD%95%E6%97%A0%E4%BA%BA%E6%8E%A5%E7%9B%98%EF%BC%9F/assets/figure_004.png)

图4末端企业购股仍为正，但已从高位减速。它支持“买入速度下降”的观察，未独立量出回购对跌幅的贡献；正文与图示的回购起始年份差异另存[来源](../../40_sources/S-WS-3784053.md#chart-notes)。

已经成交就有买方。“无人接盘”描述卖方要求的时间内，原价附近承接不足，卖方需要让价以吸引愿意承担风险的人。长线资金即使认为预期回报改善，也可能等待波动、保留风险预算，或不相信当前盈利预测。报道没有列出每家机构的具体限制，这些是需要进一步检验的解释。

<a id="trend"></a>
## 趋势转空，能否再带来买回

报道将趋势资金由极多转净空，与空头回补可能支持短线反弹相连。图5实际为动量信号，标题保留“likely”；它是对方向的研究判断，没有直接测到全行业净持仓及剩余订单。原图在[来源](../../40_sources/S-WS-3784053.md#chart-notes)可定位。

信号先结合波动预算、净资产、旧持仓和执行条件形成目标，再成为订单。由多转空可带来卖出；若转空已完成，缩小风险也可能要求买回。因此已发生的转换不能再算成未来卖压，短暂回补也未证明长期配置者回归。[CTA本次历史](../../20_mechanisms/CTA趋势跟随的价格反馈.md#korea-20261020)接入这项判断。

<a id="etf"></a>
## 流出有限，存续杠杆仍可产生规则订单

图6同时展示杠杆ETF的AUM与累计流入，按境内宽基、单股及离岸分组。存续规模在回撤后仍较高，部分产品流出有限，因而摩根大通担心再次急跌仍会触发调仓。AUM含净值变化，累计流入依赖统计方法，两者都没有直接给出剩余卖单。

![图6：左为杠杆ETF AUM，右为累计流入；单位均为百万美元，分组范围并不相同于一个统一KOSPI头寸](../../../../../materials/wallstreetcn/SourcePost/%E9%9F%A9%E5%9B%BD%E8%B7%8C%E5%87%BA%E2%80%9C%E5%8E%86%E5%8F%B2%E7%BA%A7%E4%BE%BF%E5%AE%9C%E2%80%9D%EF%BC%8C%E4%B8%BA%E4%BD%95%E6%97%A0%E4%BA%BA%E6%8E%A5%E7%9B%98%EF%BC%9F/assets/figure_006.png)

对每日恢复大于1倍多头目标的产品，标的下跌会放大净资产损失，旧敞口却只随标的价格变化，风险倍数因而上升。恢复目标需要减敞口，即使投资者没有赎回份额也会发生。完整净资产、敞口推导主留[再平衡机制logic-1](../../20_mechanisms/杠杆ETF再平衡的价格反馈.md#logic-1)，[产品持仓页](../../10_concepts/杠杆ETF.md#holdings)区分份额、净资产、敞口和订单。

形成价格反馈还要再经过一层：基金在哪个工具上调整，对手方如何净额或对冲，以及其他买家能吸收多少。订单集中且承接不足，才更容易要求让价。原图未给逐产品的标的、方向、倍数和实际执行，本文未把总AUM换成现货卖出金额；[机制logic-2](../../20_mechanisms/杠杆ETF再平衡的价格反馈.md#logic-2)解释这一条件。

<a id="earnings"></a>
## 盈利预测上修，仍要与市场收到的信息比较

正文称三星、SK海力士股价下降而预测盈利上修，其他板块也有类似现象。图7本身是剔除两家公司后的前瞻EPS序列，不能用它直接读取两家存储公司的预测。它与估值图的剔除样本也不同。

![图7：剔除Samsung/Hynix后的KOSPI前瞻EPS估计；末端仍处较高水平](../../../../../materials/wallstreetcn/SourcePost/%E9%9F%A9%E5%9B%BD%E8%B7%8C%E5%87%BA%E2%80%9C%E5%8E%86%E5%8F%B2%E7%BA%A7%E4%BE%BF%E5%AE%9C%E2%80%9D%EF%BC%8C%E4%B8%BA%E4%BD%95%E6%97%A0%E4%BA%BA%E6%8E%A5%E7%9B%98%EF%BC%9F/assets/figure_007.png)

报道据此倾向以资金与风险偏好解释下跌，并认为压力消退后反弹可能较强。这个对照说明，价格走弱可以与分析师仍上修同时发生；预测更新也可能滞后，市场可能更早担忧需求、盈利持续性或尾部风险。要区分承接不足与经营重估，应保留各版预测的日期，再接到实际产品订单、价格及交付，不能由两条线背离排除基本面消息。

<a id="cross-market"></a>
## SOX与KOSPI提供两条可比较的解释

[SOX](../../10_concepts/费城半导体指数SOX.md)观察美国上市半导体相关股，KOSPI是另一市场的综合组合。图8显示近期路径分化，文章判断美国半导体初步企稳、韩国仍弱，并警示韩股若继续失守，美股半导体反弹可能受阻。

![图8：SOX与KOSPI双轴点位；不同坐标轴的距离不等于可交易价差](../../../../../materials/wallstreetcn/SourcePost/%E9%9F%A9%E5%9B%BD%E8%B7%8C%E5%87%BA%E2%80%9C%E5%8E%86%E5%8F%B2%E7%BA%A7%E4%BE%BF%E5%AE%9C%E2%80%9D%EF%BC%8C%E4%B8%BA%E4%BD%95%E6%97%A0%E4%BA%BA%E6%8E%A5%E7%9B%98%EF%BC%9F/assets/figure_008.png)

共同AI投资或半导体需求变化，可以经相关公司经营预期传入两地价格；共同持有人减风险也可能产生跨市场交易。韩国回购减速和本地基金调仓又提供另一条解释，它们未给SOX同样的订单冲击。业务结构、权重、币种和交易时差不同，两地可以持续分化，双轴距离并未建立必须收敛的价格锚。

沿三星与SK海力士分别观察[经营和发行人回购](../../20_mechanisms/KOSPI三大买盘与边际承接.md#company-roles)，再将[产业信息与当地承接](../../10_concepts/费城半导体指数SOX.md#observation-use)对照，才能研究韩国弱势包含什么。公司页用于复用身份和经营知识，其10月28—29公告不进入本篇10月20信息集；当前图表也尚未完成逐公司与跨市场联合检验。

<a id="expectations"></a>
## 当时判断与分期检验

**截至2026-10-20的报道判断：** 存续杠杆使再次抛售风险未消，趋势转空又可能带来回补；买盘及波动环境改善前，便宜未必形成支撑。文章还提出压力缓解后的较强反弹、韩股对美股半导体的风险预警。材料未给反转日、目标或概率。

**以下为本库2026-11-16依据10月20材料后补的研究设计，未补入后来结果。** 三个窗口分别检验规则订单、承接持续性和经营信息，不能靠同一段后续行情一次验证所有解释。

**压力交易日及随后数日：规则订单是否接到价格反馈？** 先确认同一产品的标的、方向、倍数及重置规则，再对照实际净调仓、对手方对冲、执行时序与市场深度。若规则要求的净卖出实际集中执行，承接同步变弱、让价扩大，反馈解释更有支持；若实际调整很小，或价格变化在订单前已与重大新闻对应，应缩小将当日跌幅直接归于再平衡的判断，同时检查提前对冲。高AUM、缩量或动量信号单独都不能替代订单。

**随后数周：买方恢复能否超出短暂回补？** 分开观察公司实际回购、外资与境内机构净交易，以及可取得的趋势策略买回。若相同窗口内实际买入持续、深度与价差改善，且可观察的规则化卖压趋缓，支持即时承接恢复；若只有数日空头回补，发行人和配置资金仍弱，则短线反弹不足以证明持续买盘形成。新授权尚须成为执行，单一机构分组也不代表所有成员动机；消息转好亦可能同时带动价格与购买。

**随后季度及预测更新：经营压力还是韩国当地约束？** 沿三星、SK海力士和可比半导体成分，保存产品订单、售价、交付及带日期的EPS版本。若两地可比经营资料共同转弱，产业需求解释增强；若经营保持而韩国购买执行与融资承接更弱，当地约束更值得考察。预测下修须分辨新增经营信息与滞后确认，不能机械用下修本身推翻先前解释。跨市场统一起止日、币种和收益版本并处理交易时差，继续分化仅构成重新分解的起点，不能单独证明共同产业暴露失效。
