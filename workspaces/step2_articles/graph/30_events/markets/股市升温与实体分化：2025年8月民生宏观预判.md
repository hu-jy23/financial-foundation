# 股市升温与实体分化：2025年8月民生宏观预判

2025年8月27日，华尔街见闻转载民生证券陶川、钟渝梅的8月经济预判：A股上涨可能先拉动金融服务及服务业指标，消费和工业却仍受补贴效应减弱、外需放缓和供给调整约束；工业品价格可能先于产量改善。问题由此分成两层：金融交易本身增加了哪些服务，居民和企业又会不会因此扩大真实支出？

本文保存8月27日当时判断及全部9张图片（含16幅原研究图）。各图高频窗口不同，8月末箭头多为作者预测。2026年11月16日为整理日，未加入后来公布的8月结果。[来源与核读范围](../../40_sources/S-WS-3754228.md)登记转载及统计方法补核。

<a id="services"></a>
## 1. 交易活跃可以先映入服务指标，消费还要经过家庭选择

作者认为，金融活动在服务业中占有较大份额，股市活跃将拉动服务业PMI及服务业生产指数。换手增加会带来更多交易执行、账户及相关金融服务，管理资产和业务活动也可能变化；这条直接业务联系可先在[证券与资管业](../../10_concepts/证券与资管业.md#services-202508)观察。指数点位上涨、成交额扩大、金融业产出和居民支出分别需要自己的数据。

图1用2022年服务业各行业增加值构成推测统计样本，金融占16.0%、批发零售20.0%、房地产12.7%。图题明确写“推测”，没有官方两套指数的逐行业实际权重表。服务业商务活动指标来自企业环比增减调查，以扩散指数汇总；服务业生产指数则用行业业务资料及价格处理衡量月度产出。增加值结构可以提供背景，不能直接将16%设为两指标共同、固定的金融权重。[官方方法补核](../../40_sources/S-WS-3754228.md#methods)。

![原图1：基于2022年增加值的服务业样本权重推测](<../../../../../materials/wallstreetcn/SourcePost/8月经济：股市涨能否带动实体反弹？/assets/figure_001.jpg>)

图2左侧用上证指数月均值，对照服务业PMI的十二个月移动平均（MA12）；右侧再将该平滑PMI与服务业生产指数当月同比并列。平滑会减少短期变化，双轴又有不同量纲；图中的共振没有独立识别8月股价对当月指标的贡献。作者据此预期本轮行情支持服务业反弹，本库保留这一当时判断。

![原图2—3：上证月均、服务业PMI的MA12与生产指数同比](<../../../../../materials/wallstreetcn/SourcePost/8月经济：股市涨能否带动实体反弹？/assets/figure_002.jpg>)

从股价传到消费，需要持股家庭的资产变化被认为足够持久，且这些家庭愿意降低储蓄或兑现部分资产购买商品服务。持股分布、原有亏损、就业收入和债务负担都会改变反应。企业若通过发行融资再扩大设备和雇佣，也可增加收入与支出，但二级市场换手不会自动给发行人带来新钱。本篇没有持股家庭与消费的配对样本，也没有新增发行融资证据，服务指标改善不能独自完成这两条传导的验证。

<a id="demand"></a>
## 2. 金融活跃与商品需求放慢可以同时发生

民生称第三批国补资金7月底到位，但“两新”政策拉动进入平台期，规范调整与前期购买集中可能使后续销量增速回落；其预测8月社零稳中趋缓。补贴降低合格商品的有效购买成本，也可能让本来晚些时候的购买提前，因此需同时观察品类、时点和未获补贴的需求。

图3左侧分别为乘用车日均零售数量当月同比、汽车类商品零售额同比；右侧为洗衣机、冰箱、空调线上销售额同比。数量、金额、线上渠道及全国统计范围各异，8月高频变化不等于已经公布的全月社零结果。正文说投资者信心企稳、消费者信心滞后，所附图未给两套信心调查序列，本文保存为作者对状态的判断。

![原图4—5：乘用车及线上家电高频销售](<../../../../../materials/wallstreetcn/SourcePost/8月经济：股市涨能否带动实体反弹？/assets/figure_003.jpg>)

外需方面，作者将8月7日新关税措施与美国抢进口消退相连，预期8月出口放缓。图4左侧是中国至美集装箱船舶数量的年度日历比较，2025年8月起弱于2024年同期；它没有给每船装载或货值。右侧是对美出口金额同比与CCFI美东、美西航线运价指数同比。运价也受运力、航线和议价影响，船数与运价回落共同形成需求线索，仍不足以还原海关出口金额。关税成本由谁承担另见[跨境成本分担](../../20_mechanisms/关税的跨境成本分担.md)。

![原图6—7：中国至美船数、运价与对美出口同比](<../../../../../materials/wallstreetcn/SourcePost/8月经济：股市涨能否带动实体反弹？/assets/figure_004.jpg>)

<a id="production"></a>
## 3. 供给调整可能压住产量，基建恢复有自己的条件

民生认为稳外贸与“反内卷”同时影响企业安排：外需减弱降低扩产意愿，减量、停产及供给优化又可能短期制约工业生产。减少过剩供给可能改善售价，但订单、销量和单位利润仍须逐项观察，价格与数量不会必然同向。

图5左侧以研究者工业景气度指标与工业增加值同比对照，右侧给出制造业PMI及走势预测，作者据此判断8月生产趋缓、PMI环比下降可能性较大。右轴0—1未附模型输入、训练窗口或概率校准，本文不将曲线末值记为经核实的下跌概率；模型仅作当时机构预测的依据。

![原图8—9：工业景气及制造业PMI预测](<../../../../../materials/wallstreetcn/SourcePost/8月经济：股市涨能否带动实体反弹？/assets/figure_005.jpg>)

基建被作者列为相对有弹性的方向，理由是与私人企业需求的关联较低、天气干扰消退。图6显示7月下旬自然灾害后沥青开工率于8月回升，水泥价格在低位出现拐点。沥青开工率是特定行业的生产利用指标，水泥价格包含供给因素；它们提供施工活动可能恢复的观察，不能替代投资额、项目拨款和实物工程量。具体传导仍取决于项目、资金与施工接续。

![原图10—11：沥青开工率及水泥价格](<../../../../../materials/wallstreetcn/SourcePost/8月经济：股市涨能否带动实体反弹？/assets/figure_006.jpg>)

<a id="prices"></a>
## 4. 原料价格先企稳，怎样进入PPI

作者预期“反内卷”对工业品价格的提振快于生产修复。图7左将南华工业品指数当月同比与PPI当月同比并列，前者先反弹；右侧比较7月上旬、下旬生产资料价格的周环比。图中螺纹钢、煤炭等下旬改善，汽油与化肥则是例外，不能概括为所有上游价格同时回升。

PPI观察工业企业产品首次出售的价格，市场工业品指数的品种、交易阶段与权重有别。市场报价变化须经过实际成交、合同重定价和行业权重，才能进入出厂价格统计。国家统计局方法说明确认PPI通常在每月5日、20日采价；7月下旬变化因而可能较晚反映，但调查时点本身没有给出8月PPI必然回升的幅度。同比还取决于上年基数。上述统计与经济过程由本库补充解释，原“8月接棒回升”保持民生归属。

![原图12—13：PPI、南华工业品及原料周环比](<../../../../../materials/wallstreetcn/SourcePost/8月经济：股市涨能否带动实体反弹？/assets/figure_007.jpg>)

<a id="constraints"></a>
## 5. 就业与财政资金，决定修复能接多远

图8是16—24岁、不含在校生的劳动力调查失业率：2025年7月17.8%，高于2024年7月17.1%；2024年8月为18.8%。2025年8月向上箭头是预测，未给具体点位。作者认为若8月再超过去年高点，稳就业与需求支持更迫切；这是一项政策需求判断，并未记录一个已承诺的失业率触发规则。

![原图14：青年失业率及8月预测箭头](<../../../../../materials/wallstreetcn/SourcePost/8月经济：股市涨能否带动实体反弹？/assets/figure_008.jpg>)

图9左侧政府债发行规模包括国债、新增一般债、新增专项债和地方再融资债，单位亿元；右侧为“特殊新增专项债”发行进度，2025年8月数据截至8月25日，图示约120%。文章未交代这项特殊额度的完整分母及其调整，不能将超过100%扩成全部地方专项债法定额度已经超发。

发行总额还包含偿还旧债和滚动融资，不能直接当作新增财政需求。债券资金要经过财政拨付、项目采购和施工支付才进入工作量，账户已有资金又可能在新发债放慢时继续支持支出。[社融、信用脉冲与实体需求logic-3](../../20_mechanisms/社融结构、信用脉冲与实体需求.md#logic-3)维护这一过程。民生当时认为发行节奏放缓使财政脉冲减弱、可能约束年内基建并增加政策发力必要性；本篇图表尚未给出净融资、财政账户余额与实际支出的完整对应。

![原图15—16：政府债发行与特殊新增专项债进度](<../../../../../materials/wallstreetcn/SourcePost/8月经济：股市涨能否带动实体反弹？/assets/figure_009.jpg>)

<a id="outlook"></a>
## 6. 保留2025年8月的分支判断

| 民生截至8月27日的预判 | 对象、期限与依据 | 接续研究的观察 |
|---|---|---|
| 服务业指标反弹 | 8月；资本市场活跃先增加金融业务 | 未平滑服务业商务活动、金融业务量及其他服务行业，不能只看股指 |
| 消费和外需趋缓 | 8月社零、出口；补贴效应及抢进口减弱 | 同口径实际销售、出口与家庭收入；本轮未加入月底后结果 |
| 工业生产与制造业PMI承压，基建可能回温 | 8月；供给调整、外需和天气恢复分别作用 | 产量、订单、项目拨付与工作量，机构模型不作通用定律 |
| PPI改善，政策支持必要性增加 | 8月及随后数月；上游价格、青年就业与政府债节奏 | 出厂成交价、就业与财政用途，未给政策日期或量化承诺 |

本库2026年11月16日整理的认识是：股市活跃、金融服务增加、家庭支出及企业生产可以处在不同阶段。若后续服务指标上升集中于金融，同时商品需求和雇佣仍弱，就应保留这种分化；若收入、消费及项目支付持续扩大，才有依据讨论传播范围增加。本文没有据一组同步曲线确认全经济已经反弹。
