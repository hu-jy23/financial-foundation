# A股历史阈值与结构分化：2026年中期策略观察

2026年7月1日，华尔街见闻龙玥转述广发证券刘晨明团队6月30日中期策略：AI与其他行业的盈利和定价裂口扩大，旧的持仓、成交与行情年限阈值屡次失准。团队预计2026年下半年相对盈利继续支持AI，资金供需差则趋紧，其他行业机会需要真实业绩改善。

本页按当时的信息组织解释；图表主要截至6月18—24日，全年值另标预测。[来源记录及全部21张原图入口](../../40_sources/S-WS-3775922.md#figures)保留数据、图文差异和核读范围；[完整原文](<../../../../../materials/wallstreetcn/SourcePost/上半年的A股：哪些历史规律已经打破，哪些历史规律即将被打破？/article.md>)可恢复作者论述。

<a id="thresholds"></a>
## 旧阈值失准，先看比较基准怎样变化

行业在市场中的市值和盈利份额扩大时，同一绝对配置会代表不同程度的主动偏离。图3显示电子行业基金配置21.8%，超配幅度标为0.6倍，在约20%附近已五个季度，2025Q2至材料时点涨幅122%。旧六个案例的超配倍数均较高。因此，“配置约20%”没有在各时期对应相同的相对基准风险；0.6倍的计算式未随转载披露，保留其单位。

这也没有消除共同持仓的退出压力：若多只产品同时出售相同股票，实际买盘和交易深度仍决定兑现成本。图中食品饮料2012Q1、计算机2015Q1随后六个月超额分别+9.2%、+0.3%，本身已反驳约20%配置后必然跑输的说法。[主动权益公募基金](../../10_concepts/主动权益公募基金.md)解释持仓、交易与相对超配的区别。

![本地图3：基金配置约20%的历史对照；超配列单位为倍](<../../../../../materials/wallstreetcn/SourcePost/上半年的A股：哪些历史规律已经打破，哪些历史规律即将被打破？/assets/figure_003.png>)

成交的分母也在变化。TMT在本篇是研究所用科技、媒体与通信行业集合；其成交额占比MA5高位由早期约17%、30%、40%，到2026-06-24的45.1%。份额上升可能来自该组交易增加或其他行业交易减少，反映交易活动的集中，不能直接当作持仓资金。A股前5%股票成交占比MA20同期约49.8%，美股6月23日为72.1%；后者提示旧高点可以被突破，跨市场样本差异仍限制直接类推。

![本地图5：TMT成交额占比MA5与历轮高位](<../../../../../materials/wallstreetcn/SourcePost/上半年的A股：哪些历史规律已经打破，哪些历史规律即将被打破？/assets/figure_005.png>)

**行情年限与估值贡献也要放回具体窗口。** 图2列核心资产行情约4.5年，与原文“最长2—2.5年”不符；光模块从2023年初、宽口径AI从2024年9月起算，也不应混用。图1的最后一柱是2026H1，只支持2024、2025及2026上半年均有正向估值贡献，尚不能断言全年连续第三年提估值。

![本地图1：万得全A盈利估值拆分；末柱2026H1](<../../../../../materials/wallstreetcn/SourcePost/上半年的A股：哪些历史规律已经打破，哪些历史规律即将被打破？/assets/figure_001.png>)

指数的归母利润总额增速、单家公司每股盈利、指数回报有各自口径。单股价格可按每股盈利与估值倍数分解；指数还涉及样本、权重、股本和除数，不能直接拿利润总额同比代入。

<a id="earnings"></a>
## 盈利差给出经营依据，价格还反映未来要求

团队认为，AI投资提高现有产能利用率，而制造、设备交付和安装来不及迅速增加供给，客户争夺有限能力，推高部分环节价格与盈利。这条过程连接了需求和股价叙事。作者引用Top5云厂商2026年CAPEX预期7690亿美元、H100租价超过每小时2.8美元及Token调用增长，判断需求仍强；预算转成实际采购、调用转成付费及供应商利润，还需各自的经营证据。图16展示存储、光芯片等环节的提价与公司利润预期，[云服务](../../10_concepts/云服务与超大规模云厂商.md)与[HBM与存储芯片](../../10_concepts/HBM与存储芯片.md)提供对象基础。

与之对应，图9把全A按2026Q1财务指标分别分十组：截至6月18日，营收增速最高组平均涨40.4%，最低组跌9.6%。这显示该窗口增长与回报相关；各列样本不同，尚未分离行业、估值及信息公布的作用。

图20中，科创创业板相对沪深300的归母净利润同比增速差，2025年约6个百分点、2026Q1约36个百分点、2026全年一致预期约50个百分点；图21相对中证红利的2026全年预期差约60个百分点。全年值是当时Wind一致预期、自下而上整体法合成；“科创创业板”具体代码与合成规则未随转载提供。50/60均为利润增速差的预测，需等待后续报告检验。

![本地图20：科创创业板／沪深300相对走势及实际、预测利润增速差](<../../../../../materials/wallstreetcn/SourcePost/上半年的A股：哪些历史规律已经打破，哪些历史规律即将被打破？/assets/figure_020.png>)

![本地图21：科创创业板／中证红利相对走势及预测利润增速差](<../../../../../materials/wallstreetcn/SourcePost/上半年的A股：哪些历史规律已经打破，哪些历史规律即将被打破？/assets/figure_021.png>)

未来利润与投资者等待这些利润所要求的回报共同进入价格。无风险利率、风险补偿提高会压低给定现金流的现值；盈利预期上修可以抵消一部分影响，抵消程度取决于幅度、期限和原价已包含的增长。图12所选四段科技及一段供给侧行情中，利率上行与上涨并存，支持这种共同作用的可能性，无法证明利率没有抑制作用。[股权风险溢价ERP](../../10_concepts/股权风险溢价ERP.md)解释相关估值口径。

团队认为库存低位没有引出其期待的以往式总量刺激，外需与海外财政扩张减轻了国内加码压力，预计2026H2以托底和结构工具为主。它列银行净息差1.40%、1—5月财政支出同比−0.3%及汇率约束为理由，财政预算范围未完整披露。若海外财政或补库存动能转弱，政策反应可能改变；库存低位本身没有规定政策必然动作。

<a id="sectors"></a>
### 非AI机会，要有各自的盈利来源

**黄金与铜。** 团队认为3月冲突后相关板块跌超20%定价偏悲观：黄金有政府债务、储备选择和央行购金支持，铜则有电网、数据中心、电动车需求，矿山品位及长建设周期约束供给。图17预计2025—2040新增铜需求中能源转型50%、AI及数据中心10%，合计60%指新增需求份额；它是长期预测，无法单独解释2026年某月价格。短期应分开看需求、可供产量和风险偏好，[铜与工业金属](../../10_concepts/铜与工业金属.md)持续维护相关口径。

**储能锂电。** 作者认为基本面恢复较明确，称2026年6月锂电排产268GWh、连续第四个月新高，碳酸锂回落缓解储能成本压力。图18把预收、购建现金流、预付款与存货放在一起，提示订单资金与备货扩产的联系。预收体现已收款及履约义务，仍受价格和付款条款影响；中报及下半年应看排产能否转成出货、收入与回款，库存和新产能是否使价格再受压，且电池总体排产未全部归于储能。

**创新药。** 团队称龙头估值低、全球BD交易中国占比由50%到70%，并把地缘缓和、美债利率回落视为修复条件。BD占比的金额/数量分母未给。需要同时看许可交易兑现的首付款、里程碑或销售收益，以及要求回报变化；图19的海外生物科技指数与美债走势只提供特定历史对照。

**券商与金融IT。** 团队把高成交视为中报业绩支持。券商实际佣金还取决于费率和业务结构，利润也受自营及成本影响；金融IT收入涉及签约和验收。中报检验应看成交是否转为这些业务的盈利，而非仅确认交易活跃。作者未在转载中给出公司测算或“基准新规”细则。

<a id="flows"></a>
## 承接来自哪些参与者，款项和持仓如何移动

截至6月23日，团队估计居民产品渠道净流入约8600亿元，高于2025H2约6900亿元；图14同时显示险资+4226亿元、杠杆资金+4548亿元，宽基ETF−17493亿元、产业资本净增持−2374亿元、一级融资−3733亿元。方向并不一致，居民改善无法概括所有参与者。

![本地图14：截至6月23日的2026H1与2025H2参与者估计；亿元](<../../../../../materials/wallstreetcn/SourcePost/上半年的A股：哪些历史规律已经打破，哪些历史规律即将被打破？/assets/figure_014.png>)

**新增股票需求怎样形成。** 居民申购先把现金交给基金或资管产品，管理人随后按合同建仓，买股款付给出售股票的投资者；产品收到申购与实际买股存在时差，也可能被赎回抵销。[险资](../../10_concepts/保险资金与长期资金.md)把可投资现金从其他资产转入股票时，直接增加相应买单，其负债期限、偿付约束及估值判断决定配置规模。融资买入则由投资者提供保证金、经券商信用渠道取得购买能力；买入后增加借款和股票持仓，随后还本付息及担保约束会影响持续承接。文章未提供具体账户交易，以上解释各类来源怎样进入交易。

**哪些安排提出兑现与承接需求。** 开放式产品赎回要支付持有人现金；管理人可用同期申购、已有现金或出售资产筹款，实际出售股票时才向市场提出承接需求。ETF还多一层：[二级市场卖出份额](../../10_concepts/宽基ETF.md)由另一投资者付款接走份额；一级赎回则注销份额，授权参与者按品种安排取回证券篮子或现金，之后是否出售篮子决定相关股票卖盘。现金赎回时，基金可动用现金或卖证券兑付；这条路径与取回篮子后的出售需要分别识别。赎回金额、ETF成交、底层卖出属于不同环节。

股东出售已发行股份时，买家付款交给卖方股东，公司不因此取得新增资本；一级发行则由认购者付款、发行人取得募集资金，投资者增持新股。两者都需要承接，但收款人、股份供给和企业可用资金不同。上市公司回购又由公司付钱买回股份，改变流通供给。因而图表中的申赎、融资、持仓及发行估计须分别阅读，渠道可能交叉，统计边界也不完整，不能机械相加成一张市场现金守恒账；也无法从它识别每笔卖单最终由谁接手。

团队预计2026H2资金供需差缩窄逾1000亿元，理由是融资动能放慢、北向受美债利率约束、解禁减持和大额IPO分流，而险资可能继续配置。所谓存量博弈，表示按这些假设，新增承担股票风险的能力相对新增出售与融资需求趋紧，其他条件相近时结构轮动的竞争更强。不同参与者的证券偏好仍可使局部买盘扩大。图15的宽基ETF流出与指数高于100日均线共现，被作者解释为“控温”；数据没有最终持有人，尚未确认某个主体执行该均线规则。

<a id="tests-2026h2"></a>
## 以中报为起点，怎样检验2026H2判断

以下是本库在2026-11-16依据当时信息拟定的分支检验，沿用7月1日的信息边界，未加入后来结果。

中报及随后财报先检验经营：AI订单、交付、提价和利用率是否转成利润与现金回收，全年一致预期是否上修或下修；同时看非AI改善是局部还是扩散。若非AI改善而AI仍兑现，盈利差也可能收窄；若AI订单或供给约束转弱，原预测的上沿本身就需修订。储能的预收与实际出货、券商成交与收入利润，应分别对应自身业务过程。

价格的检验还要独立比较当时已包含的增长和要求回报。盈利兑现但股价不强，可能涉及此前预期更高、风险补偿上升或退出成本变化；需要新增证据区分，不能用已实现盈利一项包办解释。2026H2另以产品净申赎、险资实际增配、融资余额及还款、ETF份额与篮子交易、减持和发行节奏检验承接假设。成交缩量或市值变化本身不给出净撤资数。海外财政与补库存变化则用于检验国内政策分支，保持与企业盈利、市场承接各自的因果环节。
