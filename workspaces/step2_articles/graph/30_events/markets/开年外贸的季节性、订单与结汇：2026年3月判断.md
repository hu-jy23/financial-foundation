# 开年外贸的季节性、订单与结汇：2026年3月判断

2026年3月10日，华尔街见闻李佳转载国联民生陶川团队的分析：1—2月出口强于预想，春节时点只能解释其中一部分，全球制造业回暖、目的地开拓与退税调整前置出货还可能提供支持。团队进而预期高贸易顺差延续，支持经济和人民币。本文保存当时论证及六张原图；2026-11-16为整理日，未加入3月10日以后实现结果。[来源与核读范围](../../40_sources/S-WS-3767144.md)。

<a id="measurement"></a>
## 金额增长很快，先确定比较单位和期间

文章使用1—2月出口同比21.8%。[商务部当日统计摘要](https://data.mofcom.gov.cn/article/zxtj/202603/64407.html)列人民币出口4.62万亿元、增长19.2%，进口3.11万亿元、增长17.1%，进出口7.73万亿元、增长18.3%。21.8%沿文章及美元表检索口径保存，完整美元表正文本轮未取得；不能与19.2%相减就称实际货物数量多增2.6个百分点。换算币种及汇率会改变名义金额同比，数量、单价和产品组合也会改变它。

图1左为历年1—2月累计同比，2026高于大多数所列年份而低于2018、2021；均值线不是预期调查。右图并列中国、韩国、越南出口月度同比，月度与中国累计窗口需要分开。“超预期”是团队评价，材料未附统一市场预测样本。

![原图1](<../../../../../materials/wallstreetcn/SourcePost/开年外贸：闪耀的非常信号/assets/figure_001.jpg>)

<a id="calendar"></a>
## 春节较晚，可以搬动交付，尚不能分解全年增量

作者认为春节前企业集中交货，春节靠后时较多订单进入前两个月，3月相对承压。提前安排生产、报关和发运，可以改变统计月份，未必增加全年最终订单。1—2月合并有助减少单月错位，但并不自动消除工作日、节前备货和上年基数影响。

图3/4横轴均为当年除夕距1月31日的天数，虚线分别呈正、负方向；样本年份、拟合方法与误差未披露。原图4外标题写拖累3月，纵轴却仍写“1—2月累计出口同比”，不能自行指定应修哪一处，更不能把它当作已量化的3月预测模型。正文称春节晚近20天，图横轴本身不提供两年的具体日期，本轮未另核日历。

![原图2](<../../../../../materials/wallstreetcn/SourcePost/开年外贸：闪耀的非常信号/assets/figure_002.jpg>)

<a id="orders"></a>
## 制造业改善、市场开拓与提前出货，需要分别取证

全球制造业PMI由2025年12月50.4、2026年1月50.9升至2月51.9。表中美国52.4、欧元区50.8、日本53.0、韩国51.1等处于50以上，中国49.0、瑞士47.4、墨西哥47.1等仍低于50，不能概括全部经济体同时扩张。PMI是企业增减判断的扩散统计，未测量资本开支金额；设备投资复苏若转为中国企业订单，还要看资本品采购、交付与客户用途。作者把两者相连，属于当时需求解释，本轮未重建其贡献。

![原图3](<../../../../../materials/wallstreetcn/SourcePost/开年外贸：闪耀的非常信号/assets/figure_003.jpg>)

地区表2026/2列全球21.8%、非洲49.9%、欧盟27.8%、东盟29.4%、香港38.7%，美国−11.0%。该列与正文1—2月累计口径衔接，表中2025年各列又为月度值，不能把两者相减成同长度加速。非洲增速最高，并不保证它对总出口新增额贡献最大：贡献还取决于基期份额，表中没有提供金额权重。地区分类也有嵌套，欧盟与德国、非洲与南非不可重复相加。

东盟或香港作为申报目的地，不等于已证明全部货物经其转口，更未识别最终消费地。区分订单新开拓、转口和贸易改道，需要同货物后续流向。文章将它们作为区域开拓线索，本篇保存这种解释及美国仍负增长的差异。

![原图4](<../../../../../materials/wallstreetcn/SourcePost/开年外贸：闪耀的非常信号/assets/figure_004.jpg>)

光伏退税变化提供另一个前置交货的动机。[财政部、税务总局2026年第2号公告](https://szs.mof.gov.cn/zhengcefabu/202601/t20260109_3981637.htm)1月8日署、1月9日发布，规定4月1日起取消光伏等清单产品增值税出口退税；电池清单产品则4—12月由9%降至6%，2027年起取消，适用税率按报关单出口日期界定。取消增值税退税也不等于同时取消所有消费税退免安排。企业有动机把可交付订单提前到切换日前，但实际效应取决于产品清单、客户承接和产能。

图7列集成电路、汽车含底盘、船舶、陶瓷、塑料制品等出口金额同比。高同比也可能来自单价、产品结构、基数和其他订单变化。本轮未读附件逐项税号，不能把整车、塑料和玻璃的全部出口都认作政策覆盖或由抢出口解释；同比很高也没有给出对总量贡献。若只是发运前置，切换后可能回落，持续新订单才支持更长期增长。

<a id="imports"></a>
## 进口数量增加与内需修复，并非同一个命题

进口金额增速靠前的有自动数据处理设备及零部件、肥料、食用植物油、集成电路等。图9比较部分资源品进口价格与数量的累计同比变化，原注写“2026年2月−2015年12月”，正文却说相对去年。本轮保留这个年份差异，未擅改为2025，也未用它复算逐商品量价分解。量增和价格贡献变化不等于同一商品进口金额必然同比增长。

进口数量增加可以来自居民最终消费、制造业投入、补库存或为未来加工出口备料。企业也可能趁价格或供应条件有利时提前采购。作者以资源数量改善判断内需回温，仍需把用途、库存和实际生产接起来；科技设备进口不能单独证明全部消费和投资同步恢复。

<a id="fx"></a>
## 顺差如何连接人民币，作者预期应怎样更新

货物出口额减进口额得到相应统计口径的贸易余额，经常账户还包括服务、初次及二次收入，不能直接以海关货物顺差替代。统计交货、合同收款与银行结汇又有不同时间：出口商可以保留外币、偿还外币债或支付进口，结汇才直接形成相应外币出售需求。[人民币页](../../10_concepts/人民币与离岸人民币.md#trade-20260310)保存这条历史入口；[贸易收支调整](../../20_mechanisms/汇率贬值后的贸易收支调整.md)解释计价、数量与合同时间的区别。

**团队截至3月10日的展望：** 出口强于进口，高顺差将延续，为“十五五”开局增长及人民币升值提供支撑，未给全年出口增速、目标汇率或发生概率。出口与进口增长率的大小本身也不足以确定未来顺差金额，需要基期金额和后续路径；经济增长贡献还须转为国民账户的实际净出口口径。

**本库11月16日按该历史信息整理的条件解释：** 后续若非洲等市场订单持续、设备需求扩大且企业将新增收款结汇，贸易支持汇率的路径更充分；若主要是退税与节日交付前置、进口加快或资金继续留在外币账户，人民币反应可能不同。资本流动、相对利率和政策条件也会同时改变汇率。本轮未用后来汇率或外贸结果追认其成败。
