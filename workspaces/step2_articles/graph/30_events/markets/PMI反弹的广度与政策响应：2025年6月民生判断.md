# PMI反弹的广度与政策响应：2025年6月民生判断

2025年6月30日，民生证券陶川、钟渝梅借《PMI稳住了吗？》追问：贸易风险缓释后，产需恢复是否足以带动更广修复？其判断是用工、小企业与价格仍弱，下半年需要货币和财政增量支持。[来源记录](../../40_sources/S-WS-3750088.md)保留华尔街见闻转载、全部原图和核读范围；以下不加入6月底之后的实际结果。

<a id="reading"></a>
## 1. 产需在恢复，修复尚未扩散

制造业PMI从4月49.0升至5月49.5、6月49.7：连续两月回升，同时连续三月低于50。6月生产51.0、新订单50.2均有改善，用工47.9和原材料库存48.0仍弱，因而生产、订单越过50并未使五项合成总指数同步越线。[PMI基础页](../../10_concepts/PMI与景气调查.md#composition)保存权重、配送逆向和49.66算例。

![六月PMI原图001](<../../../../../materials/wallstreetcn/SourcePost/PMI稳住了吗？/assets/figure_001.png>)

<a id="dispersion"></a>
新出口订单由47.5升至47.7，恢复有限；用工由48.1降至47.9，生产经营活动预期由52.5降至52.0。企业可以先用现有设备完成恢复的订单，仍因未来税率与销售不确定，延后招聘和新增投入。民生据此担忧外需扰动继续传向内需；这条解释还需要企业订单、用工和投资的后续表现支持。

规模差异加强了这一判断：大、中、小企业PMI分别为51.2、48.6、47.3，月差+0.5、+1.1、−2.0点，小型企业实际在走弱。购进价格48.4、出厂价格46.2虽各回升1.5点，仍低于50，作者因而认为PPI明显改善仍有压力。两价格指数是调查广度；售价、成本和销量怎样共同作用于利润，要结合具体行业。

![六月PMI原图005](<../../../../../materials/wallstreetcn/SourcePost/PMI稳住了吗？/assets/figure_005.jpg>)

<a id="calendar"></a>
## 2. 外部缓释能解释反弹，尚未回答其持续性

作者用各年6月的工作日月差与PMI月差比较，将2025年约多1天、升0.2点视为符合历史趋势。官方序列已季调，残余日历影响仍需识别；位于历史拟合线附近，也不能代替对市场事前预测的比较。因而这张图提供日历线索，未证明全部回升由工作日造成或数据没有超出市场预期。

![六月PMI原图002](<../../../../../materials/wallstreetcn/SourcePost/PMI稳住了吗？/assets/figure_002.jpg>)

<a id="external"></a>
贸易不确定性指数回落、部分海外调查改善，构成民生的另一依据。中国6月升0.2点，低于图中约0.3点的跨国平均虚线；法国反降2.0点，是“均回升或维稳”图题的例外。不同调查范围也限制了直接比较强弱。

![六月PMI原图003](<../../../../../materials/wallstreetcn/SourcePost/PMI稳住了吗？/assets/figure_003.jpg>)

作者还援引2018—2019年关税与PMI分项的拟合，认为用工和经营预期可能承受更久影响。那段历史同时包含其他需求和政策变化，不能直接把系数移作2025因果效果；[完整系数表与原图5](../../40_sources/S-WS-3750088.md#tariff-fit)留在来源。企业是否敢把短期订单转成招聘与投资，是这段比较留下的实际问题；[关税成本分担](../../20_mechanisms/关税的跨境成本分担.md)解释税负如何经售价、毛利和订单分配。

<a id="policy"></a>
## 3. 作者期待政策回应，资金和支出各有执行环节

民生认为制造业连续至少三月低于50后，资金面往往趋松，有时伴随总量政策调整。原图8同时画DR007月均和7天OMO操作利率：[DR007](../../10_concepts/DR007、R007与同业存单.md#pmi-202506)是成交价格，OMO是操作定价。弱信贷需求和央行投放都可能使资金趋松，缴税、政府债缴款又会扰动市场利率；历史同向并非自动降息规则。

![六月PMI原图006](<../../../../../materials/wallstreetcn/SourcePost/PMI稳住了吗？/assets/figure_006.jpg>)

财政判断是新增专项债更易提速。原图9红线表示累计发行进度偏离历史均值，末端仍落后；它没有表示同额资金已经支出。债券募集后还要经拨款、采购和施工支付，才能支持需求，具体过程见[社融结构logic-3](../../20_mechanisms/社融结构、信用脉冲与实体需求.md#logic-3)。

![六月PMI原图007](<../../../../../materials/wallstreetcn/SourcePost/PMI稳住了吗？/assets/figure_007.jpg>)

<a id="services"></a>
建筑业商务活动升1.8点至52.8，服务业降0.1点至50.1，后者仍略在扩张侧。作者结合其所述发改委项目审批高位，期待基建改善；本组图没有审批项目表，审批到实际施工仍需资金和开工条件。图10/11的灰区为2013—2019年历史范围，供比较当时恢复程度。

![六月PMI原图008](<../../../../../materials/wallstreetcn/SourcePost/PMI稳住了吗？/assets/figure_008.jpg>)

<a id="expectations"></a>
## 4. 在随后一至三次发布中，分别检验修复与政策

**民生截至2025-06-30的下半年判断**：贸易风险阶段缓释有利产需，但小企业、用工、预期和价格使修复基础仍弱，增量货币宽松、专项债和基建支持的必要性上升。原文未给政策日期、幅度或分支概率。

**本库于2026-11-16依当时信息整理的检验思路**，以随后2025年7—9月一至三次月度发布及相应政策窗口为观察范围：

- **反弹是否扩散。** 若订单继续改善，随后用工、经营预期和小企业也回升，支持企业开始将短期生产恢复转为较持续安排；若订单与生产上升而这些分项继续弱，反弹仍可能依赖短单或既有产能，难据总指数确认广泛修复。价格与行业数据再帮助区分销量、库存和盈利变化。
- **支持预期是否落地。** DR007相对OMO回落只说明市场资金条件改善；操作利率实际调整或投放变化，才提供政策行动证据。专项债进度回升说明融资推进，资金使用和项目支付改善才进一步支持财政传到需求。两者应分开核对，也不把政策发生自动归因于PMI连续收缩。

这里保存观察窗口与判断条件，没有补写后来事实。[八月民生预判](股市升温与实体分化：2025年8月民生宏观预判.md)是可接续的另一时点，须按其信息日比较。
