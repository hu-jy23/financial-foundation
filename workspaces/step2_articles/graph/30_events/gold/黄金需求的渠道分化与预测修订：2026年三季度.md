# 黄金需求的渠道分化与预测修订：2026年三季度

2026年11月3日，华尔街见闻张雅琦根据世界黄金协会（WGC）三季度报告，讨论同一黄金市场内几种相反变化：ETF重新净流入，央行购买加快，金条金币和金饰吨量却下降。WGC因此下调投资需求增量预期，同时上调官方部门展望。文章要解释的变化是需求组成及预期修订，不能用“黄金买盘强／弱”一句话合并。

本篇保留原文8图及主要地区数字；本库于11月16日定向核读同日WGC网页，补定义与版本比较，没有加入11月3日后结果。[来源与核读范围](../../40_sources/S-WS-3785076.md) · [本地原文](<../../../../../materials/wallstreetcn/SourcePost/世界黄金协会：下调全年黄金投资需求增长预期至200吨，全球央行购金提速、ETF持仓创新高/article.md>)。

<a id="headline"></a>
## 总量接近去年，投资预期为何下修

转载称三季度含场外总需求约1369吨、同比下降1%。原图1比较的是**各年前三季度累计**数量与美元价值；它不能直接当作单季1369吨的图。图中数量接近2025同期，金额却更高，反映重量与计价金额是两层观察。

![原文图001](<../../../../../materials/wallstreetcn/SourcePost/世界黄金协会：下调全年黄金投资需求增长预期至200吨，全球央行购金提速、ETF持仓创新高/assets/figure_001.png>)

原文把金价自1月5595美元高点回落约29%，与伊朗战争、油价和加息预期相连，属于文章的市场背景与归因。本轮没有复算当时实时价格；WGC摘要给出的三季度LBMA PM均价约4262美元／盎司、环比降5%、同比高23%，则是季度均价的比较。离历史高点回落与比上年仍贵能够并存，不能把29%直接用作季度回报。

WGC将2026年投资需求**含场外的年度同比吨数增量**由约+400降至+200。图2纵轴是“同比吨数变化”，不是全年投资总量；黑线区间没有附概率定义。原因是金条金币放慢，抵消ETF表现超预期的部分改善。央行、首饰及供应的点位也都是相对上年的变化，不能拿它们当各类别年度水平。

![原文图002](<../../../../../materials/wallstreetcn/SourcePost/世界黄金协会：下调全年黄金投资需求增长预期至200吨，全球央行购金提速、ETF持仓创新高/assets/figure_002.png>)

<a id="official"></a>
## 官方买盘：估计总量、披露主体与价格反应

三季度央行及其他官方机构净购买约321吨，同比增42%、环比增8%；前三季度约675吨、同比增6%。图3各年按季度堆叠，2026仅有前三季。较长配置期限支持持续购买，但季度规模仍可随价格、预算和执行节奏变化。

![原文图003](<../../../../../materials/wallstreetcn/SourcePost/世界黄金协会：下调全年黄金投资需求增长预期至200吨，全球央行购金提速、ETF持仓创新高/assets/figure_003.png>)

原文列已披露买家：中国63吨、波兰40吨，合计约占已披露净购买86%；哈萨克斯坦与乌兹别克斯坦各14吨，俄罗斯净减19吨。WGC央行章区分了约120吨已报告与321吨总估计，未披露部分约占63%，并说明数据提取至10月30日、迟报可引发修订。不能据前两国份额把未知购买也分给它们。图4是截至9月30日可得的**年初至今**地区购买，且只覆盖至少0.5吨的国家变化，不能替代这组季度排名。

![原文图004](<../../../../../materials/wallstreetcn/SourcePost/世界黄金协会：下调全年黄金投资需求增长预期至200吨，全球央行购金提速、ETF持仓创新高/assets/figure_004.png>)

Reade将金价回落解释为部分央行增加购买的机会，并提出：若管理者长期看空美元、短期美元债到期，可以用较强美元换取黄金。这需要实际到期现金、配置目标及可执行的交易，不等于所有央行因同一动机追买。[央行购金机制](../../20_mechanisms/央行购金与黄金需求结构.md#logic-1)展开目标与价格约束。

图5用2022Q3—2026Q3的季度数据，将央行购买量及购买变化与LBMA PM**季度平均价**回报比较，标示相关系数−0.7、−0.6。它支持研究价格敏感性，无法独立排除配置目标及统计估计的影响，也没有给出购买托底价。季度均价变化与季度末持仓收益并非相同口径。

![原文图005](<../../../../../materials/wallstreetcn/SourcePost/世界黄金协会：下调全年黄金投资需求增长预期至200吨，全球央行购金提速、ETF持仓创新高/assets/figure_005.png>)

<a id="private"></a>
## ETF回流与金条走弱：先分渠道，再问买家

三季度全球实物黄金ETF净流入211吨，季度末持仓4256吨；新闻称净流入金额约310亿美元。一个是期间新增持有，一个是期末存量，一个是资金金额，不能相加。它们也不等于基金二级市场的全部成交，更不能把全球量归到[GLD](../../10_concepts/SPDR黄金信托GLD.md)一家产品。基金持有人包括不同身份，ETF渠道本身未测出全部机构的配置。

欧洲净流入92吨，其中英国53、法国16、德国13、瑞士9吨；北美81吨，亚洲34吨、中国为区域主力。同日WGC另列其他地区约3吨，主要来自澳大利亚，另有南非贡献。四区取整后约210吨，与全球约211吨之间仍有小幅取整差异。图6展示季度需求与均价，本季211吨较上年同期225.7吨仍少约6%：环比扭转净流出、同比减少和期末持仓创高可以同时成立。WGC把财政可持续性、通胀与债券市场担忧解释为支持因素，认为它们部分抵消更高收益率、较强美元的不利作用；本轮没有持有人级数据来分离贡献。

![原文图006](<../../../../../materials/wallstreetcn/SourcePost/世界黄金协会：下调全年黄金投资需求增长预期至200吨，全球央行购金提速、ETF持仓创新高/assets/figure_006.png>)

原文与WGC把全球金条金币走弱归于三项因素：价格在区间内反复、缺乏明确趋势；美国利率可能更久处于高位；股市上涨分流资金。据此展开，依赖价格继续上涨的新买家可能先等待，较高的有息回报又提高持有黄金的机会成本，股票机会则提供另一种资金用途。与此同时，担心财政、通胀或主权债波动的持有人可能更看重黄金在特定风险下的分散作用，愿意承担部分持有成本，以ETF取得和调整黄金敞口。这些用途也可在同一渠道内并存。通用过程见[黄金的机会成本机制logic-3](../../20_mechanisms/黄金的机会成本机制.md#logic-3)。

金条金币净投资同比下降19%至268吨、为近四年季度低位，前三季累计1053吨却仍为2013年以来同期最高。中国当季79吨、增7%，累计393吨创新高；同日WGC把其相对强势联系到本地股市走弱、国债收益率下降，以及价格回落时的买入。本地替代回报不同，全球股市上涨和美国利率高位因而不能概括所有买家的选择。印度55吨、降40%，约贡献全球同比降量的60%，文章以节日错位和数字黄金分流解释。美国8吨、降40%；欧洲20吨、降31%；伊朗降51%，部分居民为生活与迁居出售。全球季度走弱、年内累计强及个别市场继续增持，使用不同期间和范围，不能互相抵销为一句结论。

<a id="jewellery"></a>
## 金饰：买得更少，花费仍增加

三季度全球金饰消费313吨、同比降17%，低于2020年同期331吨；支出却增2%至430亿美元，年内接近1300亿美元、增15%。高价压缩预算可买的重量，产品克重、纯度与组合变化也会改变金额／吨比，金额增长不能直接确证同一款首饰提价多少。

中国66吨、同比降22%，累计202吨、降27%；印度100吨、降20%，文章称当地金价同比涨45%、部分节庆需求后移。美国21吨、降18%，欧洲不含独联体11吨、降11%，中东26吨、降22%，越南降39%。这些是消费地区与本地购买条件，不与全球美元均价强行合并。

![原文图007](<../../../../../materials/wallstreetcn/SourcePost/世界黄金协会：下调全年黄金投资需求增长预期至200吨，全球央行购金提速、ETF持仓创新高/assets/figure_007.png>)

需求表加总使用金饰**加工**，而新闻上述313吨是终端消费。同日WGC表1为加工340.1、消费312.9、库存增加27.2吨；库存是两者的桥接项，不能把消费再与加工重复相加。[黄金的统计分类](../../10_concepts/黄金.md)提供通用解释。

<a id="supply"></a>
## 矿产创新高，为什么总供应仍略降

新闻列三季度矿产1071吨、同比增3%，回收314吨、降8%，净套保收缩后总供应1369吨、降1%。同日WGC表1可核对：`1070.9 + 314.5 − 16.8 = 1368.6吨`。净套保项反映生产商套保及解除套保对当期供应的增减，不能等同当期开采量；负值也没有表示负产量。图8虽然写季度产量，却按各年前三季堆叠，整柱不能读成该年第三季。

![原文图008](<../../../../../materials/wallstreetcn/SourcePost/世界黄金协会：下调全年黄金投资需求增长预期至200吨，全球央行购金提速、ETF持仓创新高/assets/figure_008.png>)

原文报加拿大、印尼、智利产量分别增22%、21%、19%，由新矿与品位等支持；纳米比亚、土耳其和澳洲则减产。矿山响应需要建设与采掘安排，回收取决于持有人出售意愿。新闻以季度均价下降5%解释回收较弱，并称尚无广泛困境出售；伊朗等局部出售并不构成全球已普遍变现。供需含OTC及其他后相等还有统计残差安排，不能把等量本身视为独立测出的短缺或宽松程度。

<a id="revisions"></a>
## 保存修订：新的判断接在旧判断之后

7月30日旧页记录WGC预计全年官方购买低于2025；11月3日因三季度强及二季度上修，改为至少追平，新闻用2025年848吨作为参照。同日WGC摘要二季度官方需求为296.3吨，旧7月版本为288.9吨。较早估计继续保存，跨季度比较用同版序列。

旧机制在2026年1月29日年度章采用2025年863.3吨，与本次新闻848吨存在版本差异。本轮当前全年XLSX下载403，未独立提取完整2025年表，不能据此确定差额来自哪个国家、时期或重分类。[来源登记](../../40_sources/S-WS-3785076.md)保留两处版本；也未用当前数据抹去旧预测的当时基准。

截至11月3日，WGC仍预计投资为全年需求增长主力，但同比增量降至约200吨；央行全年至少持平，金饰四季度继续承压；矿产可能全年创新高，回收偏弱使总供应略降。它们都属于机构的条件展望。

<a id="q4-checks"></a>
### 用四季度及全年报告区分解释

**本库于2026-11-16依据11月3日信息提出以下检验，尚未加入后来结果：**

- **印度需求是跨季后移，还是受到持续约束？** 在2026年四季度及全年报告发布时，分开读取金条金币与金饰，并对齐两年节庆日期比较三、四季度合计。若节庆之后恢复、两季合计缺口明显缩小，较支持需求时点后移；若金条金币仍弱而数字黄金渠道增加，较支持投资渠道替代；若金条金币和金饰都仍偏弱，本地金价及克重选择又继续显示预算约束，则购买力限制的解释更强。价格、节庆和渠道可以共同作用，单看四季度从低位反弹不足以分离原因。
- **官方全年至少持平，靠什么实现？** 待四季度及全年同版数据公布，先分开第四季净购买、前三季估计修订和2025基准修订，再比较同版两年全年总量。较强的第四季新购买支持需求延续；如果全年达标主要依赖旧季度上修或基准改变，应分别修正对新增购买和原数量预期的认识。新闻848吨基数及旧版863.3吨继续保留，不把两版直接拼接，也不据前三季差额替WGC设定季度购买目标。

本轮没有补造全年目标金价或上述检验的实现结果。
