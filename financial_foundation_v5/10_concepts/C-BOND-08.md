# 浮息债FRN

> 执笔：`/root/full_b016`，GPT-6-Astra，medium。制作日2026-10-28；实际拍卖样本截至2025-03-26。美国财政部动态制度页于制作日核读，旧版term sheet与ARRC文件保留版本边界，不作为2026年市场报价。

## 概念定义

浮息债（Floating Rate Note，FRN）是票息按合同指定基准及规则定期变化的债券。常见普通结构把基准利率与固定合同利差相加，按应计期间计算利息；本金偿还仍按债券合同到期安排进行。票息重置减少了投资者被长期固定在旧市场利率上的程度，但不会自动清除发行人信用、市场要求利差、交易流动性或支付时点风险。[S-C-BOND-08-01](#S-C-BOND-08-01)、[S-C-BOND-08-03](#S-C-BOND-08-03)

本页先解释通用的重置逻辑，再以美国财政部两年期FRN作可核验实例。财政部FRN按13周国库券拍卖结果确定基准；公司或其他发行人的SOFR挂钩债券可以采用不同观察期、复利与付息规则。“浮息”不是一种统一的信用等级，也不是所有产品共用一套计息方法。

## 概念详解

### 基准、合同利差与市场要求利差是三个量

普通单利、期初定息结构可以简写为：

\[
c_i=L_i+s_c,\qquad I_i=N\alpha_i c_i.
\]

\(L_i\)是按合同观察并用于第\(i\)期的年化基准利率，\(s_c\)为合同约定的年化利差，\(N\)是计息本金，\(\alpha_i\)为日计数规则决定的年化期间长度，\(I_i\)是该期利息金额。利率均以小数代入；若合同有利率下限、上限、复利或特殊重置条件，需要先按合同修改公式。

**假设算例：** 本金100万元、基准4%、固定利差0.8%、实际90天按actual/360计息，一期利息为12,000元。下一期基准降至3%，在其余条件不变时利息降至9,500元。票息跟随基准下降，是合同正常运作；它既不是发行人违约，也不是上一期利息被追回。

市场要求利差\(s_m\)则是投资者今天愿意持有这只债券所要求的补偿，可以随信用、流动性、供求和剩余期限改变。合同仍支付\(L+s_c\)，市场却可能要求\(L+s_m\)。当\(s_m>s_c\)，未来票息相对不足，债券通常必须降价；当\(s_m<s_c\)，它可能溢价交易。重置的是基准部分，不是每期重新替发行人谈一遍信用利差。

这也解释了贴现利差（discount margin）的作用：在指定未来基准与贴现约定下，寻找一个利差，使预期票息及本金现值等于市场价格。它是价格换算量，须与固定合同spread分开。美国财政部新发FRN拍卖中两者可以相同，续发时就能不同，后文保留了同一CUSIP的真实例子。[S-C-BOND-08-02](#S-C-BOND-08-02)、[S-C-BOND-08-05](#S-C-BOND-08-05)

### 四种时间不能混在一起

| 时间或规则 | 对现金流的意义 |
|---|---|
| 基准观察时间 | 使用哪一天或哪一段时间的利率；观察可能落在计息期之前，也可能主要位于期内。 |
| 重置频率 | 合同多久更新适用利率；不等于多久实际收到现金。 |
| 应计期间与日计数 | 每天或每期累积多少利息，actual/360与actual/365等分母会改变金额。 |
| 付息日期与支付准备安排 | 累积利息何时支付，是否有锁定、观察回溯或支付延迟，以便提前确定款项。 |

期初定息的三个月基准，可以在季度开始时确定当季利息；采用期内隔夜SOFR复利的结构，则要随着每天的观察形成全期利率，通常接近期末才知道最终金额。ARRC的2020年附录表3对term rate、compounded in arrears、compounded in advance逐项比较：事后复利用本期利率，事前复利用前一观察期。它们虽然都可以称浮息债，降息刚发生时的票息反应却不同。[S-C-BOND-08-03](#S-C-BOND-08-03)

本页不把某一种锁定期泛化到所有FRN。基准停止发布时，合同的fallback（替代基准条款）还决定谁选择替代利率、是否加入调整差额、何时触发。ARRC文件明确区分基准替代调整与原合同信用利差：前者用于处理旧新基准差异，后者原本就是借款人融资定价的一部分。看到“SOFR加一个利差”，需要辨认有没有同时包含这两项。

### 美国财政部FRN：逐日累积，通常按周改变基准，季度付款

财政部产品页列明，两年期FRN每三个月付息，基准联系最近一次13周国库券拍卖的最高获接受贴现率，固定spread由首次拍卖确定并贯穿存续期。由于13周券通常每周拍卖，基准通常每周更新。[S-C-BOND-08-01](#S-C-BOND-08-01)

技术条款进一步说明，拍卖high rate需转换为actual/360口径的简单货币市场收益率后，才作为计息index；不能直接把贴现报价当成同口径的收益率。日利息按本金乘以当日适用的\((index+spread)/360\)计算，总日应计率下限为零。term sheet写“daily reset”，指每日依据适用规则确定日利率，并非每天都有一次新的13周券拍卖；产品页“weekly reset”描述通常更换基准结果的节奏，二者解释层次不同。[S-C-BOND-08-02](#S-C-BOND-08-02)

该条款还设有发行结算或付息日前两个营业日的lock-out：为确定结算金额或当期利息，忽略在锁定期内本应生效的新13周券拍卖利率，暂用锁定开始前适用结果。旧版FAQ说明，相关变化在锁定期结束后的首个日历日生效。因而付息日前某次市场变动，不必立刻改变本次已经锁定的应付利息。

这个产品的基准不是联邦基金目标利率，也不是SOFR。[政策利率](../10_concepts/C-IR-POLICY_policy_rate_target_range.md)会影响短端利率环境，但国库券供求和拍卖结果仍会影响FRN指数。拿“政策利率下降25bp”直接当作每只FRN当日票息准确下降25bp，会跳过基准、观察和锁定规则。

### 为什么低利率久期不等于价格永远100

在无违约、无上限下限、可按同一基准融资与投资、且合同利差正好等于市场所需利差的理想条件下，重置后的未来支付会重新接近市场条件，所以普通FRN的净价倾向于接近本金。这个直觉解释了它为何通常比同到期固定利率债对基准平移不敏感。

现实偏离来自几处。第一，距离下一次有效重置还有时间，已确定票息仍有短期利率风险。第二，市场要求利差能变，而合同spread不跟着变，价格会承担差额。第三，有cap时基准继续上升也不能无限提高票息，产品会在该区域变得更像固定利率债。第四，公司发行人付息成本随基准提高，其信用状况反而可能承压。财政部FRN没有公司个体信用问题，但仍有市场利差和卖出价格变化。

**本库近似算例：** 对剩余期限约两年、市场利差敏感度假设为1.8年的普通FRN，市场要求利差突然增加50bp，而基准路径不变，则一阶价格变化约为\(-1.8\times0.005=-0.9\%\)。这里的1.8年是显式假设的利差久期，不是声称其基准利率久期等于1.8年。由于两个风险方向不同，“每周浮息”不能推出“所有风险都只有一周”。

## 观测与相近对象

研究FRN至少保存发行人、CUSIP或其他证券代码、原始及剩余期限、基准名称、固定spread、计息日数、重置与支付规则、上限下限、替代基准、净价、应计利息及市场discount margin。净价加应计利息才对应通常的结算支出；在付息期中以高于100的全价成交，不必意味着债券净价溢价。

| 相近对象 | 差异 |
|---|---|
| 固定利率短债 | 短到期本身降低久期；FRN可以有较长本金期限，但较短的利率更新间隔。 |
| 滚动持有国库券 | 每次到期都要重新安排本金投资；FRN在合同到期以前保留本金期限，票息仍随短端改变。 |
| 通胀保值债 | 与物价指数联系；FRN主要与名义利率基准联系，不直接保证购买力。 |
| [高收益债](../10_concepts/C-BOND-06.md) | 信用等级与浮息方式是两条维度；不能把浮息债基金中公司信用风险等同于财政部FRN风险。 |
| 浮息债基金或ETF | 持有人拥有的是组合份额，费用、持仓变动、信用构成与份额价格均可能改变回报，不能只读取其中一只国债的spread。 |

## 本对象的历史与带归属判断

### 2013年的发行目标与2014年的实际推出

财政部在2013年7月31日公布配套拍卖规则时，说明FRN用于扩展投资者基础、管理债务到期结构，并力求长期最低融资成本。当时FAQ预计首场拍卖于2014年1月举行；这是发行前的机构计划。[S-C-BOND-08-02](#S-C-BOND-08-02)

**后来结果：** 财政部历史页记载，首场拍卖于2014-01-29举行、1月31日发行，募集150亿美元，投标超过850亿美元，投标覆盖倍数5.67。历史页所谓2013年“introduced”与2014年首次实际发行，应分别理解为制度推出与证券发行，不能压成一个日期。[S-C-BOND-08-04](#S-C-BOND-08-04)

对发行人而言，FRN延长的是本金到期时间，并未同时锁定两年的融资利率。财政部当时就指出，每周改变票息所承担的利率风险类似连续发行短票据。由此，政府减少短期本金滚动需求与保留短期利率暴露可以同时成立；“平均到期期限变长”不能单独表示财政付息对加息更不敏感。

### 基准转换把合同细节推到前台

ARRC于2019年发布FRN替代基准建议，2020年材料继续解释SOFR各种计息结构。其当时问题意识是：原本为短暂技术故障设计的LIBOR缺失处理条款，可能不足以处理永久停止发布；含糊条款可导致现金流与定价不确定。此处记录的是当时工作组提出的合同处理思路，不把2020文件对未来基准与市场惯例的预期当作后来已全面实施的统一规则。[S-C-BOND-08-03](#S-C-BOND-08-03)

### 2025年同一证券的首次与续发拍卖：固定spread，变化的是定价

财政部拍卖结果对CUSIP **91282CMJ7、AX-2027**给出可直接比较的两次记录：

| 拍卖日期 | 2025-01-28首次 | 2025-03-26续发 |
|---|---:|---:|
| 发行／结算日 | 2025-01-31 | 2025-03-28 |
| 到期日 | 2027-01-31 | 2027-01-31 |
| 固定spread | 0.098%（9.8bp） | 0.098%（9.8bp） |
| 最高获接受discount margin | 0.098% | 0.105%（10.5bp） |
| 每100本金净价 | 100.000000 | 99.984794 |
| 每100本金应计利息 | 无 | 0.677045512美元 |

这些是已发生拍卖的实际结果。[S-C-BOND-08-05](#S-C-BOND-08-05) 3月续发并未把持有人的合同spread从9.8bp提高到10.5bp；市场要求利差更高，通过略低于面值的净价体现。仅按结果表两项相加，每100本金的价格加应计利息为100.661839512美元，实际结算按适用舍入规则处理。该差额中的应计部分是补偿已累积利息，不是新增的高票息承诺。

原表另列1月27日Index Determination Rate为4.195%、3月24日为4.190%。此项应与条款中的high rate转换规则一起读取，本页不直接把它加spread宣布为整个两年期的锁定收益率，更不把两次投标结果推断成未来降息概率。

**本库条件推演，整理于2026-10-28：** 对上述合同，若未来13周券基准下降且spread不变，未来应计利息会按重置规则下降；若市场discount margin继续高于9.8bp，净价仍可能低于100。两者可以同时发生。应使用其后各日指数与成交价格检验，而不能只看一次拍卖。未取得拍卖前预测或2025年3月之后完整利息序列，本页不评价这些情景后来是否兑现。

## 涉及的关系

它与[收益率曲线](../10_concepts/C-IR-CURVE.md)的联系在于：短端路径决定未来浮动票息，市场要求利差和到期结构决定估值；与政策利率的联系须经实际合同基准，不能直接用政策目标代替。对财政融资研究而言，本页提供本金到期与利息重定价期限不同的具体产品例子。
