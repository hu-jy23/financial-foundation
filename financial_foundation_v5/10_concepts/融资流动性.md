# 融资流动性

> 执笔：main agent `/root`，2026-10-27。历史材料覆盖至2025-05-09；动态定义页于2026-10-27核读。本页解释融资能力及其约束，历史数字均对应所注明时期。[制作记录](../50_reviews/FISCAL_CONCEPT_PILOT_20261027/FUNDING_MAIN_NOTES.md)保存阅读范围。

## 概念定义

融资流动性描述一个主体在需要付款或维持头寸时，能够以怎样的成本和条件及时取得、续接并调动资金。它包括借款是否可得、额度够不够、能借多久，以及需要提供多少合格抵押品。资金最终要在指定时间、账户和币种中可用，才能完成结算、偿还到期债务或应对追加保证金。

这一概念在不同主体上有不同表现：银行需要应付存款支付和批发融资到期；交易商需要为库存融资；基金需要维持回购和衍生品头寸，并满足投资者赎回。BCBS对银行流动性的定义强调及时支持资产和到期义务，且避免不可接受的损失；Brunnermeier—Pedersen则从交易者取得资金的难易解释其提供市场流动性的能力。本页将这些联系放在同一个资金约束框架中，重点讨论与国债持有和中介活动有关的融资。[S-FUND-01](#S-FUND-01)、[S-FUND-02](#S-FUND-02)

## 概念详解

### 1．融资条件包含价格、数量与时间

假设交易商买入国债，等待随后卖给最终配置者。持有期间要支付买券款，还要覆盖价格波动和交易结算产生的资金需求。它可以用自有现金，也可以将国债用于回购融资。融资成本决定这笔库存的持有收益，授信额度和抵押条件决定能够持有的规模，融资期限决定何时必须再找资金。

因此，同样“借款利率为4%”可能对应很不同的融资状态：一笔已经承诺并可用一个月的贷款，与明早就要续作、额度随时需要重新协商的隔夜融资，对持仓稳定性的含义不同。某市场平均成交利率稳定，也可能同时存在个别借款人的额度削减。观察融资流动性，需要把以下条件放在一起：

| 条件 | 具体含义 |
|---|---|
| 价格 | 同币种、同期限、同抵押品下的融资利率及费用；还要与相应政策利率环境比较 |
| 额度与准入 | 出借人是否愿意提供资金、给谁提供、可用额度多少，以及承诺是否附条件 |
| 期限与续作 | 资金覆盖头寸多久，到期是否依赖重新借入；集中到期会放大同一时点的资金需求 |
| 抵押条件 | 接受哪些资产、采用什么估值和折扣、何时补交，以及是否允许替换抵押品 |
| 调动速度 | 现金或证券何时完成交割，是否能跨账户、币种和法律实体转移 |

借款人的资产质量、资本和对手方关系，会影响这些条件；出借人的现金需求、风险限制及资产负债表空间也会改变供给。交易商把借入资金转借给客户时，还承担中介成本，所以终端基金的可得条件与一个公开基准利率之间可以存在距离。[S-FUND-01](#S-FUND-01)、[S-FUND-08](#S-FUND-08)

### 2．抵押品市值与折扣怎样决定借款能力

在只考虑一种抵押品、没有其他授信上限且忽略应计利息的示意中，设抵押品市值为\(V\)，haircut为\(h\)，可借金额为\(L\)：

\[
L\leq (1-h)V,\qquad 0\leq h<1.
\]

\(V\)与\(L\)使用同一币种，\(h\)是对抵押品市值扣减的比例。例如10%的haircut意味着市值100的抵押品最多支持90的现金借款。ICMA区分了haircut与回购中“抵押品价值／借款额”的initial margin报价；二者分母不同，数值不能直接互换。[S-FUND-03](#S-FUND-03)

**假设算例：** 一项资产原来市值100，借款90，账面权益10。随后市值降至98，出借人把haircut从10%提高到15%。新借款上限为\(98\times0.85=83.3\)。如果保留全部资产，借款人需要从其他来源补入6.7现金以偿还部分借款，或按合同补充足够的合格抵押品。资产仍高于原借款8，但这8并不自动成为账户中的现金。

若既没有外部现金，也没有额外抵押品，只能出售该资产并把全部所得用于还款，出售本身又会缩小抵押池。进一步假设成交价不受出售影响，卖出市值\(x\)的资产后需满足：

\[
90-x\leq0.85(98-x)
\quad\Longrightarrow\quad x\geq44.67.
\]

这解释了为何6.7的补款缺口可能对应更大规模的持仓收缩：每卖出1单位资产，虽然能够偿还1单位借款，剩余抵押能力也减少0.85。这里是本页的机械算例，未计手续费、价格冲击和其他资金来源；实际处置量须按合同和资产组合重新计算。

抵押融资中的资金压力可以分别来自\(V\)下降、\(h\)上升、借款额度降低或到期不再续作。零haircut只描述某一项交易的抵押比例，仍然存在对手方限额、其他头寸保证金和支付需求；不能由此推得无限融资能力。美联储2023年对基金回购的研究也显示，低或零折扣与较高杠杆往往同时存在，压力分析仍需看到整个组合。[S-FUND-04](#S-FUND-04)

### 3．初始保证金、变动保证金与现金路径

衍生品的初始保证金主要覆盖对手方违约后平仓、替换头寸期间潜在的未来敞口，变动保证金则对应已发生的市值变化。[S-FUND-11](#S-FUND-11)波动上升可以增加初始保证金要求；头寸亏损可以触发变动保证金支付。两项同时发生时，现金需求会叠加。保证金保护交易对手，同时让持仓者必须准备可及时交付的资产。[S-FUND-05](#S-FUND-05)

对冲后的净经济风险较小，也可能存在很大的中途付款需求。例如，国债现货上涨使持有人产生账面收益，空头期货却可能要求当日支付变动保证金。将现货升值转为新增回购借款，需要重新估值、获得额度并完成结算；两个账户之间的时间差本身就会造成融资需求。若现货和期货没有同步变化，还会出现组合层面的实际损失。Kruttli等人的研究附录详细说明了这类基差交易的续作和保证金风险。[S-FUND-06](#S-FUND-06)

由此，持有到期可能获得什么回报，与能否筹到期间所需现金，是两项都要检查的条件。提前出售、缩小对冲或补充资本，都可能改变原先预期的收益。

### 4．把“资金够不够”写成带时间的判断

对于指定账户、币种和情景，可以整理一条累计现金路径：

\[
H(u)=C_0+I(0,u)+F(0,u)-O(0,u).
\]

其中\(C_0\)为起点可自由动用现金；\(I\)为截至\(u\)确实可收到的累计非融资现金流；\(F\)为届时可完成提取的新增融资；\(O\)为累计付款，包括到期偿还、结算、保证金和赎回等。所有量均为同一币种金额。这是本页整理的收支框架；每个重要付款时点的\(H(u)\)都须检查，月末余额为正无法消除月中或日内缺口。

信用额度的合同总额与届时可提取金额要分开，已经质押的资产也不能重复计作无负担缓冲。某项资产若已按出售所得计入现金流，就不能再把同一份资产可取得的抵押融资重复加入。集团合并现金充足，也可能因为币种转换、实体间转移或证券交割所需时间，使某一账户无法准时付款。BCBS的跨币种、日内及抵押品管理原则分别处理这些问题。[S-FUND-01](#S-FUND-01)

把不同压力情景代入这个框架，可以看出缺口来自流出增加、融资减少还是资金到账延迟。FSB在2024年对非银行机构的研究强调，保证金压力、现金及抵押品可用性与操作准备应一起考察。这个思路适用于理解压力来源，具体压力幅度与可用资金需由实际数据决定。[S-FUND-05](#S-FUND-05)

### 5．为什么融资能力会进入资产定价

当交易商的资金能够覆盖库存和保证金时，它可以在客户集中出售时暂时接盘，等待另一侧买家出现。融资条件收紧后，同样的库存会占用更多稀缺资金，交易商可能降低买入价、缩小报价数量或减少持仓。市场成交变难又可能使抵押品估值和自身资本承压。

Brunnermeier—Pedersen模型区分两种放大：既有头寸亏损消耗资本，以及保证金要求随条件变化而收紧。两者在特定条件下相互强化；出借人对基本价值的信息、头寸方向和约束是否已经接近生效，都影响结果。论文提供条件性解释，无法仅凭价格下跌就认定已经发生某一种融资螺旋。[S-FUND-02](#S-FUND-02)

在[国债供给的定价机制](../20_mechanisms/国债供给的定价机制.md#logic-1)中，这个对象解释交易商和杠杆买家有多大能力承接发行与库存风险。发行规模相同，融资条件改变也会改变承接意愿；最终对收益率的影响还须结合久期、最终配置需求与宏观预期分析。

偿付能力涉及资产价值及未来收入是否足以覆盖负债；融资压力涉及能否按时取得支付资源。短期融资缺口可能迫使持有人低价变现并侵蚀资本，资产损失也可能反过来降低出借人意愿。判断一项压力时，应同时记录资产价值和现金时间表，不把一种证据替代另一种。

央行融资设施也有合格对手方、抵押品和结算安排。设施存在，须经过相应渠道才能成为具体主体的资金。2025年纽约联储对SRF的讨论专门涉及早间结算和使用成本，说明操作时间与机构约束会影响工具实际可用性。[S-FUND-08](#S-FUND-08)

## 观测与数据口径

| 要回答的问题 | 可观察的材料 | 解释时保留的口径 |
|---|---|---|
| 资金价格是否承压 | 对应币种、期限与抵押品的回购利率、成交分布及相对基准利差 | 政策利率上调可带动融资利率普遍上升；需区分政策水平与额外融资压力 |
| 融资是否仍可续接 | 期限分布、到期集中度、可用授信、拒绝续作记录及对手方反馈 | 总借款下降也可能来自主动减仓；需要数量变化的需求／供给背景 |
| 同样资产能借多少 | 抵押品估值、haircut、可接受资产范围、授信上限 | 平均折扣可能掩盖特定借款人和品种；不能仅记录一个市场均值 |
| 现金何时需要、何时可用 | 保证金通知、结算时刻、提款条件、现金和未质押证券 | 自由现金、已交保证金和受限现金分别记录；资产变现速度也要计入 |
| 中介能否承接交易 | 交易商融资成本、库存、报价深度与客户融资条件 | 报价和库存反映市场结果，直接归因融资仍需资金端证据 |

SOFR是美国国债抵押隔夜现金借款成本的广泛指标，按所覆盖交易的成交量加权中位数计算。它有明确的市场范围，无法覆盖所有基金的非集中清算双边融资，也不能直接提供被拒绝融资者的条件。现时纽约联储方法页用于辨认统计对象；历史研究还须保存当期方法和数据版本。[S-FUND-09](#S-FUND-09)

抵押品的稀缺性还会改变回购报价：某只证券被强烈需求时，现金出借者可能接受较低利率来取得该证券。因此，个别券的低回购利率需要结合“借到现金”与“取得特定券”的两个目的分析。[S-FUND-09](#S-FUND-09)

## 本对象的历史

### 2007—2009：融资条件成为理解流动性的核心变量

BCBS于2008年9月发布修订后的流动性风险管理原则，开篇回顾了2007年起融资由便宜且易得转为持续承压的变化，并把表外承诺、压力测试、抵押品与日内支付纳入分析。这里保留的是当时制度总结，不据此估计每项改革的效果。[S-FUND-01](#S-FUND-01)

2009年发表的Brunnermeier—Pedersen研究将交易者资本、保证金与资产成交条件放进统一模型，解释约束接近生效时为何可能出现非线性放大。它帮助本库明确概念之间的关系，模型预测需另用事件证据检验。[S-FUND-02](#S-FUND-02)

### 2020年3月：区分回购融资、衍生品保证金与主动现金管理

Kruttli等人2021年的事后研究显示，其样本中的美债交易对冲基金在2020年3月平均回报约为−7%，美债敞口减少接近20%，双边回购借款和haircut的整体变化却相对有限。基差交易基金承受更大的保证金压力，减持及回购收缩更明显。数字描述的是研究样本和敞口，不能转写成全市场国债价格跌幅或现金债卖出比例。[S-FUND-06](#S-FUND-06)

基金可以在尚未失去全部融资渠道时主动增加现金，以应对未来保证金和潜在赎回。该研究据此强调机构自身的流动性管理，结论有其样本和识别范围。与此同时，纽约联储研究者2020年8月对回购操作的回顾记录，3月交易商资产负债表承压，一个月以上国债回购相对同期限隔夜指数掉期（OIS）的利差一度达到60bp，通常为5—10bp。该文也记录期限回购总量变化不大、新交易期限缩短。月度借款余额相对稳定与特定期限／时段融资变贵可以并存；需要把观察对象和频率对齐。[S-FUND-06](#S-FUND-06)、[S-FUND-10](#S-FUND-10)

本页据这些后来材料解释渠道，未取得事件发生前各基金的原始流动性预测或逐日保证金通知，因而不重建其当时预计缺多少现金。

### 2022年英国LDI压力：长期负债对冲仍需短期现金

英国央行2022年12月报告回顾：9月下旬长期国债收益率迅速上升，债券价格下跌，杠杆LDI头寸面临追加抵押品与保证金要求。养老金的长期负债现值可以随收益率上升而下降，但资金向LDI账户调拨需要时间；这使养老金整体财务状况与具体账户的即时付款压力出现分化。[S-FUND-07](#S-FUND-07)

报告估计，**2022-09-23至10-14，单位为十亿英镑**：确定给付养老金卖出国债约14，LDI基金约23，同期两者面对的保证金与抵押品要求合计超过70。出售国债的金额小于总要求，因为它们还动用现金并出售其他资产。70描述资金／抵押品需求，不能改写成损失金额；14与23分别对应不同主体。[S-FUND-07](#S-FUND-07)

**后续制度判断，2023-03-29。** 英国金融政策委员会提出，LDI应具备至少约250bp收益率冲击的韧性，并在此之上为日常波动和操作风险保留额外空间。该标准表达需要承受的压力幅度，未预测收益率将上涨250bp；说明还将抵押品调拨的时间与所需缓冲联系起来。[S-FUND-07](#S-FUND-07)

### 2025年4月、5月9日回顾：融资稳定可以缓冲成交条件恶化

纽约联储SOMA经理Roberto Perli在2025-05-09讲话中判断，4月国债现货市场流动性承压期间，回购利率总体仍在近期范围内，交易商继续提供中介服务，融资的稳定帮助限制了无序减仓。该判断归属于讲话者，支持的是所述时期融资渠道的缓冲作用，未证明全部机构均无资金压力。[S-FUND-08](#S-FUND-08)

讲话还提到，2025年3月杠杆基金十年期及以内国债期货空头名义头寸约为1万亿美元；它只是基差交易规模的粗略代理，不能直接当成实际基差交易总额或必然要抛售的现金债。保留代理性质，才能正确理解潜在融资依赖的规模。[S-FUND-08](#S-FUND-08)

**当时的政策执行计划**是将早间结算的SRF操作纳入常规日程，具体时间尚未确定。其作用在于更早取得可结算现金。本页保留这个截至5月9日的计划，未将后来实施结果回填。[S-FUND-08](#S-FUND-08)
