# 宽基ETF

> 执笔：`/root/full_b031`，GPT-6-Astra，medium；制作日2026-10-28。核心财务资料截至2025-03-31公开的2024年度报告；交易所动态问答于制作日核读。下列产品截面均指2024年末。

## 概念定义

宽基ETF是以反映一组不同规模或市场范围股票整体表现的宽基指数为跟踪标的、在交易所上市交易、可按基金合同申购赎回的基金产品。上证50、沪深300、中证500等ETF是典型例子。宽基指数是一套选样、加权、计算与调整规则；ETF则是真实持有资产、支付费用、接收申赎并发行基金份额的投资载体。投资者购买的是基金份额所对应的资产权益，不是指数点位本身。[S-C-ASIA-04-01](#S-C-ASIA-04-01)

本页以境内A股宽基ETF为主。宽基意味着不以单一行业为选样主题，仍可以偏向大盘、中盘、小盘或特定交易板块，并不等于覆盖全部经济活动、各行业等权或风险天然较低。红利等策略指数是否被统计为宽基，应依来源分类，不能因其包含多个行业便自动合并。

## 概念详解

### 从指数规则到实际资产组合

基金管理人根据指数成分和权重构建组合，指数定期调整、公司行动、申购赎回都会产生组合维护需求。完全复制法尽量逐一持有指数成分；实际操作仍可能因停牌、流动性不足、新股、现金替代与结算安排产生短时偏差。管理人维护跟踪，托管人保管和复核资产，投资者承担组合价格风险。[S-C-ASIA-04-02](#S-C-ASIA-04-02)

以**华泰柏瑞沪深300ETF（510300）**为例，其2024年报规定主要采用完全复制，标的指数成分股及备选成分股投资比例不低于基金资产净值的95%，基准为沪深300指数。2024-12-31，实际股票资产为**3554.52亿元人民币，占基金总资产98.76%**，银行存款和结算备付金合计约39.84亿元，占1.11%。这不是“300家公司各买相同金额”：年报指数投资行业分类中，制造业占基金净资产51.72%、金融业24.31%。股票占比的分母为总资产，行业占比的分母为净资产，二者不可不加说明地拼成同一张比例表。[S-C-ASIA-04-02](#S-C-ASIA-04-02)

由此可见，宽基ETF分散的是个别公司风险，仍保留指数结构带来的共同风险。金融业利润变化、大盘相对小盘表现或整体风险偏好变化，都可以主导净值。把全部经济预测压缩成“买大盘”之前，应先知道基金实际代表哪个股票集合。

### 一只基金、两种交易层次

二级市场上，甲把已有ETF份额卖给乙，资金在投资者之间转移；若没有申购赎回，基金总份额和组合资产不会因为这笔买卖而变化。一级市场上，参与者按申赎清单交付组合证券、现金替代及现金差额等，取得新增份额；赎回则注销份额并取得相应对价。交易所问答明确，实物申购创造新的ETF流通份额，实物赎回相反。[S-C-ASIA-04-01](#S-C-ASIA-04-01)

因此，二级市场成交额反映份额交易活跃度；份额净增加反映申购超过赎回；基金持仓股票的二级市场买入量则还取决于投资者交付的是股票还是现金。实物申购可以只是把投资者已有股票装入基金，并非申购发生时全部重新买股。把ETF“资金流入”解释为同额新增股票买盘，会跳过这一步资产转移。

当ETF市价相对可执行篮子价值偏高，具备申购与交易能力的参与者可能买入或使用库存篮子、申购份额并卖出ETF，增加ETF供给；折价时可能买ETF、赎回并处置篮子。这个机制使市价受到组合价值约束，但参与者要承担价差、费用、资金占用、证券可得性及执行时差。停牌或涨跌停使篮子难以成交时，账面价差不等于可实现利润。完整传导见[ETF申赎套利](../20_mechanisms/R-MARKET-04.md)。

### 市价、净值与投资者回报

设基金净资产为\(A_t\)，总份额为\(S_t\)，每份净值为\(NAV_t=A_t/S_t\)，都采用同一估值时点。二级市场每份价格为\(P_t\)，折溢价为：

\[
\pi_t=P_t/NAV_t-1.
\]

盘中不能直接用昨日收盘净值判断“套利空间”。参考净值IOPV用盘中价格及相关清单信息估算，仍可能受到成分股停牌、估值更新和现金项误差影响，也不是参与者保证可以成交的价格。实际买卖还涉及买卖价差和佣金。

**假设算例：** 买入时每份净值4.00元、市价4.04元，溢价1%；卖出时净值4.20元、市价4.20元，不计分红及费用。基金净值上涨5%，买方实际价格回报却只有\(4.20/4.04-1\approx3.96\%\)。指数方向判断正确，初始溢价消失仍会侵蚀到手收益。

分红也需一致处理。基金向持有人分配现金后，净值相应下降，不能仅把两个未复权净值相除作为总回报。指数价格收益、含股息再投资的全收益，以及基金含分红净值增长率应区分。基金相对价格指数表现较高，可能包含收到股息的作用；这不自动证明管理人通过选股获得主动超额收益。

### 谁使用宽基ETF，为什么市场作用不同

个人投资者可以用一笔交易获得组合敞口，避免逐只建立数百只股票头寸；资产配置机构用其调整大类或规模风格暴露；做市与套利参与者连接基金份额和股票篮子；政策性或长期持有主体也可能通过ETF实施大额组合配置。相同的份额变化可能来自不同目的，需要持有人和申赎证据来辨认。

510300年报的2024年末持有人结构是：机构投资者83.06%、个人16.32%，联接基金单列0.62%；前两名中央汇金投资有限责任公司和中央汇金资产管理有限责任公司分别持有上市份额39.89%、29.78%。这是**单只基金期末截面**，不能推广成全部宽基ETF的持有人结构，也不证明两家主体在某个盘中时刻买入。联接基金汇集其自身持有人的需求后投资ETF，分析最终投资者时还需穿透，不能把两层资产规模相加当作新增权益资产。[S-C-ASIA-04-02](#S-C-ASIA-04-02)

## 观测与数据口径

| 观察对象 | 它回答的问题 | 必须保留的区别 |
|---|---|---|
| 份额与净申赎 | 投资载体的份额是否扩大 | 份额拆分需调整；份额不是人民币金额 |
| 资产净值／规模 | 基金拥有多少净资产 | 同时受价格、申赎、收益与分配影响 |
| 成交额、买卖价差、深度 | 份额是否容易交易 | 大成交额不是净流入，成交活跃不保证任何规模都能低冲击成交 |
| 申赎清单 | 一级市场交付什么 | 现金替代、最小申赎单位与退补款按产品版本确认 |
| 跟踪差异与跟踪误差 | 基金回报是否贴近基准 | 前者是回报差，后者描述差的波动；日频、年化和基准口径不能混用 |
| 持有人与行业权重 | 谁持有、承担什么风险 | 期末观察不提供完整交易路径；行业分类也可能随数据源不同 |

严格的净资产变化可以用基金会计表核对：

\[
A_1=A_0+F+G-D,
\]

\(F\)为申购赎回导致的净资产变动，\(G\)为综合收益，\(D\)为向持有人的利润分配，单位均为期间内同币种金额。\(F\)可能含实物对价，不是纯现金入账。用每日份额变化乘净值估算“资金流”时，必须明确这是估算方法，不能替代会计表或成分股实际交易。

## 本对象的历史与带归属的判断

### 2012产品建立，到2024规模扩张

510300基金合同2012-05-04生效、同月28日在上交所上市，是跨沪深股票组合的实际ETF载体。2024年宽基ETF扩张时，已有产品的申赎与交易基础设施承接了更多组合需求。上交所《ETF行业发展报告（2025）》记录2024年底沪市宽基ETF规模约**1.6万亿元**，较2023年底增长147%；这是沪市上市产品口径，不是全境内宽基ETF总量。[S-C-ASIA-04-02](#S-C-ASIA-04-02)、[S-C-ASIA-04-03](#S-C-ASIA-04-03)

510300审计年报提供了更可核验的单产品拆分。以下均为2024年度、人民币亿元，按原表元金额换算并四舍五入：

| 净资产变动项 | 金额 |
|---|---:|
| 2023年末／2024年初净资产 | 1310.87 |
| 申购赎回导致的净资产增加 | 1746.00 |
| 综合收益 | 564.35 |
| 向持有人分配利润 | −24.94 |
| 2024年末净资产 | 3596.27 |

期末减期初为2285.41亿元，其中约1746.00亿元来自份额交易，其余主要是投资收益扣除分配。不能把2285.41亿元全部称为净流入。份额由374.44亿份升至893.87亿份，全年总申购864.09亿份、总赎回344.664亿份，净增519.426亿份；申购与赎回规模都很大，年末余额掩盖了期间周转。[S-C-ASIA-04-02](#S-C-ASIA-04-02)

### 2024跟踪结果与2025当时展望

同一报告记录，2024基金份额净值增长17.38%，沪深300基准增长14.68%；管理人报告日均绝对跟踪偏离度0.016%、期间日跟踪误差0.029%。后两项是报告的日口径，不能直接写成年化跟踪误差；基金与价格指数年度回报相差2.70个百分点，也不能全部解释为选股能力。[S-C-ASIA-04-02](#S-C-ASIA-04-02)

**管理人当时判断，2025-03-31公开：** 年报展望2025年，认为稳增长政策有望使风险偏好整体好于2024年，同时承认需求、物价与外部环境扰动，并判断结构性机会可能增加、宽基配置吸引力显现。这是基金管理人的展望，不是保证收益；该判断并未改变被动跟踪的合同职责。本页没有核验2025全年实现结果，不能以后来行情倒推其预测正确。[S-C-ASIA-04-02](#S-C-ASIA-04-02)

**本库条件推演，2026-10-28整理：** 对未来一个申赎和指数调整周期，如果新增份额主要由实物篮子交付，ETF扩容更多表现为资产所有权转移；若以现金方式交付且管理人需补齐组合，才会形成相应股票执行需求。组合越容易买卖、套利者融资越充足，ETF价格越容易靠近可执行篮子价值；遇到成分股交易受限或持有人集中赎回，执行成本和现金需求可能显著上升。该推演需要以具体产品清单、份额及市场深度更新，不能由净申购一个量直接预测指数上涨。
