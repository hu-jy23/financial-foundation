# 半导体设备与材料

> 执笔：`/root/resume_b039`，GPT-6-Astra，medium；2026-10-30制作。产业与公司证据覆盖至2026-10-15；设备市场采用SEMI 2026年7月预测版本，材料全年数据截至2025年，不能把不同截止混成2026年实际全年结果。

## 概念定义

半导体设备是用来制造、量测、组装和测试芯片的生产工具；半导体材料是构成芯片、转移图形、加工表面和完成封装所需的基材、化学品与其他投入。二者共同决定工艺能否以足够良率、速度和成本稳定运行。设备较多对应新增产能和技术升级的资本开支，材料较多随实际加工消耗，但设备还包括服务及升级业务，材料中也有光罩等可重复使用的项目，不能把两类机械划成“一次性采购”与“每片固定耗用”。

## 概念详解

### 工具做什么，材料为什么必须和它一起看

| 加工任务 | 主要设备功能 | 与之配合的材料及关键要求 |
|---|---|---|
| 建立器件基底 | 晶圆处理、外延等 | 硅片及外延层的平坦度、晶体质量和均匀性 |
| 转移图形 | 涂胶显影、光刻、套刻量测 | 光刻胶、光罩和辅助化学品；要求曝光反应、图形与缺陷控制一致 |
| 增加或移除薄膜 | 沉积、刻蚀、清洗 | 前驱体、工艺气体、湿化学品；要求目标材料的反应选择性及低污染 |
| 调整电学性质与表面 | 离子注入、热处理、化学机械平坦化 | 掺杂源、研磨液和抛光垫；控制电性、表面与后续工艺接口 |
| 控制过程 | 缺陷检测、电性测试、尺寸量测 | 测试晶圆、探针及相关耗材；测得偏差后反馈到加工参数 |
| 组成可用器件 | 减薄、切割、键合、封装和测试 | 基板、重布线材料、焊接和封装材料；处理互连、应力及热路径 |

这张表按功能解释制造系统，并非市场份额划分。同一厂商可能跨多个功能；某些材料也跨多个工序。ASML的工艺说明展示沉积、图形化、刻蚀和掺杂反复配合的过程；台积电年报则把硅片、气体、化学品和光刻胶列为连续生产所需投入。[S-C-TECH-09-01](#S-C-TECH-09-01)、[S-C-TECH-09-02](#S-C-TECH-09-02)

化学式相同的材料也可能因金属杂质、颗粒、浓度、批次稳定性和包装输送条件而表现不同。量产工艺是一组已经验证的设备、配方和材料组合：供应商替代如果改变蚀刻速率、薄膜性质或缺陷分布，就需要重新验证。台积电披露按质量控制和交付可靠性选择供应商，季度评估并调整采购分配，并通过双厂材料认证、安全库存及长期协议降低中断风险。这提供了“认证壁垒”的实际采购背景；不意味着所有材料都只有单一来源。[S-C-TECH-09-02](#S-C-TECH-09-02)

### 技术约束不等于设备清单

光刻的简化分辨率关系为：

\[
CD=k_1\lambda/NA.
\]

\(CD\)为可印出的关键尺寸，\(\lambda\)为光波长，二者用相同长度单位；\(NA\)为数值孔径，\(k_1\)代表工艺相关因子，均无量纲。缩短波长、提高数值孔径及优化工艺有助于缩小图形，但这个关系不是完整良率或生产成本模型，也不直接给出商业节点名称。[S-C-TECH-09-03](#S-C-TECH-09-03)

从DUV到EUV，光源和光学系统改变，光刻胶及其他工艺也必须配合。EUV采用13.5nm波长；NXE的NA为0.33，EXE High-NA为0.55。EUV印复杂层，DUV继续印其他层，因此新技术并不立即清空旧平台需求。更少图形化步骤可能减少缺陷机会和加工时间，但更昂贵设备、曝光剂量、维护与实际吞吐量仍决定经济性。[S-C-TECH-09-04](#S-C-TECH-09-04)

先进结构同样改变其他设备的重要性。GAA纳米片需要选择性移除材料而保留极薄沟道，三维结构需要在复杂表面控制薄膜均匀性；先进封装扩大尺寸、增加连接数，又提高键合、翘曲和测试要求。因而“制程更先进”并不按固定比例拉动所有设备。判断供应商机会必须落实到增加了哪些步骤、每步花多长时间、哪些原有设备仍可复用，而非只给厂商贴“AI设备”标签。

### 资本开支链上至少有四个不同时点

芯片制造商先根据客户需求、节点规划和可用资金决定资本预算，再向供应商下单。设备商安排零件、装配和出货；设备抵达晶圆厂后，还需安装调试、验收、工艺认证并爬坡。设备商收入何时确认取决于合同与会计条件，客户现金支付时间也可能不同。最终新增合格芯片产出通常更晚。

所以资本预算、订单、出货、收入和现金流不能互换。晶圆厂资本开支还含厂房、公用设施等，不等于设备商销售额；全行业设备收入也不能与某一家代工厂资本开支直接相除来推算市场份额。一个订单积压量既可能反映需求，也可能因为供给延迟；取消、推迟或重新排程会改变其含义。

设备销售还存在持续服务业务。ASML 2025年按US GAAP披露总净销售327亿欧元，其中系统245亿、服务与现场选件82亿。服务及选件同比增长26.2%，快于系统的12.4%；公司解释涉及装机基础、工具使用及升级。旧设备存量因此也是经营资产，供应商收入不完全依赖当期新建厂。[S-C-TECH-09-05](#S-C-TECH-09-05)

### 材料消耗跟加工活动走，收入还要加上价格与库存

对同一材料，某期间的采购量可用下式整理：

\[
采购量=生产消耗量+期末库存-期初库存.
\]

这是库存核算框架，假设没有报废、退货和其他调整；实际应补上这些项目。生产消耗又取决于晶圆投入、相关加工次数、每次耗用以及清洗和工程验证需求。客户减库存时，材料供应商出货可能低于晶圆厂实际消耗；提前备货时则相反。

**本库假设算例。** 某种工艺气体原来加工100单位晶圆，每单位需10次相关步骤，每步耗用1单位，消耗1,000单位。随后晶圆加工量不变、步骤变为12次，消耗增至1,200；若客户同期去库存100单位，则采购只有1,100，增长10%而非20%。材料单价若再变动，供应商收入增幅会进一步偏离采购量。此例不适用于所有材料，例如裸硅片数量并不随每片的薄膜步骤同比增加。

材料市场金额还受商品价格和产品结构影响。SEMI对2025年材料增长的解释指出，封装材料的增收既有先进基板需求，也有键合线金价上升因素。因此，材料销售额增幅不是纯粹的芯片产量增幅。[S-C-TECH-09-06](#S-C-TECH-09-06)

### 技术壁垒、供应限制与客户集中

高精度设备通常依赖专用零部件、软件和现场服务能力；材料需要稳定配方及客户验证。若某一投入不可得，其他设备即使闲置也不能完成整条工艺。台积电年报明确提示部分设备供应商有限、部分材料单一来源以及出口许可延迟可能妨碍扩产。这些是经营风险披露，不是本页对具体机型当前合法可售地区的判定。[S-C-TECH-09-02](#S-C-TECH-09-02)

壁垒也不自动等于所有供应商都有同样定价权。能否替代、停机损失、材料占总成本比例、客户集中度及长期合同，都会影响议价。客户可能为保供预付款或增加库存，但在需求放缓时也可能推迟采购。供应商还需在研发与制造能力上先投入，若技术路线或客户认证失利，这些投入未必转成收入。

## 观测与数据口径

| 数据 | 应记录的范围 | 它不能单独代表什么 |
|---|---|---|
| WFE销售 | 晶圆加工、光罩及相关厂务设备；按统计机构定义 | 不是所有封测设备，更不是含建筑的全行业资本开支 |
| 新系统销售／服务收入 | 币种、会计准则、系统类别及确认期间 | 台数不等于同质产能，服务不是重复卖出整机 |
| 订单与积压 | 是否净额、预计交付年、取消及许可条件 | 不是已经兑现的收入或客户现金付款 |
| 硅片出货面积MSI | 百万平方英寸，材料供应商出货口径 | 不是加工后晶圆出货，更不是晶体管数量 |
| 材料销售额 | 晶圆制造材料／封装材料、价格和产品组合 | 不是单纯消耗量；区域消费额不等于供应商国籍 |
| 客户资本支出 | 实际／预算、建设／设备／研发配置 | 不能直接映射一家设备商的收入增幅 |

## 历史演变与关键数量

**技术进步使设备与材料共同升级。** ASML产品历史记录，首台EUV生产系统在2013年交付，首台High-NA系统在2023年12月交付。交付标志着平台演进，不等于所有客户马上采用，也不等于量产收益率已经达标。精细图形化逐步商业化的同时，存储三维化和多芯片集成把增量需求扩展到刻蚀、沉积、键合及测试。[S-C-TECH-09-04](#S-C-TECH-09-04)

**2025年的实际市场规模。** SEMI于2026-05-12报告，2025年全球半导体材料收入732亿美元，同比增长6.8%；其中晶圆制造材料458亿美元、增长5.4%，封装材料274亿美元、增长9.3%。这是供应商销售金额，不能与设备金额相加后称为芯片产值，也不能把全部封装材料增长归于CoWoS。[S-C-TECH-09-06](#S-C-TECH-09-06)

**2026年的数量与预测分别保存。** SEMI 7月29日公布，第二季硅片出货面积为3,573 MSI，较上年同期3,327 MSI增长7.4%，较第一季3,275 MSI增长9.1%。它提供材料实物活动的观察，但并未给出各逻辑节点的产量。[S-C-TECH-09-07](#S-C-TECH-09-07)

SEMI在7月14日的OEM口径预测中，预计2026年设备销售1,659亿美元，同比增长23.2%；其中WFE为1,439亿美元、测试153亿美元、组装封装67亿美元。三类数额与增速说明扩张并不均匀，且均是当时全年预测。本轮没有取得付费底表或后来同系列完整修订，不能当作2026全年实际收入。[S-C-TECH-09-08](#S-C-TECH-09-08)

**2026年10月的公司信息更新。** ASML于10月14日披露第三季总净销售116.62亿欧元，其中服务与现场选件32.89亿；管理层把全年销售预期提高到440亿—450亿欧元。相较其2025年年报中对2026年340亿—390亿欧元的展望，这是后来信息下的预期调整，不是年报发表时已经知道的结果。[S-C-TECH-09-05](#S-C-TECH-09-05)、[S-C-TECH-09-09](#S-C-TECH-09-09)

需求端，台积电2025年实际资本开支为408.95亿美元（按年报所列加权平均汇率换算），年报对2026年的预算为520亿—560亿美元；2026年10月15日电话会已重申600亿—640亿美元的年度资本预算。公司同时提到设备供给紧张，需要提前与供应商规划。这里展示客户计划怎样修订，既不说明全部增量流向光刻，也不等于该预算已经全额支付。[S-C-TECH-09-02](#S-C-TECH-09-02)

### 保留当时预期，如何继续更新

ASML在2026年10月判断，按当时供给计划，2027—2028年难以完全满足客户需求，并研究进一步扩产。其公告脚注明确，先前的30%扩产描述针对低NA EUV和浸没式DUV，不能扩写为所有设备类别。这个判断来自供应商对客户计划的观察，不是终端需求的无条件保证。[S-C-TECH-09-09](#S-C-TECH-09-09)

**本库条件推演，2026-10-30。** 如果先进逻辑、HBM及复杂封装的技术迁移持续，每片晶圆或每套器件所需设备时间、材料步骤和测试复杂度都可能增加，供应商收入可以快于芯片单位数量增长。但新产能交付、客户库存回落或终端需求未兑现，会使订单先调整、材料消耗随后变化；装机服务则可能相对滞后。有效更新应把客户资本计划、设备交付与验收、晶圆投入、材料库存和最终产品出货放到同一时间线上，而非用一个“半导体景气”指标代替。
