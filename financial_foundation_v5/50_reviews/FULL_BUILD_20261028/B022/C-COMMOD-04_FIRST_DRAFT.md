# 天然气与LNG

> 执笔：`/root/full_b022`，GPT-6-Astra，medium；制作日2026-10-28。市场研究覆盖至2026-07-07，制度与定义网页于制作日核读；文中2026全年数字为对应发布时点的预测。

## 概念定义

天然气是以甲烷为主要成分、可用作燃料和化工原料的气体能源；商品交易中通常指已处理到管输或用户要求的天然气。LNG（液化天然气）是将天然气冷却至约−162℃后得到的液体，体积约为气态的六百分之一，便于跨海运输。它不是另一种能源矿产，而是天然气的一种运输、储存形态。出口端需要液化装置，进口端需要接收、低温储存与再气化设施，之后仍要靠管网送到用户。[S-C-COMMOD-04-01](#S-C-COMMOD-04-01)

因此，理解天然气应同时看三张地图：气田和生产设施在哪里，管道、液化厂和接收站能把气送到哪里，冬季供暖、夏季发电和工业用户何时需要它。全球资源充足，并不等于某个地区今天有足够的可交付气量。

## 概念详解

### 区域市场通过LNG相连，价差仍有经济含义

管道将产区与特定消费区连接，短期运力既定；LNG扩大了可选择的买家范围，但要经过液化、船运、卸货、再气化与管网输送。任何一环达到上限，都可能使低价地区增加供给无法及时压低高价地区的价格。接收站建成也不意味着其内陆管线已有足够外输能力。

三种常见价格分别对应不同交货对象：Henry Hub是美国管道天然气市场的基准；TTF是荷兰虚拟交易点的气体交付基准，ICE合约以欧元/MWh报价；JKM是Platts对东北亚到岸LNG现货船货的价格评估，并非单一交易所的一笔成交。当前JKM说明页涵盖日本、韩国、中国及台湾的DES交货，评估还需规范交货窗口、质量和地点。比较价格时要统一币种、能量单位和期限；TTF的某月交付与某个未来窗口抵港的JKM船货，未必是同一时间风险。[S-C-COMMOD-04-03](#S-C-COMMOD-04-03)、[S-C-COMMOD-04-04](#S-C-COMMOD-04-04)

对有可用运力及销售权的货主，可用下面的简化式理解目的地选择：

\[
N_i=P_i-C_{ship,i}-C_{terminal,i}-C_{loss,i},\qquad \Delta N=N_A-N_B.
\]

各项均按同一交付能量折成美元/MMBtu（百万英热单位）；\(N_i\)是目的地\(i\)扣除船运、码头与输送费用及损耗价值后的净回值。这个比较针对同一船已可支配货物的替代目的地，未扣共同的上游购气与液化成本，也不包括违约或改港费用。若\(\Delta N>0\)，A有更高净回值，但船期、合同目的地限制、信用额度和接收槽位仍可能阻止改港。

**假设算例：** A、B到岸售价分别为14、12美元/MMBtu；A、B航运及其他差异成本分别为3、0.8。净回值为11、11.2，报价更高的A反而少赚0.2。若A、B是两笔独立的新建出口项目，则还须计入各自液化资本与固定费用，不能把这个货船调配算例当作完整项目盈利模型。

### 合同价格、边际船货和国内价格不是一个量

LNG可以采用油价挂钩、气价挂钩或其他议价方式；交货义务、数量弹性和转售权与价格公式一起决定风险。长协买家当期采购均价可能平稳，但新增一船货需要支付更高现货价格。反过来，国内产气充足的地区即使出口价格高，也可能受液化能力约束而无法把全部气量按国际价出售。S&P的价格说明记录了油价挂钩长协与市场化LNG基准并存的演变；这不意味着所有长协都已转为JKM定价。[S-C-COMMOD-04-04](#S-C-COMMOD-04-04)

价格上涨还会改变需求。燃气电厂与燃煤电厂比较的是每单位发电量的燃料、效率与其他边际成本；化肥厂则同时把气当能源和原料，改用另一种燃料未必能维持原工艺。当用户无法迅速替代时，价格必须上升到促使部分工业减产或消费节约的水平，才能重新平衡有限供应。燃料切换能力因设备和地区而异。[S-C-COMMOD-04-02](#S-C-COMMOD-04-02)

### 季节库存同时有“容量”和“流速”约束

冬季采暖与夏季燃气发电使需求随天气变化。产量短期较平稳，储气库把淡季气量移到旺季；但高温导致夏季发电用气增加，也可能减少入冬前注气。美国常见的是春夏注气、冬季提气，这不是所有气候区均适用的日历规律。[S-C-COMMOD-04-02](#S-C-COMMOD-04-02)

地下储气分为维持压力的垫底气和可调度的工作气。库容表示最多能放多少，库存表示已经放了多少，提气能力表示每天能送出多少。盐穴与枯竭气田的注采速度和循环能力不同。即使库存足够覆盖整月消费，寒潮某几天仍可能因提气或管输瓶颈而缺气。[S-C-COMMOD-04-05](#S-C-COMMOD-04-05)

对一个明确地区和一个期间，可写物理收支：

\[
S_{t+1}=S_t+Q_t+M_t-X_t-D_t-L_t.
\]

\(S\)为期末可用库存，\(Q\)为地区产量，\(M\)、\(X\)为进口和出口，\(D\)为终端及其他已定义用气，\(L\)为尚未包含在这些项内的损耗；均用同一温压基准的气态体积或同一能量单位。实际统计需统一液化耗气是否已含在需求中，避免重复扣除。库存变化是供需差的结果，却也决定下一期能够承受多大天气冲击。上述平衡不能替代逐日运力约束。

## 观测与容易混淆的口径

| 观察项 | 能说明什么 | 应保留的边界 |
|---|---|---|
| 地区现货、远期及跨区价差 | 指定地点和期限的稀缺程度 | 船货、枢纽交付和终端零售价不能直接相减 |
| LNG产量、出口装船和进口卸货 | 供应链不同环节的实际流量 | 海上航程和在途库存使同月装船不等于同月卸货 |
| 工作气库存、同比和季节均值 | 已积累的缓冲 | 同时看需求、库容、提气能力与地理分布 |
| 液化产能与投产进度 | 潜在出口能力 | 最终投资决定、机械完工、试运行、商业爬坡均不同于实际产量 |
| 供暖/制冷天气、燃气发电及工业用气 | 需求组成和季节异常 | LNG进口下降可能来自国产气或管道气增加，也可能来自需求被价格压低 |

bcm是十亿立方米气体，Mt是百万吨LNG，MMBtu是能量；三者换算依赖温压和气体热值，不能把一种固定换算无条件套给所有船货。液化能力常按Mt/年计，是流量上限；库存bcm是时点存量。LNG也不同于LPG（主要为丙烷、丁烷）或CNG（压缩天然气），储运条件与可替代设备均不同。

## 本对象的历史与预期

### 从区域管道体系到跨区船货竞争

EIA记录，亚洲自20世纪70年代全球LNG贸易发展以来一直是最大的进口区域；美国LNG进口在2007年达到约771 Bcf，之后随着本土天然气生产及管网扩展而下降。这说明基础设施和产量变化可以改变一个地区在全球LNG体系中的角色，不能永久把其当作进口端。[S-C-COMMOD-04-01](#S-C-COMMOD-04-01)

### 2025年上下半年：同一年内供给节奏不同

IEA在2026-01-23的回顾估计，2025年全球LNG产量增加近7%、约38 bcm，其中约四分之三出现在下半年。上半年增量10 bcm仍部分被欧洲管道供应减少及补库吸收；下半年增量28 bcm，供给转松。该报告记载下半年TTF与亚洲现货LNG价格分别比2024年同期低14%和17%。这是随后发布的半年比较，不是2025年初已知结果。[S-C-COMMOD-04-06](#S-C-COMMOD-04-06)

**当时的2026年预测。** 同一份1月报告预计全球LNG产量增逾7%、超过40 bcm，亚太天然气需求增4%。这套判断依赖新增项目兑现和供应趋松，不是单纯把2025年增速机械外推。

### 2026年7月的更新：运输和供应中断改变年初展望

IEA于2026-07-07报告，2月底起霍尔木兹海峡运输受阻影响了此前近20%的全球LNG供应。3—6月卡塔尔及阿联酋装船同比减少35 bcm，其他地区增约27 bcm，全球净减少约8 bcm。其二季度价格统计为TTF约16美元/MMBtu、亚洲现货约17.5美元/MMBtu，分别同比涨32%与45%；3—6月亚洲相对欧洲平均溢价2.1美元/MMBtu，吸引可改目的地船货流向亚洲。[S-C-COMMOD-04-07](#S-C-COMMOD-04-07)

**7月信息集中的预测**已改为2026全年LNG供应大致持平、天然气需求下降约0.5%（20 bcm），并明确假设海峡第三季度全面重开、未受损设施在第四季度初恢复。它与1月展望的差异说明：有新增液化能力，仍可能因旧产区损失和运输约束而没有净增量。本页未核验7月以后恢复程度，不将这套情景称作制作日已实现结果。

**本库条件推演，2026-10-28整理：** 若运输恢复慢于7月假设，进口地区会继续通过高价吸引船货、提取库存和压低需求来平衡，冬季缓冲更薄；若恢复较快而天气温和，新项目增量更可能转成补库和较低的进口边际价格。需要用装船、卸货、工作气与工业负荷共同更新判断，单看国际报价回落不足以证明需求已经恢复。
