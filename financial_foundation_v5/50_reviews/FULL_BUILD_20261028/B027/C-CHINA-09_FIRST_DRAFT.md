# DR007、R007与同业存单

> 执笔：`/root/full_b027`；资料截止2026-10-19，定盘编制页于2026-10-28核读。历史资金利率数字取2024年上半年；2026年同业存单材料明确区分征求意见稿与已实施规则。

## 概念定义

DR007是银行间存款类金融机构以利率债为质押形成的7天期回购加权平均利率；R007是覆盖更广泛银行间参与者及合格质押券的7天期质押式回购加权平均利率。两者都是市场成交形成的资金价格，但统计对象不同。同业存单则是银行业存款类金融机构在银行间市场发行的记账式定期存款凭证，是可按发行和交易规则流通的货币市场工具。它自身有发行收益率及二级市场收益率，不是单一固定的“同业存单利率”。[S-C-CHINA-09-01](#S-C-CHINA-09-01)、[S-C-CHINA-09-02](#S-C-CHINA-09-02)、[S-C-CHINA-09-04](#S-C-CHINA-09-04)

把三个对象放在一起，是为了观察银行取得短期有担保资金、非银行参与者取得资金、银行锁定较长期批发负债的不同条件。它们不能拼成一个不分主体、期限和风险的“资金面数字”。

## 概念详解

### 回购的现金与抵押品

质押式回购中，融入资金的一方以合格债券出质，到期偿还现金本金和利息；出借方承担交易对手与担保品处置相关风险。债券的信用、流动性和可接受程度，以及对手方授信限额，都会影响能否成交和成交价格。利率低不代表所有机构都能取得相同额度。

DR把双方限定在存款类机构，并把质押品限定为国债、央行票据、政策性金融债等利率债，以减少参与者信用及担保品差异对利率观察的扰动。R范围更广，包含银行与证券、基金等非银行参与者之间的交易。因而R007不是“非银专属融资利率”：银行间符合DR口径的交易也属于更宽的市场范围。DR007也不等于政策利率，它是政策调节与市场供求共同形成的成交结果。[S-C-CHINA-09-01](#S-C-CHINA-09-01)、[S-C-CHINA-09-02](#S-C-CHINA-09-02)

按成交额加权的概念可以写为：

\[
\bar r=\frac{\sum_i V_i r_i}{\sum_i V_i}.
\]

\(V_i\)是纳入相应统计口径的第\(i\)笔成交金额，\(r_i\)是该笔年化利率，结果仍为年化利率；一日之内资金价格和成交结构都可能变化。交易笔数多但金额小的一组交易，未必主导加权结果。

### R007与DR007之差为何有信息，也为何不是纯风险溢价

银行拥有准备金账户并可经相应渠道获得央行资金，非银行机构通常需要银行或其他市场参与者提供回购融资。银行自身支付需要、资产负债表空间、授信与抵押品规则会影响再分配。如果银行间资金充足而向非银传导受阻，R007相对DR007可能上升。反过来，货币基金等非银持有大量现金、银行愿意融出时，差额可以缩小。

但两个指标不是相同机构、相同券种、相同时间交易的成对比较。**假设算例：** DR样本成交额80，利率1.5%；其余R样本成交额20，利率2.0%，则R007为1.6%，R减DR为10bp。若两组利率都不变，仅后一组交易份额由20%升到40%，R007便升至1.7%，差额升至20bp。价差扩大可以包含融资分层，也可以包含成交权重变化，需配合分机构融入融出、抵押品和盘中分布才能归因。这是本页的统计算例，不是任何交易日的真实数据。

### 同业存单把融资期限和发行人信用带入价格

银行发行存单取得期限资金，投资者则持有对该银行的债权。它不同于银行用已有债券作担保借入7天资金：持有存单直接暴露于发行银行履约能力，且可能在到期前需要卖出。发行人规模、资本与资产质量、信用认知、期限、发行供给及投资者偏好均可影响收益率。

投资者比较一年期存单与滚动7天回购时，比较的是未来一年滚动资金利率的预期路径，以及两种投资的信用、流动性和再投资风险差异。因此，一年期存单收益率低于当天DR007，并不自动构成套利：市场可能预期未来短率下降；今天借到7天资金，也不能保证未来一年按同价连续融资。持有存单期间，价格可能变化，融资额度可能缩减。

从发行银行看，发存单可以缓解存款流失或期限错配，但到期须兑付、重新发行需重新定价。发行量大不能直接解释为银行“缺钱”，也可能是主动置换其他更贵负债、提前锁定期限。应同时观察到期量、净融资和利率，而不是只看发行总额。投资者买入存单增加需求时，也会在其他条件相同下压低发行融资成本。

## 相近指标与观测口径

| 指标 | 应保留的区别 |
|---|---|
| DR007、R007 | 加权平均成交指标，关注主体、担保品、7天期限口径、成交时段及金额。跨节假日观察要核实际资金占用天数。 |
| FDR007、FR007 | 回购定盘利率，采用上午9:00—11:30交易样本的排序位置，且对相同对手、相同利率交易作去重处理；不是全天成交额加权平均。 |
| Shibor | 报价形成的同业拆放参考利率，不应与有担保回购成交指标当作同一价格。 |
| 存单发行利率 | 银行取得新资金的边际价格，须保存发行人、期限、评级、发行方式、规模与日期。 |
| 存单二级估值／成交收益率 | 已发行债权的市场价格；估值曲线与真实成交不同，期限应按剩余期限对齐。 |

交易中心定盘方案规定FR和FDR每天11:30起发布。其排序规则取\(\lfloor N/2\rfloor+1\)位置，偶数笔样本时不是两个中间利率的算术平均；无成交时有Shibor乘365/360的替代规则。这些细节影响衍生品合同结算，不能用DR007数据替代FDR007，也不能把定盘样本的去重规则套到全天加权指标。[S-C-CHINA-09-01](#S-C-CHINA-09-01)

观测融资压力宜比较同一日期的DR007与相应政策利率，同时看R007与DR007之差、盘中成交、银行净融出及同业存单期限结构。短期税款缴纳、政府债缴款、季末支付等均能改变资金供求；政策利率未变时，暂时性冲高并不足以证明政策转向。月均值、半年均值和单日收盘截面必须分别标示。

## 本对象的历史与预期

**2013—2017：存单融资工具与期限边界。** 2013年暂行办法建立存单制度；2017年8月30日人民银行公告修订期限条款，自9月1日起不再新发行超过1年的存单，列明1、3、6、9个月及1年，可固定或浮动计息，参考同期限Shibor定价。此前已发的较长期品种可以存续到期。该变化约束的是新发行期限，不能由此推断当日全部存量存单都立即缩短。[S-C-CHINA-09-03](#S-C-CHINA-09-03)

**2024：DR007与主要政策利率的接近。** 人民银行8月9日报告记录，2024年上半年DR007均值1.87%，较同期7天逆回购操作利率高7bp；6月末金融机构超额准备金率1.5%。这些数字对应银行体系总体环境，不能证明每家银行和非银均无流动性约束。7月22日逆回购转为固定利率、数量招标，操作利率由1.8%降至1.7%。报告解释其目的在于明确主要政策利率并提高操作效率；新增午后临时操作则用于平抑日间意外资金波动。[S-C-CHINA-09-02，印刷页1、11—13](#S-C-CHINA-09-02)

**2026年6月的存单修订提案。** 6月26日征求意见稿拟把DR等加入定价参考，同时写入临时额度、年内备案额度动态调整等安排。草案第22条生效日期仍为空白。本页取得的是完整草案转载，没有取得最终生效文本，因此这组内容只作为当时制度改进方向，不能把草案的范围与日期当成现行规则。[S-C-CHINA-09-04](#S-C-CHINA-09-04)

**2026年10月19日的政策沟通。** 潘功胜称DR001实际上已成为货币政策调控的目标利率，而主要政策操作期限仍为7天，并提出研究择机将主要操作品种切换为隔夜。因此，截至这次讲话，观察中国短端调控不能只看DR007，更不能把“目标利率”和“政策操作利率”当作已经同期限、同数值的对象。讲话给出未来方向，没有给出切换日期。[S-C-CHINA-09-05](#S-C-CHINA-09-05)

**本库条件推演（2026-10-28整理）。** 若隔夜调控及以DR为参考的产品增加，DR001在基准体系中的作用可能加强，但锁定跨周、跨月资金的需求仍会使DR007及存单期限价格有独立信息。若非银融资授信或抵押品条件收紧，即使隔夜银行间价格稳定，R007及终端融资成本仍可能波动；若银行增加期限负债而资管购买意愿不足，存单发行利率可能先于DR007上升。需要对照成交量与发行人构成，而非预设三个价格同步。未取得同期调查、完整2025—2026日频三类价格及发行结果，不能给出未来利差的数值区间或声称哪个渠道已主导2026行情。

## 涉及的关系

- [存款迁移的债市传导 R-CHINA-12](../20_mechanisms/R-CHINA-12.md)：居民转向理财等产品后，银行存款来源和资管机构对存单、短债的需求可以同时变化，一侧推动银行融资供给，另一侧影响存单购买价格。
