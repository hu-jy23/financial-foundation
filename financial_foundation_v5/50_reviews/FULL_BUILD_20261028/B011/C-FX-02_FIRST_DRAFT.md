# 人民币与离岸人民币

> 执笔：`/root/full_b011`；制作日2026-10-28。已取得的最新制度公告为2026-10-23；市场结构研究截至2026-08-27。本文没有2026-10-28的即期汇率、资金利率或实时跨境额度使用量。

## 概念定义

人民币是中国的货币。外汇交易中的CNY通常指在岸人民币市场，CNH通常指离岸人民币市场，香港是主要离岸中心。两者区别在于资金所在账户、适用市场及跨境流动规则，不是两个发行机构分别发行的货币，也不是两种不同面额的纸币。CME在清算通知中特别提醒，离岸结算银行也可能使用CNY代码，SWIFT报文同样使用CNY；因此仅看三个字母不足以确定合约的结算地和交付义务。[S-C-FX-02-01](#S-C-FX-02-01)

本页的核心对象是：**同一种计价单位，在存在跨境约束的两个资金市场中，形成不同即期价格、融资条件和可交付资产。** 人民币跨境使用如何形成更广的结算、融资与储备网络，归[人民币国际化](../20_mechanisms/R-RMB-INTERNATIONALIZATION.md)。

## 概念详解

### 同一种人民币，为什么会有两个美元报价

在岸市场服务境内银行、企业及获准进入的境外机构，人民币跨境收付与投资须经相应制度渠道。离岸机构可持有人民币存款、融资和交易，但把离岸余额转为境内可用资金，或反向汇出，并不意味着任何人都能无条件、无限额、即时完成。RBA研究者Joshua Brown将这一安排解释为：允许人民币在境外使用，同时保留境内资本流动管理。[S-C-FX-02-02](#S-C-FX-02-02)

设同一时点、同一结算日的美元兑在岸人民币为\(S_Y\)，美元兑离岸人民币为\(S_H\)，两者单位均为“元人民币／美元”。\(S_H>S_Y\)表示境外购买1美元需要更多人民币，即CNH相对CNY偏弱。这里的价差来自两地美元与人民币的供求、做市库存、资金成本和跨境约束。海外机构集中对冲人民币资产时，订单首先进入其可交易的离岸市场；境内出口商结汇、境内银行资金配置则可能形成另一组供求。

**假设算例。** 同时取得的报价分别为7.20和7.23，离岸价差为0.03元／美元；本页定义相对价差为\((S_H/S_Y-1)\times10,000\)，结果约41.7bp。这不是利率，也不是年化收益。它只把两个即期报价的相对距离换成基点。不同数据商可能反过来计算CNY减CNH，引用“价差扩大”时必须先交代符号。

表面上，交易者可以在便宜的一侧买美元、在昂贵的一侧卖美元。但闭合交易还必须将人民币本金合法调回原市场，覆盖两地结算时间差，并为期间库存融资。有跨境额度、用途或账户限制时，账面价差不等于可执行套利收益。合规贸易收付可以帮助连接市场，却不能把虚构贸易当作一般套利通道。

### 中间价与交易价分别承担什么功能

中国人民银行2014年第5号公告规定，自2014年3月17日起，银行间即期人民币兑美元交易价可在当日中间价上下2%以内浮动，较此前的1%扩大。该规则针对明确的在岸银行间即期市场，不是每天保证人民币只波动2%，更不是CNH的统一交易边界。[S-C-FX-02-03](#S-C-FX-02-03)

用当日中间价\(m_t\)表示这一制度区间：

\[
0.98m_t\leq S_{Y,t}\leq1.02m_t.
\]

各量都是人民币／美元；假设中间价为7.10，则上下边界是6.958和7.242。这是按上述制度计算的示意值，不是历史行情。中间价翌日可以调整，所以连续多日的累计变动不限于2%；中间价也不等于客户实际成交价。美元报价上升代表人民币对美元贬值，不能因“人民币汇率上升”这类口语省略报价方向。

中间价与收盘价的偏离，和CNY与CNH的偏离，是两种不同问题：前者描述境内成交相对制度参考点的位置，后者描述两地市场的分割程度。亦不能仅由前者推定央行当天实际买卖了多少外汇。

### 离岸人民币的资金价格也是独立对象

做空CNH通常需要取得人民币融资或形成远期人民币支付义务。融资利率突然上升，会提高维持空头的成本；需要人民币完成正常贸易付款的企业也同时受到影响。因此，离岸流动性管理不是只影响投机者的“汇率按钮”。资产有人民币面值、账上持有人民币债券，也不等于已在指定账户取得今天可交付的人民币现金。

离岸资金供给既可以来自存款、贸易收付和银行间拆借，也可以通过获准的跨境安排得到补充。2026年1月HKMA人民币业务资金安排RBF公告展示了具体链条：人民银行与HKMA的货币互换安排支持HKMA向参与银行提供人民币，银行再为符合条件的企业活动融资。这是有参与机构和用途的设施，不是向所有离岸持有人开放的无限兑换承诺。[S-C-FX-02-04](#S-C-FX-02-04)

假设企业持有一笔一个月后到期的人民币应收款，却需明天支付人民币工资，汇率风险可能很小，期限错配仍会带来融资需求。若企业买入CNH远期但合同实际应付CNY，还须处理跨境到账和结算地差异。这就是汇率对冲与付款能力必须分别检查的原因。

## 相近概念与边界

| 容易混淆的说法 | 应当区分的对象 |
|---|---|
| “离岸人民币是香港发行的人民币” | 离岸是市场和账户概念；香港的本地货币是港元，CNH并非港元的另一名称。 |
| “人民币国际化意味着资本项目完全开放” | 跨境贸易结算、境外融资、境外储备持有可在不同准入制度下分别扩大。 |
| “远期比即期贵，市场就预计人民币必贬” | 远期还反映两币融资条件、基差、期限和交易约束；其价格不能直接当作无偏预测，详见[利率平价](../20_mechanisms/R-FX-PARITY.md)。 |
| “在岸价与离岸价总能无成本互换” | 同币种不消除资金转移、用途、结算日和对手方信用条件。 |
| “总额度就是已经投放的资金” | 设施上限、已分配额度、提款余额和最终企业贷款分别计量。 |

人民币计价债券还须区分发行市场与发行人：境外主体境内发行的人民币债券与境外发行的人民币债券，不因同为人民币计价便具有相同准入、托管、流动性和信用风险。研究人民币资产回报时，币种只是其中一层。

## 观测与数据口径

首先保存同一时间的USD/CNY、USD/CNH、境内中间价和报价时间。境内休市、境外仍交易时，两个“最新价”可能隔了数小时；不能把信息到达的先后误判为可以成交的跨市场价差。

其次同时观察境内、离岸同期限融资价格，区分隔夜与三个月，区分银行间报价与特定客户可得利率；再看远期点、外汇掉期和[跨币种基差](../10_concepts/C-FX-10.md)。人民币突然偏强，可能伴随离岸现金紧张，也可能来自资产流入或预期变化，需要资金数量和操作公告共同辨认。

数量指标应分别记录香港人民币存款、债券余额、跨境收付、设施余额及结算使用量。存款是某时点存量，收付是期间流量；支付系统处理金额也可能包含金融交易，不能等同出口额或全球贸易份额。对照国际化指标时，储备、贸易、外汇交易和债券各用自己的分母。

## 本对象的历史与预期

**2013—2014：离岸产品与在岸波幅分别发展。** CME于2013年2月公告推出实物交割的USD/CNH期货，并解释代码与交割人民币的差别。次年在岸银行间波幅扩大至±2%。二者说明市场产品开放与在岸汇率制度调整是两个维度，不能用某种离岸衍生品的存在推定境内资本流动已完全自由。[S-C-FX-02-01](#S-C-FX-02-01)、[S-C-FX-02-03](#S-C-FX-02-03)

**2015—2017的压力，2026年的研究回顾。** Brown于2026年8月回顾，2015—2016的汇率压力和两地资金流动限制曾挤压CNH流动性，离岸隔夜利率一度超过70%，2015—2017离岸存款下降超过25%。这些是作者整理的历史口径，不是本文取得的逐日原始定盘，也不能把隔夜年化利率当成借一天损失70%。本页不指定未独立核实的单日峰值日期。[S-C-FX-02-02](#S-C-FX-02-02)

**2025—2026：从贸易融资扩展到企业业务资金。** HKMA的2026-01-26公告回顾：2025年2月设贸易融资流动资金安排，2025年10月由RBF取代及扩充；随后宣布自2026年2月2日起，总规模从人民币1,000亿元增至2,000亿元。原有1,000亿元额度已分配给40家银行，不表示已全额提款。合格活动扩展至资本开支及营运资金定期贷款，并覆盖参与银行境外集团内银行实体的企业客户。[S-C-FX-02-04](#S-C-FX-02-04)

**2026-10-23公告：做市流动性设施另有口径。** HKMA指定12家一级流动性提供行，自10月27日起任期两年；该计划专用人民币回购安排总额从200亿元增至220亿元。这是PLP计划，并非上述RBF再次从2,000亿元缩减至220亿元。两个数字服务不同设施与参与条件。[S-C-FX-02-05](#S-C-FX-02-05)

**有归属的判断。** Brown在2026-08-27研究中认为，政策仍在国际使用与资本流动控制之间渐进平衡，进一步国际使用有空间，但改革推进预计仍渐进；这不是人民币未来汇率点位预测。[S-C-FX-02-02](#S-C-FX-02-02) HKMA于2026-10-23认为PLP扩容有助加强离岸流动性和香港枢纽地位；这是制度设计者对设施作用的预期，不是已经识别出的价差收窄效果。[S-C-FX-02-05](#S-C-FX-02-05)

**本库条件推演，整理于2026-10-28：** 未来几个季度，如果银行取得的稳定人民币资金能够覆盖真实企业需求，并且资金能顺畅到达最终账户，离岸企业将较少依赖隔夜滚动融资，极端资金价格对跨境使用的阻碍可能减轻。但若用途、额度或抵押品限制在压力时约束实际提用，公布规模扩大仍可能与局部现金短缺并存。更新判断需要提款余额、期限分布及压力窗口报价；不由设施额度直接预测CNH升贬。
