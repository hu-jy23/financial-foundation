# 房地产开发与物业

> 执笔：`/root/resume_b048`。制作日2026-10-30；统计资料截至2026-10-19发布的2026年前三季度数据，制度材料按所列版本解释。

## 概念定义

房地产开发是把土地使用权、建设投入和资金组织成可出售或出租房屋的经营活动。其经济结果取决于销售价格与成本，也取决于收款、施工付款和债务到期能否衔接。物业在本页同时指建成后可经营的不动产及其管理服务：业主持有物业收租，是资产经营；物业服务企业按合同提供维护、清洁、秩序管理等服务，是服务经营。三者可以在同一集团，但资产、客户、收入来源和资金责任不同。物业服务合同及费用责任有独立制度依据。[S-C-SECTOR-06-02](#S-C-SECTOR-06-02)

本页以中国内地商品房开发为主要制度背景。租赁型资产的证券化与长期分派另见[REITs与基础设施资产](../10_concepts/REITs与基础设施资产.md)。

## 概念详解

### 销售、回款和交付是三张时间表

开发商先支付土地及前期费用，施工过程中持续购买材料和劳务。预售允许其在房屋完工前签约、收取定金或价款，因此一部分项目融资由购房款提供；开发商同时承担未来交付义务。预售许可并不等于房屋已经可交付。2004年修正的《城市商品房预售管理办法》规定许可条件，并要求预售款用于有关工程建设；具体资金监管办法由房地产管理部门制定。[S-C-SECTOR-06-01](#S-C-SECTOR-06-01)

签约金额衡量合同交易，回款衡量现金到账，交付衡量履约进展。取消合同、分期付款、按揭发放时滞，都会让三者分离。财务收入确认还需按适用会计准则与具体合同核定；不能把月度销售简报直接当利润表收入。本页没有核读具体公司的收入政策，不据此宣称所有项目均在同一时点确认收入。

监管账户资金即使在合并报表中列作现金，也未必能转给集团偿还债券。应按项目、账户和支付用途辨认可用资金。供应商同意延期收款可缓解当前现金压力，但应付款是后来必须支付的义务；它不会消除工程成本。集团债务重组和项目获得施工贷款也不同：后者可帮助继续交付，却未必足以恢复母公司的偿付能力。

### 利润可以为正，项目仍可能缺现金

以下是本库假设算例，金额均为亿元，不代表任何实际楼盘。项目预计销售100、土地和建造等全部成本80，预期项目毛利20；当前已支付40，已回款35，自有启动现金10，则当前现金为5。若下期必须再支付工程款20，只能新收款8且没有新融资，下期缺口为7。即使最终价格和成本预测成立，项目也不能仅凭20的预期利润准时支付。

可用一条按月份排列的收支式检查：

\[
C_t=C_{t-1}+R_t+F_t-K_t-D_t-T_t.
\]

\(C_t\)是期末可用于指定项目的现金，\(R_t\)是实际回款，\(F_t\)是新增可提款融资，\(K_t\)是土地、施工及经营付款，\(D_t\)是债务本金和利息，\(T_t\)是税费；同一币种金额，融资偿还和成本不得重复计入。这是现金分析框架，不是会计报表法定分类。应在每个付款日检查余额，而非只检验全年合计。

缩减拿地会立即节省部分资金，却减少未来可售资源；压低售价可能加速回款，却侵蚀利润，并可能改变其他购房人的等待意愿。结果取决于成交量对价格的反应，不能单由降价方向推断回款改善。融资对新项目的作用与对已售未交项目的作用也不同：前者支持扩张，后者首先用于完成既有义务。

### 物业服务为何不能直接等同开发商

物业服务收入主要由实际在管面积、收费标准和履约期间形成，现金还要乘以收缴效果。签约管理面积可能尚未交付，不能都视为当期收费面积。人员、外包和维护支出往往持续发生，服务费拖欠会形成营运资金占用。关联开发商的交付推迟，会延后新项目进入在管；关联方应收款增加也可能把开发风险传给服务企业。这是业务结构上的条件性解释，并非对全行业坏账规模的估算。

《物业管理条例》将已竣工未出售或未交付物业的服务费用安排给建设单位，且明确专项维修资金属于业主并有专门用途。因此，业主维修资金或代收水电费不能未经辨认就当作物业企业可自由分配的经营收益。[S-C-SECTOR-06-02](#S-C-SECTOR-06-02)

## 观测与口径

| 观察量 | 回答的问题 | 容易误读之处 |
|---|---|---|
| 合同销售面积、销售额 | 新签交易规模如何变化 | 金额／面积所得均价受城市与产品组合影响，不是同质房价指数 |
| 回款、定金及预收款、个人按揭资金 | 买方资金实际进入开发环节多少 | 行业累计到位资金不是企业期末现金余额 |
| 新开工、施工、竣工 | 项目处于哪个建设阶段 | 施工面积包含跨期项目，不能与当年新开工简单相加 |
| 竣工待售面积 | 已建成未售或未出租存量 | 不包含全部在建库存及土地储备；不是所有未来供给 |
| 自由现金、受限现金、债务到期表 | 能否跨过支付时点 | 合并余额不能代替项目可用余额 |
| 在管面积、收缴率、应收账款账龄 | 物业服务覆盖和变现质量 | 各公司收缴率分母、当年费与历史欠费口径需核对 |

前三项统计定义及待售口径依据统计局附注；其中销售是合同口径、到位资金是实际用于开发的货币资金，二者不能合并为同一个融资量。[S-C-SECTOR-06-03](#S-C-SECTOR-06-03)

## 本对象的历史与判断

预售制度把建设融资与居民购房连接起来，也使“卖出”之后仍存在完工任务。2024年政策进一步突出项目层面的融资与交付。2024-10-17发布会披露，截至10月16日白名单项目贷款审批通过2.23万亿元，并预期年底超过4万亿元；这是当时政策执行预期，不是全部已发放贷款。[S-C-SECTOR-06-04](#S-C-SECTOR-06-04)

后来的2025-02-06工作专班答记者问称，2024年末白名单审批通过金额超过5万亿元，保交房攻坚战实现373万套交付。它说明官方记录的审批与交付结果，不能由两个总量计算每套房贷款额，也不能把审批额度全部当作新增现金到账。专班当时表示2025年继续支持合格项目建设交付；本页不把这一政策方向改写为销售增长预测。[S-C-SECTOR-06-05](#S-C-SECTOR-06-05)

统计局2026-01-19公布，2025全年房地产开发投资82788亿元、同比下降17.2%；新建商品房销售额83937亿元、下降12.6%；到位资金93117亿元、下降13.4%。保交房推进与行业投资、销售收缩能够同时出现，因为政策支持既有项目完成，并不要求新项目扩张。[S-C-SECTOR-06-03](#S-C-SECTOR-06-03)

较晚的2026-10-19发布显示，2026年1—9月新房销售面积56483万平方米、同比下降13.2%，销售额53799亿元、下降13.9%；到位资金56813亿元、下降21.6%。其中定金及预收款17982亿元、个人按揭贷款7678亿元，分别下降14.8%和22.1%。同期二手房网签面积增长10.7%。新房开发现金流因此应与存量房交易区分，不能用二手成交活跃直接证明开发商回款转好。同比采用官方可比口径，不能用本次发布值与旧年度报道简单相除替代。[S-C-SECTOR-06-06](#S-C-SECTOR-06-06)

**本库条件推演，2026-10-30整理，展望未来数季而非点位预测：** 若买方回款继续弱于工程和债务付款，即使贷款政策延续，企业仍可能优先保交付、减少拿地；若销售改善同时转化为可用回款，且项目完工成本受控，才更有条件修复现金缓冲。更新判断应看回款、受限现金释放和债务到期，而非只看签约额。未取得同期企业现金预测调查，以上不是市场共识。
