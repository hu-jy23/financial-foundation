# REITs与基础设施资产

> 执笔：`/root/resume_b048`；2026-10-30制作。最新已核事件为2026-06-18；中国基础设施制度以2020指引及本页所列后续调整为阅读范围，未声称覆盖全部2026业务规则。

## 概念定义

REITs是不动产投资信托基金或相应公司型载体，将投资者资本集中到产生收入的不动产及相关资产，再按制度和合同向持有人分配收益。底层基础设施可以是仓储、收费交通设施、能源设施等，它们的价值来自可依法收取的租金、使用费或经营收入。REITs是持有和管理资产的金融载体，基础设施是经营资产；同一基础设施也可以由企业直接持有，不必发行REITs。[S-C-SECTOR-12-01](#S-C-SECTOR-12-01)、[S-C-SECTOR-12-02](#S-C-SECTOR-12-02)

本页重点解释中国公募基础设施REITs，同时保留美国制度对照。两地的法律形式、税收和分配基数不同，不能只凭同一英文缩写移植规则。

## 概念详解

### 从使用者付款到持有人分派

以仓储物业为例，租户支付租金，项目承担维护、人员、保险及税费，必要时还要进行屋顶翻修等资本支出。若有借款，还需支付利息和到期本金；剩余能够合法上划的资金经过项目公司、资产支持证券及基金层面安排，才成为持有人可分派现金。收入、净利润、经营现金流、可供分配金额和实际分派额分别描述这条链上的不同位置。

中国2020年指引的制度架构是：80%以上基金资产投资于基础设施资产支持证券并持有全部份额，通过项目公司取得底层资产所有权或经营权利；基金采取封闭式运作，年度分配不低于合并后可供分配金额的90%。这不是承诺本金的90%收益，也不是分配营业收入的90%。美国SEC的2016年投资者公告所述90%要求以应税收入为基数，两者分母不同。[S-C-SECTOR-12-01](#S-C-SECTOR-12-01)、[S-C-SECTOR-12-02](#S-C-SECTOR-12-02)

折旧、摊销会降低会计利润，却不必在当期发生等额现金支付；反过来，资本开支需要付款，却可能分期进入会计费用。因此，从利润推到可分配现金必须读取基金披露的调整表，不能一律用净利润加折旧。中国指引要求披露可供分配金额的计算过程、实际与测算差异，并披露重大运营现金流变化，为这种核对提供入口。[S-C-SECTOR-12-01](#S-C-SECTOR-12-01)

### 所有权与有限经营期影响分派的含义

长期出租物业仍需辨认土地使用权期限、建筑物剩余寿命与续期条件；收费公路等经营权项目还可能在特许经营期末移交。若经营权只有剩余20年，收到较高年度现金也可能包含对初始投入的逐步收回。不能把其现金分派率与永续资产的收入收益率直接比较。

用本库简化估值框架表示：

\[
V_0=\sum_{t=1}^{T}\frac{CF_t}{(1+r)^t}+\frac{RV_T}{(1+r)^T}.
\]

\(CF_t\)是第\(t\)年末支付给选定资本层级的现金，\(r\)为匹配该现金风险、币种和名义／实际口径的年折现率，\(T\)是权利剩余年数，\(RV_T\)是依法可归持有人的期末剩余价值。若使用股东现金流，应采用权益折现率；若用偿债前项目现金流，则需另处理债务价值。经营权无偿到期且无其他剩余权利时，不能擅自添入永续终值。

**假设算例：** 每年末分派10、剩余20年、无终值，折现率5%时现值约124.62，首年现金／价格约8.02%，但内部收益率仍为5%。8.02%中的一部分是本金回收。若折现率升至6%、现金不变，现值约114.70，下降7.96%。这些是年金公式计算，不是某只REIT的估值或实际回报。

### 利率通过估值和经营融资两条路进入

投资者要求的回报提高，会降低固定未来现金的现值；项目有浮息债务或需要再融资时，利息支出也可能增加。若旧债固定利率且较晚到期，第二条路径滞后，但市场价格可先反应第一条路径。与此同时，经济增长或租约指数化可能提高租金，抵消部分折现压力；租户支付能力恶化则可能同时降低现金、提高风险补偿。SEC亦提示不同REIT的利率敏感性依资产及融资结构而异。[S-C-SECTOR-12-02](#S-C-SECTOR-12-02)

对成熟、持续经营且可近似恒定增长的资产，\(V\approx CF_1/(r-g)\)有助于展示增长率\(g\)与折现率的相互作用，但须满足\(r>g\)且现金可持续。有限收费权、到期集中租约、大额更新支出不能不加修正地套用这一永续式。公开交易的份额价格还受资金供需和流动性影响，评估净值并非随时可成交的清算价格。

### 扩募既能增长，也要求按份额检查

高比例分配减少内部留存，新增资产往往需要扩募或借款。原始权益人出售成熟项目可以回收资本用于新投资，持有人则取得后续经营收益的权益。新增资产总收入再大，若购买价格过高、融资成本过高或份额增加过快，原持有人每份现金流仍可能下降。因此应比较扩募前后的单位可分配现金、风险和剩余年限，而不只看资产规模。

管理人、运营机构、原始权益人之间若有关联关系，购买定价和管理费会改变利益分配。资产法律隔离有助于界定财产归属，却不消除对关联运营能力和服务合同的依赖。2020指引明确基金财产独立性及关联交易披露要求；它没有提供原始权益人兜底承诺。[S-C-SECTOR-12-01](#S-C-SECTOR-12-01)

## 观测口径与边界

| 量 | 应如何读 |
|---|---|
| 出租率、租金、收缴率 | 前者看空间利用，后两者看单位收入与实际收款；需核免租期、租约到期与租户集中度 |
| 车流量、电量、收费或电价 | 数量乘单价后还要扣成本；政策定价、补贴到账与可用率决定现金转换 |
| 现金分派率 | 明确过去十二个月还是预测全年、分母为发行价还是市价；价格跌也会机械抬高该比例 |
| 可供分配金额 | 看利润调节、营运资金、资本支出和保留现金；实际分派另列 |
| NAV与评估值 | 核估值日、折现率、剩余权利和终值；账面净资产与评估资产价值不必相同 |
| 杠杆与到期表 | 穿透项目层借款，区分固定／浮动利率、现金受限与再融资时点 |

REITs份额是权益类风险承担，不是固定票息债券；高分派并不消除本金波动。美国抵押型REIT持有按揭贷款或证券，与直接运营物业的权益型REIT有不同的杠杆和利率风险；本文没有把其资金结构移植给中国基础设施基金。[S-C-SECTOR-12-02](#S-C-SECTOR-12-02)

## 历史、近期状态与预期

2020年中国建立公募基础设施基金试点制度，重点从成熟资产中获得运营现金流。2023-10-20证监会修改第五十条，将试点资产扩至消费基础设施；2024年发改投资〔2024〕1014号通知于7月26日公布、8月1日起实施，推动常态化发行，同时要求审慎披露未来收入预测假设。制度扩大可入池资产集合，没有改变资产经营收入仍可能波动的事实。[S-C-SECTOR-12-01](#S-C-SECTOR-12-01)、[S-C-SECTOR-12-03](#S-C-SECTOR-12-03)、[S-C-SECTOR-12-04](#S-C-SECTOR-12-04)

2025-09-12公布的782号通知继续支持扩围，并允许首次上市满6个月后申报新购入项目，支持同类及有关联性的跨行业项目，但原则上保持所有权类／经营收益权类一致。这里保存的是申报政策条件，不代表所有申请都会完成或带来收益增厚。[S-C-SECTOR-12-05](#S-C-SECTOR-12-05)

2026年4月上交所对2025年报的汇总覆盖沪市52只产品：营业收入145亿元，同比增长71%；可供分配金额88亿元，同比增长42%。这是随产品数量与资产范围变化的总量，不能直接解释为同一资产组合的内生增长率。该汇总还称产业园和仓储物流单位租金承压，说明不同业态并非同步改善。[S-C-SECTOR-12-06](#S-C-SECTOR-12-06)

2026-06-18上交所公告首批4只商业不动产REITs上市，募集约203亿元，底层包括商业零售与办公楼。这是比本页基础设施制度底稿更晚的产品边界扩展；商业不动产试点的完整特别规则未逐条核读，因此不能仅凭该事件断言所有商业资产适用2020指引的同一门槛。[S-C-SECTOR-12-07](#S-C-SECTOR-12-07)

**本库条件推演，2026-10-30整理，未来一至两年：** 常态化发行与扩募可增加资产多样性，但收益取决于收购估值、每份现金增长及运营兑现。若利率下降而租金不恶化，估值有支持；若降息伴随空置和欠租上升，现金下修可能抵消折现收益。需要逐季观察同项目指标和每份现金，而非把发行数量当回报预测。未取得覆盖全市场的同期盈利预测调查，不声称这是市场一致预期。
