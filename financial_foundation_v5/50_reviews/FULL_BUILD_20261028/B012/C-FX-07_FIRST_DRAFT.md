# 美元指数DXY与广义美元指数

> 执笔：`/root/full_b012`，GPT-6-Astra，medium；2026-10-28制作。已核Fed 2026-02-02权重、截至2026-08-12更正公告和2026-10-26标注更新的指数说明页；未提取制作日即时报价。

## 概念定义

美元指数把美元相对多种货币的变化按既定规则合成为一个数。DXY通常指ICE U.S. Dollar Index（亦称USDX），是六种货币的固定权重几何指数；本页的“广义美元指数”特指美联储按美国主要贸易伙伴构建的Broad Dollar Index。两者上涨均表示美元相对各自篮子升值，但篮子、权重更新与用途不同。“美元涨了多少”若没有注明指数，就尚未给出完整的测量对象。[S-C-FX-07-01](#S-C-FX-07-01)、[S-C-FX-07-03](#S-C-FX-07-03)

指数是测量工具，不是美元价值的唯一真实尺度。以欧元支付采购款的公司、以人民币记账的投资者、研究美国整体贸易竞争力的分析者，面对的是不同的相关汇率组合。

## 概念详解

### DXY的六种货币与固定权重

ICE公布的DXY构成为：

| 货币 | 固定权重 |
|---|---:|
| 欧元 EUR | 57.6% |
| 日元 JPY | 13.6% |
| 英镑 GBP | 11.9% |
| 加拿大元 CAD | 9.1% |
| 瑞典克朗 SEK | 4.2% |
| 瑞士法郎 CHF | 3.6% |
| 合计 | 100.0% |

该权重不是每年按美国当期贸易量重新计算。ICE说明，指数成分仅在1999年1月欧元推出时变更过一次，原有相关欧洲货币的合计权重由欧元承接，保持57.6%。人民币、墨西哥比索等重要贸易伙伴货币不在DXY中。[S-C-FX-07-01](#S-C-FX-07-01)、[S-C-FX-07-02](#S-C-FX-07-02)

因此，DXY对欧元美元汇率尤其敏感。欧洲自身的消息就可能显著改变DXY，不能把其每次上涨都解释成美国独有的冲击。固定篮子的优点是暴露定义相对稳定；代价是它不会自动追随美国贸易结构变化。

### 几何平均怎样合成变化

用统一报价写最容易避免方向错误。设\(e_{j,t}\)为时点\(t\)每1美元可兑换的第\(j\)种外币数量，\(w_j\)为该币权重，小数表示且合计为1。固定权重指数在两时点的变化可写为：

\[
\frac{I_t}{I_0}=\prod_j\left(\frac{e_{j,t}}{e_{j,0}}\right)^{w_j}.
\]

\(I\)是无量纲指数点，两个汇率必须同单位；各汇率比值也无量纲。这是几何平均定义的相对变化表达，不涉及复原DXY的初始标定常数。若数据用“美元／欧元”报价，必须先取倒数，或等价地在其变化因子上使用负的欧元权重。不能把EUR/USD上涨直接当作美元升值。

**假设算例一：** 其他五种货币不变，EUR/USD从1.10升至1.21，即欧元以美元计价上涨10%。美元对欧元的变化因子是\(1.10/1.21=1/1.10\)，DXY变化为\((1/1.10)^{0.576}-1\approx-5.34\%\)。若起点指数为100，终点约94.66。近似使用“10%乘57.6%”会得到−5.76%，只适合变动较小的一阶估算；百分比倒数关系和几何复合使精确值不同。此为自行构造算例，不是历史行情。

指数权重说明的是对汇率**比例变化**的敏感度，不是美元现金持仓比重。日元报价数值约为欧元报价的多少倍，也不意味着日元对指数贡献更大；相对变化与权重才决定贡献。

### 广义指数为什么更广，权重又怎样形成

Fed构建广义指数的目的，是帮助评估汇率变化对美国国际贸易的整体影响。2019年起采用货物与服务双边贸易合计的份额，并剔除石油、黄金和军事装备等类别。货币组成定期审查，权重随年度贸易数据更新；广义指数还可分为先进外国经济体AFE与新兴市场经济体EME子指数。[S-C-FX-07-03](#S-C-FX-07-03)

“贸易加权”并不是按外汇成交量、股票市值、外汇储备配置或跨境美元债务加权。广义指数适合贸易问题，也不能自动充当所有金融敞口的最佳代理。银行的美元负债主要集中在哪些国家、企业收入以什么货币计价，仍需另查。

下表摘录**2026年2月2日生效的权重表中2026列**，单位为百分比；用其与DXY比较组成，不将新表中的历史列冒充早年实时版本：[S-C-FX-07-04](#S-C-FX-07-04)

| 货币／经济体 | Fed广义指数2026权重 | DXY权重 |
|---|---:|---:|
| 欧元区 | 21.007 | 57.6 |
| 墨西哥 | 14.801 | 0 |
| 加拿大 | 12.769 | 9.1 |
| 中国 | 10.891 | 0 |
| 英国 | 5.246 | 11.9 |
| 日本 | 5.182 | 13.6 |
| 瑞士 | 2.975 | 3.6 |
| 瑞典 | 0.624 | 4.2 |
| 其他入篮经济体合计 | 26.505 | 0 |

最后一行由100减去本表已列Fed权重得到，并非单一币种。把某币的DXY权重写0表示未入该篮子，不表示该币对美国经济没有意义。

Fed采用链式几何合成。设\(I_{t-1}\)为上期指数，\(w_{j,t}\)为该期实际采用的权重，\(N_t\)为币种数，则：

\[
I_t=I_{t-1}\prod_{j=1}^{N_t}\left(\frac{e_{j,t}}{e_{j,t-1}}\right)^{w_{j,t}},\qquad \sum_jw_{j,t}=1.
\]

这里\(t\)表示相邻观测时点，并不表示每一天都重新估贸易权重。跨越不同权重期时，应按各段使用的权重连接，不能用今天权重乘几十年前的汇率变化来复原官方全历史。公式来自Fed方法说明；后面的反事实算例只比较一次给定权重下的变化。[S-C-FX-07-03](#S-C-FX-07-03)

**假设算例二：** 仅“人民币／美元”报价上升10%，所有其他汇率不变。按上述2026权重，广义指数约升\(1.10^{0.10891}-1=1.04\%\)，DXY机械上不变。两个指数在这一设定下都计算正确，分歧来自问题定义。现实中货币可能共同变化，但相关性不是指数公式的一部分。

## 名义、实际、现货指数和投资回报的边界

Fed同时提供名义与实际指数。实际指数用消费者价格指数作调整，帮助比较价格水平变化后的相对价值；实际序列只按月提供，名义序列有日频和月频。[S-C-FX-07-05](#S-C-FX-07-05) 美元名义汇率不动而美国物价相对更快上涨时，实际升值仍可发生。实际指数不是单纯把名义指数换个基期，也不是DXY的另一名称。

指数点位受基期选择影响。100没有“美元合理价值”的含义，120不代表美元高估20%；判断高估还需要一个购买力、贸易、资产收益或其他均衡框架。同样，两种指数一个报100、另一个报120，无法据此判断哪一种显示美元更强，应该比较同一观察窗口的百分比变化。

ICE的现货指数以成分货币即期买卖报价中点计算。期货是以该指数为基准的可交易合约，基金回报还可能受到持仓、展期、抵押现金收益和费用影响。不能把DXY现货涨幅直接当作任意“做多美元基金”的净回报。[S-C-FX-07-01](#S-C-FX-07-01)

## 观测与版本管理

记录指数时至少保留提供者、系列全名、名义／实际、频率、观测时点、基期及下载日期。若研究一个事件，DXY盘中变化应与同一时间窗口的其他资产比较，不能拿盘中低点与Fed日频或月均值直接比较。分解贡献时，先统一“外币／美元”的方向，再使用对应权重。

权重更新可能改变Fed历史指数。另有技术更正：Fed于2026年5月11日公告修正5月1日G.5发布后出现的部分历史广义、AFE和EME数据错误；8月12日公告修正8月10日H.10所含8月3日各币及指数错误。这些不是经济走势本身，而是数据版本变化。[S-C-FX-07-06](#S-C-FX-07-06)

本次还发现官方网页内部时点不一致：Nominal/Real Indexes页标注2026-10-26更新，但正文仍写权重上次修订于2025-03-24；独立权重页和公告明确写2026-02-02生效。因此本页采用后两者的具体权重日期，保留前者用于名义／实际系列和修订规则，不照抄过时摘要。这也说明“网页今天可见”不能替代逐项版本核验。

## 本对象的历史与有归属的判断

### DXY：连续性来自保持篮子，而非保持贸易代表性

ICE记载指数于1973年3月推出，1999年欧元转换是唯一成分变更。原有欧洲币种被同一欧元替代后，指数仍保留历史合计暴露。[S-C-FX-07-01](#S-C-FX-07-01) 对研究者而言，固定篮子便于保持相似的外汇风险定义；对贸易研究而言，几十年中贸易伙伴重要性已经变化，固定篮子会逐渐偏离当期结构。这是本库据构造作出的测量判断，不是指数发行人的收益预测。

### Fed：2019年方法变更与2026年权重

2019年2月4日新方法生效，增加服务贸易、改变权重计算并纳入越南、剔除委内瑞拉。Fed同时提供从2006年1月2日开始的新口径官方历史序列，更早重建需要估计服务贸易权重。方法调整因而改变“历史上的美元表现如何被测量”，不能假设当时投资者已经见到后来回算值。[S-C-FX-07-03](#S-C-FX-07-03)

2026年权重表显示欧元区21.007%、墨西哥14.801%、加拿大12.769%、中国10.891%，四项合计**59.468%**。这是当前表所定义的贸易暴露，与DXY欧元单项57.6%的集中程度有实质差异。此前权重版本使用期为2025年3月24日至2026年1月30日。[S-C-FX-07-04](#S-C-FX-07-04)

**本库条件判断，2026-10-28整理。** 若未来一段时间变化主要集中在欧元，DXY通常比广义指数反应更大；若集中在人民币或墨西哥比索，两者可能明显分离。该判断指其他汇率变化相对较小时的构造敏感性，不预测哪种货币下一步涨跌。没有取得同期专业机构对两个指数的同期限点位预测，也未下载2024—2026完整行情来检验实际分歧幅度，因此不把测量规则写成市场共识或历史收益结论。
