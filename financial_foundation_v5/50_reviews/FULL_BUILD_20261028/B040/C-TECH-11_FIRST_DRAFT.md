# 散热与液冷

> 执笔：`/root/resume_b040`；2026-10-30制作。设备资料覆盖至2026-09-17更新的DGX硬件指南；历史实验按原报告年份保存，未取得2026年行业渗透率。

## 概念定义

散热是把计算设备运行产生的热量，从芯片及其他器件转移到最终可以接受热量的环境或用热设施，使设备在允许温度内工作。液冷是其中用液体承担重要传热环节的一类方法；本页重点是液体接近服务器热源的冷板和浸没方案，以及它们与机房冷却系统的衔接。

机房有冷冻水管，不一定就是通常产业讨论中的服务器液冷。传统风冷服务器仍先把热交给空气，再由机房空调转入水回路。直接液冷把部分热量在更靠近芯片的位置交给液体，减少空气搬运环节，但热量仍须最终排到室外或被利用。美国能源部FEMP的系统示意分别说明了这两条路径。[S-C-TECH-11-01](#S-C-TECH-11-01)

## 概念详解

### 功率、功率密度和温度是三个不同问题

在稳态、忽略储能等小项时，服务器消耗的电功率大体最终变成热负荷。100 kW机架需要持续处理相近量级的热量；kW是功率，运行一小时对应约100 kWh能量，不能把两者混写。

相同总功率集中在更小芯片面积上，会提高局部热流密度；相同机房功率集中在更少机架中，会提高单机架密度。这两种密度对设备的要求不同：前者考验芯片界面和冷板，后者还考验风量、管路、配电、楼板承重和维护空间。多装一台机房空调未必能解决芯片局部过热。

可以用简化热阻模型理解温度：\(T_j-T_f=Q R_\theta\)。\(T_j\)是芯片结温，\(T_f\)是选定参考流体温度，\(Q\)为穿过该热路径的热功率（W），\(R_\theta\)为对应等效热阻（K/W）。相同功率下，降低界面或换热热阻能降低结温；提高进液温度虽有利于外部节能，却会减少芯片温度余量。它是近似稳态关系，实际热阻会随流量、结构和工况变化，不能据此给出所有芯片的统一进水温度。

### 一条液冷热路径有哪些设备

冷板接触CPU或GPU封装，通过内部流道带走热量。多块冷板通过管路和分配歧管连接。冷却液分配单元CDU承担循环、换热与控制等功能，常用换热器把服务器侧回路与设施侧回路隔开，便于分别管理水质、压力和温度。设施侧再通过冷水机、冷却塔或干式冷却器排热，具体组合依气候和允许水温决定。

这里的“直接到芯片”通常不是让普通水直接碰到裸露电路，而是热量先穿过封装、界面材料和冷板壁面。冷板未覆盖的内存、存储、网卡或电源等仍可能需要空气冷却。2026年DGX指南明确描述CPU/GPU冷板与其余部分风冷并存，所以“液冷机架”不能自动解释成100%的热由液体带走。[S-C-TECH-11-04](#S-C-TECH-11-04)

单相循环的热平衡可写为：

\[
Q=\dot m c_p(T_{out}-T_{in}).
\]

\(\dot m\)为质量流量kg/s，\(c_p\)为比热kJ/(kg·K)，温差用K，结果为kW。**假设算例：**液体承担100 kW，近似取水的比热4.18 kJ/(kg·K)、供回液温差10 K，所需流量约2.39 kg/s，按1 kg/L近似约143 L/min。这是循环流量，不是每分钟消耗143升新水；闭式回路主要循环同一批液体。实际混合液物性、管阻、旁路和安全余量需另计。

### 冷板与浸没、单相与两相

| 方案 | 热量怎样离开电子设备 | 主要工程区别 |
|---|---|---|
| 冷板 | 热先传到贴在主要器件上的冷板，再交给内部流体 | 容易围绕现有机架组织，但连接、漏液检测及未覆盖器件散热要一起设计 |
| 单相浸没 | 设备浸在绝缘液中，液体升温并通过自然或强制循环传热 | 电子部件、线缆、密封材料须与浸没液长期相容 |
| 两相浸没 | 绝缘液吸热汽化，再由冷凝器凝结回流 | 需要管理沸腾、蒸气与冷凝过程，不能只按单相流量公式选型 |

“冷板／浸没”按液体接触设备的方式分类，“单相／两相”按是否发生相变分类；冷板也可以采用两相方案。OCP的流体规范明确区分这两个维度，并强调热性能、信号完整性、材料相容性与维护共同构成选液条件。[S-C-TECH-11-02](#S-C-TECH-11-02)

### 节能收益发生在哪里

液冷可能减少服务器风扇电耗，降低机房空气处理需求，并允许更高供液温度，从而增加不用压缩式制冷机的运行时间。但“更高水温”仍须满足芯片温度约束；室外温度过高时，干式冷却器也可能无法提供足够温差。泵、控制和备用系统继续消耗能量。散热方式的优劣要比较整个运行工况，而不是只比较某个换热器的效率。

LBNL的2014年实验把38台改造服务器与2台对照服务器配合，先测液体捕获热量和服务器用电，再模拟整站不同冷却配置。其结论在平均服务器负载50%的设定下，整站节能约14%—20%；作者还指出，沿用已有冷水机虽然运行节省较少，改造总成本可能更有利。这是指定原型及模型结果，不是所有液冷项目实测节电率。[S-C-TECH-11-03](#S-C-TECH-11-03)

## 观测与成本口径

PUE为同一边界、同一期间的设施总能耗除以IT设备能耗；WUE在FEMP采用的现场口径中为年用水升数除以IT年用电kWh。[S-C-TECH-11-01](#S-C-TECH-11-01) PUE计入的额外设施能耗不仅是冷却，还包括供配电等损耗。一个瞬时设计值不能替代全年实测值，寒冷地区与炎热地区也不能仅凭PUE高低比较设备技术。

**本库假设算例：**IT用电100 MWh、设施额外用电40 MWh时，PUE=1.40。改造后IT因风扇减少降为90 MWh、设施额外用电30 MWh，总用电从140降到120 MWh，节省14.3%，PUE却只降至1.33。IT侧节能同时缩小分母，因此PUE变化不能完整代表总节电。若IT负载随业务扩张大幅增加，PUE下降也可能伴随总用电上升。

液冷是否节水取决于最终排热方式。服务器闭环循环水量很大，可以同时只有很少补水；外部冷却塔则可能通过蒸发消耗水。采用干式排热可以降低现场水耗，但在某些气候和温度条件下可能增加电耗或设备面积。现场WUE也不含发电环节的全部间接用水，比较时必须保留边界。

| 要观察的量 | 为什么有用 |
|---|---|
| 芯片功率与结温、进出液温及流量 | 判断局部换热是否满足实际负载，而非只看标称冷量 |
| 液体捕热比例及剩余风冷负荷 | 决定机房空气冷却能缩小多少；捕热比例不是节电比例 |
| 机架kW、设施MW及冗余 | 区分单点密度与总容量，备用设备额定功率不能全算作日常负载 |
| 全年电、水与IT有效产出 | 区分设施效率、设备效率和业务增长 |
| CDU、冷板、管路及施工成本 | 拆清设备售价、整机价值与工程安装费用，避免产业规模重复计数 |
| 维护、漏液与恢复记录 | 决定可用性和运营成本；有漏液检测不等于已测得零故障 |

总拥有成本还应计入改造停机、冷却液维护、备用能力和设备寿命。若供电容量固定，降低辅助用电可以释放更多电给计算；若芯片已受温度限制，改善散热可减少降频。两者属于不同收益，不能把同一份性能改善重复计价。

## 本对象的历史与预期

2014年的LBNL原型研究说明，液冷在生成式AI热潮之前已是服务器节能与余热利用的研究方向。研究同时发现供回液温度提高可能减少捕热量，提示“更容易利用的高温余热”与“尽量多捕获热”之间存在设计权衡。其未来研究建议是改善热路径理解及捕热比例，并非预测某年液冷市场规模。[S-C-TECH-11-03](#S-C-TECH-11-03)

2022年OCP公布浸没液基础规范，研究重点延伸到供应链兼容性：不同液体使设备厂商逐项验证变得困难，统一性能与材料要求有助于减少重复测试。这显示产业化不仅取决于能否降温，也取决于多代设备是否能维护与互换。[S-C-TECH-11-02](#S-C-TECH-11-02)

2024-10-15，NVIDIA公开GB200 NVL72机架与计算／交换托盘设计贡献，文章以120 kW冷却能力需求说明采用直接液冷，并介绍歧管和浮动盲插连接的对接设计。高密度计算把液冷从独立附件变成机架结构的一部分。[S-C-TECH-11-05](#S-C-TECH-11-05)

2026-09-17更新的DGX指南列出NVL72机架18个计算托盘、9个NVLink交换托盘，并继续描述液冷与风冷共存及漏液检测。这是产品配置证据，不能据此估算全行业液冷渗透率或客户实测PUE。[S-C-TECH-11-04](#S-C-TECH-11-04)

**本库条件推演，2026-10-30整理：**在未来几代高功率密度系统中，若客户继续提高单架计算密度，冷板、CDU与设施工程的协同会比单件冷量更重要。既有机房是否具备可用水路、电力和地板承载，会影响交付节奏。对低密度、已有良好气流组织的存量机房，全面液冷改造的经济性仍须由节能、维护及新增计算容量共同证明。本文未取得客户订单和项目回收期，以上不是厂商营收预测。
