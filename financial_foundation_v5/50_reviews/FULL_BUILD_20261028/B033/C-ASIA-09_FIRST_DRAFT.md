# IPO、再融资与退市

> 执笔：`/root/full_b033`，GPT-6-Astra，medium；制作日2026-10-28。发行统计覆盖内地2024自然年、香港2025自然年；制度历史主要核至2024-12-23，不声称逐项覆盖2026年的现行规则。

## 概念定义

IPO是公司首次公开发行股票并进入公开交易市场的融资过程；再融资是已上市公司进一步发行股票或其他证券取得资金或资产；退市是证券终止在某一交易所上市交易。三者分别改变上市权益的进入、扩张和退出，但并不互为简单逆操作：发行新股可以给公司增加资本，出售老股的款项归出售股东；退市可能伴随现金收购，也可能只改变股票交易场所，而不向原股东返还本金。

本页以中国内地股票市场和香港股票市场为主要范围，讨论权益供给、股东权益和制度事件。再融资中的可转债兼有债务与潜在权益属性，发行时和转股时应分别处理。公司在A股已上市后首次发行H股，在香港市场可以列作IPO；从公司整体看，它已经是上市公司，因此不同统计口径下的“首次”并不相同。

## 概念详解

### 1．先分清谁收到钱、谁获得什么

| 行为 | 公司与股东之间的变化 | 对公开市场供给的含义 |
|---|---|---|
| IPO发行新股 | 认购者付款给发行人，扣除发行费用后增加公司资金；总股数增加 | 新增上市投资对象和可交易股份，部分股份可能锁定 |
| IPO中的老股出售、上市后股东减持 | 买家付款给原股东；公司一般不因此收到新增资本 | 原有权益换手，可能增加公众持股，但不是新增股本融资 |
| 增发、配股 | 新投资者或原股东追加资金，发行人增加股本及资金 | 发行对象、定价、认购权和锁定期决定谁承接新增股份 |
| 发行股份购买资产 | 公司以新股交换资产，新增股数但不一定收到现金 | 股本增加，资产负债表加入被收购资产；不能全记作市场现金“抽走” |
| 可转债 | 发行时取得债务融资，转股前可能有利息和到期偿还义务 | 转股形成普通股；不能同时把债券发行额和转股股数当成两笔现金融资 |
| 退市 | 上市交易资格终止；股东可能收到收购款、换股或继续持有非上市权益 | 去掉一个上市证券不等于注销全部公司资产，也不等于给市场注入等额现金 |

证券发行审核与交易所上市条件也应分开。2023年全面注册制的制度安排明确，交易所审核和证监会注册各有职责，信息披露、保荐承销、监管执法和投资者保护一起构成框架。注册生效表示发行获得相应程序许可，不是监管者保证发行价合理、公司盈利或投资回报。[S-C-ASIA-09-01](#S-C-ASIA-09-01)

### 2．稀释不等于财富按股数同比消失

假定公司原有普通股数为\(N\)，权益合理价值为\(V\)，按每股\(P_s\)发行\(n\)股新股，忽略费用及项目消息效应。发行完成后的每股价值为：

\[
P_{\text{after}}=\frac{V+nP_s}{N+n}.
\]

金额、股价及股数单位须匹配。新股增加分母，也给公司带来\(nP_s\)资金；只把原价值除以更多股数，会漏掉这项资产。若\(P_s<V/N\)，且旧股东没有获得可补偿的认购权或其他利益，低价发行会把部分原有价值转给新股东。若募集项目的净现值为正，公司的经济价值又可能增加，必须另作评估。

**假设算例。** 原股数1亿股、权益价值10亿元，原每股价值10元。新发2000万股，每股8元，取得1.6亿元。忽略其他变化，发行后每股价值为\(11.6亿元/1.2亿股=9.67元\)。持有100万股且不认购的股东，持股比例由1%降为0.833%，但每股价值下降约3.33%，并非16.67%。若按比例配股，原股东追加出资可以维持持股比例；其总投入也随之增加。

每股收益稀释还涉及时间。假设原年度利润1亿元、全年原股数1亿股，每股收益1元；新发2000万股且全年没有新增利润，简化全年口径降为0.833元。实际财报基本每股收益采用加权平均股数，年末发行不能按全年新股数计算；项目投入后新增利润、发行费用、债务偿还节息及可转债的潜在稀释又会改变结果。因此，要分别观察持股比例、每股收益、每股资产价值和股东总财富。

### 3．发行“抽水”究竟约束什么

认购发生时，投资者必须提供可结算资金。在现金预算、融资额度或风险预算较紧时，投资者可能出售现有股票来认购新股，承销商也要为分销和库存安排资金。这是短期发行供给可能压低同类资产价格的具体路径。影响取决于发行相对市场可用资金的规模、认购者来自哪里、结算安排及其他资金流入，而不是IPO家数单独决定。

认购款进入企业账户后仍是金融体系中某个主体的存款，随后可用于设备、工资、还债或收购；它并没有永久从经济中消失。另一方面，资金留在银行体系，也不意味着它会立即回到股票买盘。必须把银行体系资金、证券账户现金、投资者风险承受能力和企业投资用途分开。

中期还存在反向选择：估值较高、融资需求旺盛时企业更愿意上市，投资者需求好也使发行更容易完成。观察到IPO多与市场下跌先后相伴，不能排除先前高估值、盈利预期变化和政策收紧等共同因素。2023-08-27证监会把收紧IPO节奏和融资必要性、发行时机、前次募资使用效果并列，是监管对当时一二级市场平衡的政策安排，不能解释为所有时期发行额与指数涨跌的固定函数。[S-C-ASIA-09-02](#S-C-ASIA-09-02)

### 4．退市对应不同的价值结局

强制退市可以由财务、交易、规范运作或重大违法等不同条件触发。经营恶化可能同时降低公司价值和导致退市；退市又会减少交易渠道、流动性及机构可持有性。分析损失时应分清经营和违法造成的价值损害，以及上市资格变化造成的额外折价。

主动退市通常有私有化、吸收合并等具体交易安排。股东最终收到什么，取决于收购价、换股比例、现金选择权和程序完成情况。2024年证监会退市意见要求，通过要约收购、股东大会决议等方式主动退市时，应提供异议股东现金选择权等专项保护；重大违法退市还要求追责和赔偿救济。赔偿需要相应责任认定和程序，不能视作每位投资者自动按买入价获偿。[S-C-ASIA-09-03](#S-C-ASIA-09-03)

ST是其他风险警示，*ST是退市风险警示，两者都不等于已经退市。证监会2024-12-23针对媒体名单解释，个别财务指标或监管问询不能单独决定退市；要结合完整规则、过渡期和公司整改情况。该答复针对当时被报道的公司与制度窗口，不应被理解为一切*ST公司都有统一的一年宽限期。[S-C-ASIA-09-04](#S-C-ASIA-09-04)

## 观测与数据口径

发行事件至少有申请、受理、审核、注册、询价、认购缴款和股份上市等时点。预案金额是意向，注册额度是许可，实际募集金额才是已完成融资；审查终止也不等于上市公司退市。若研究短期资金需求，关注缴款和交收日；若研究可交易股份供给，关注上市及解禁日；若研究信息变化，需定位公告和市场此前已知内容。

| 指标 | 必须保留的边界 |
|---|---|
| IPO家数、募资额 | 交易所、上市地、自然年或滚动期、上市日或发行日；是否包含介绍上市、转板及de-SPAC |
| 再融资额 | 现金与资产认购、普通股与优先股、可转债是否包含；总额还是扣费用净额 |
| 解禁数量 | 解除限售的股数和价值，不是已经卖出的数量；实际减持另核 |
| 退市家数 | 决定日、终止上市日或进入退市板块日；主动、强制及合并分别统计 |
| 净股本变化 | 新发股、转股、注销式回购、股份支付等综合变化；不能用IPO金额减退市市值代替 |

## 本对象的历史与可核数字

### 2023—2024：全面注册制与发行节奏调节同时存在

2023-02-17全面注册制规则发布实施，覆盖发行条件、审核注册、承销和监管等165部规则。2023-08-27，证监会又针对当时市场阶段性收紧IPO、关注大额再融资必要性，并对破发、破净等情形作出差异化安排。前者改变制度框架，后者体现具体市场环境下的监管节奏；不能把注册制理解为任何时点都无约束增加发行。[S-C-ASIA-09-01](#S-C-ASIA-09-01)、[S-C-ASIA-09-02](#S-C-ASIA-09-02)

2024-04-12退市意见强调严格标准、拓宽主动退出和削减壳价值，意味着依靠上市资格出售、资产注入维持估值的预期受到约束。54家退市是全年结果；它不能单独度量改革的因果效果，也不是次年退市家数的政策目标。[S-C-ASIA-09-03](#S-C-ASIA-09-03)、[S-C-ASIA-09-05](#S-C-ASIA-09-05)

港交所《Market Statistics 2025》统计主板与GEM的股票，排除REITs、债券等其他证券；2025融资金额标为暂定数。以下金额由原表百万港元换算为十亿港元，保留一位小数。[S-C-ASIA-09-06](#S-C-ASIA-09-06)

| 上市后募资，十亿港元 | 104.2 | 358.6 |

### 有归属的条件判断

以2026-10-28整理、以上述统计及制度为信息边界，本库的条件推演是：若未来发行主要投向有盈利和现金流支撑的项目，同时最终投资者资金增加，融资恢复可扩大优质资产供给，短期承接压力未必转化成持续估值下降；若高折价发行集中、项目回报偏低且投资者现金预算不变，稀释和换仓卖出压力可能更明显。判断应分别跟踪已缴款现金、募资用途及每股盈利实现，不以申请排队数直接预测指数。

本页未取得同一事件窗口的机构IPO融资预测、认购资金来源或投资者现金余额，因此不报告发行意外的金额，也不把上述条件推演写成市场共识。

## 涉及的关系

[A/H溢价的市场分割机制 R-CHINA_MARKET-07](../20_mechanisms/A／H溢价的市场分割机制.md)：双重上市公司在一地增发，会改变当地可交易供给和两地股东承接新股的条件；折价增发还可能改变现有股东的每股权益。由于A、H股票通常不能自由互换，一地新股供给变化不会自动由另一地存量股份抵消。这个联系用于理解具体发行对相对价格的作用，不能仅凭发行金额预测溢价方向。
