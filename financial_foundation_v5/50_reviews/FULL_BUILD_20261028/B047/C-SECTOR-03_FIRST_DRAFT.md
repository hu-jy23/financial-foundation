# 证券与资管业

> 执笔：`/root/resume_b047`；制作日2026-10-30。已读中国券商案例为2024财年，海外资管更新到2025财年及2026-01-15业绩稿；这不是2026年实时行业状态。

## 概念定义

证券与资管业是围绕证券发行、交易、融资、投资管理和财富配置提供服务的金融行业。证券公司可以为客户代理成交、承销证券，也可以使用自己的资产负债表融资并承担头寸；资产管理机构通常受托管理客户资产，通过管理费及合同约定的业绩报酬取得收入。两者在同一集团内可能共存，但“客户承担投资损益”与“公司资本承担投资损益”必须先分开。

首创证券的业务披露同时包含资产管理、投资、投资银行、财富管理等板块；BlackRock的披露则把管理和行政费、证券借贷收入、业绩报酬、技术服务等分别列示。这两种一手披露提供了不同业务模型的实际例子，不能视为行业统一收入结构。[S-C-SECTOR-03-01](#S-C-SECTOR-03-01)、[S-C-SECTOR-03-02](#S-C-SECTOR-03-02)

## 概念详解

### 成交、融资和管理资产，是不同的收入基础

| 业务 | 公司实际提供什么 | 收入基础与主要约束 |
|---|---|---|
| 经纪与财富销售 | 交易执行、账户服务、产品销售和投顾 | 成交量、净佣金率、客户保有资产与收费合同；销售量不能直接当管理规模 |
| 投资银行 | 发行组织、承销、保荐、财务顾问 | 完成项目和收费条款；项目储备不等于已经确认收入 |
| 信用与资本中介 | 融资融券、做市、衍生品及对冲服务 | 客户借款或头寸、资金成本、风险资本、抵押与对冲能力 |
| 自营投资 | 用自有或借入资金持有证券 | 票息、价差、估值与信用损失；净头寸及融资比名义成交额更重要 |
| 资产管理 | 按受托约定投资与持续服务 | 计费AUM、费率、客户留存和业绩报酬条件；产品资产一般不等于公司自有资产 |

“成交放量”首先影响经纪业务；它对资管收入的影响要经过客户净申购、净值与计费规则。二级市场换手也不直接增加发行人融资，更不保证投行项目顺利完成。同一个市场上涨阶段，券商各板块可能呈现完全不同的利润变化。

### 经纪的量价关系与经营杠杆

本库简化经纪收入为\(R_B=T\times c\)：\(T\)是本公司客户在观察期内的计费成交额，单位元；\(c\)为与该成交口径一致的有效净佣金率。不能把全市场单边成交额直接乘公司报价，而遗漏市场份额、买卖双边计费、机构与零售客户差异，以及代收费用。

**假设算例：** 基期计费成交额1万亿元、净佣金率万分之二，收入2亿元。下一年成交额增加30%，但净佣金率降到万分之一点五，收入变为1.95亿元，反而下降2.5%。这是量价核算，不是实际行业预测。获客、系统和合规等固定成本使收入变化可能被放大成利润变化；若公司为了扩份额增加渠道支出，则放量对利润的贡献还会被部分抵消。

经纪收入的周期性也不等于“下跌无收入”。快速下跌可能带来很高交易量，短期佣金增加；若随后客户资产和活跃度减少，持续收入才会承压。因此，应将单日成交、季度平均成交和客户留存分别记录。

### AUM不是新增资金，更不是资产管理公司的资产

资产管理规模（AUM）是特定口径下管理的客户资产存量。一个不含其他调整的期间勾稽关系为：

\[
AUM_1=AUM_0+F+M+X+B,
\]

其中\(F\)为净流入，\(M\)为市场价格变化，\(X\)为报告币种换算影响，\(B\)为并购或业务并入口径变化，均以同一币种金额计量。实际公司可能另列再分类和分配等调整项。净流入通常已抵销申购与赎回，但应核对是否包含实物资产转入、再投资分配和机构账户转移。BlackRock的AUM桥接表明确分开上述来源。[S-C-SECTOR-03-02](#S-C-SECTOR-03-02)

基础管理费可近似写成\(R_M=\sum_i\overline{AUM}_i f_i\)，其中\(\overline{AUM}\)是当期平均计费规模，\(f_i\)是产品对应的期间费率。若使用年化费率，季度收入须按实际计费天数折算。年末突然流入一大笔资金，对全年平均规模的贡献很小；用年末AUM直接除年度收入推断“真实费率”，会把时点变化误当成定价。

**假设算例：** 平均计费AUM为1000亿元、年费率0.5%，基础管理费5亿元。若规模升至1200亿元，但低费率产品占比提升使综合费率降至0.35%，收入为4.2亿元。产品结构比总规模更能说明利润质量。业绩报酬可能还要求超过门槛、弥补历史亏损或在实现退出后确认，不能把所有产品的账面涨幅按固定分成率计入当期收入。

客户产品亏损与管理公司亏损之间存在联系，但两者不是同一金额：客户亏损可能减少计费资产、触发赎回和损害声誉；只有公司自投、担保或其他明确风险承担，才会另行形成公司资产损失。封闭基金限制赎回可延长资金存续期，也会把现金回收问题转移到资产退出与分配阶段，不能因此称其没有流动性风险。

### 融资与资本中介：利息收入之外还有资产负债表

券商向客户提供融资，需要自有资金、发债、回购等资金来源。若平均融资资产为\(L\)，客户年化收费为\(r_c\)，对应资金成本为\(r_f\)，简化毛利差为\(L(r_c-r_f)\)，尚未扣除信用损失、运营费、资本成本和期限错配代价。融资余额增大而资金成本上升更快，净收入未必增加。

抵押证券价格下降时，追加担保要求先落到客户；客户不能补款，券商处置抵押品并可能承担跳空与执行损失。自营、做市、衍生品还会带来库存、保证金与对冲融资需求。同样规模的名义交易，净风险可能差异很大。理解资本中介应同时看净资本、杠杆、期限和压力下可用现金，参见[融资流动性](../10_concepts/融资流动性.md)。

资管机构也可能通过产品持仓与赎回影响债市，但客户资金不是管理人可自由用于自身偿债的资金。把客户结算资金、受托资产、公司自有现金相加，容易虚增公司“资金实力”。

## 观测与比较口径

先用财务报表的分部说明识别业务，再连接交易所成交、融资余额、基金份额与净值。不同来源的统计范围可能不同：券商资管本金规模、产品净值规模和公募基金净资产不是同一序列；含不含专项计划、海外业务、参股基金公司，也会改变数字。

| 观察对象 | 最小必要口径 |
|---|---|
| 经纪景气 | 市场和公司、股票或股票基金、单边或双边、总佣金或净收入、期间 |
| 融资业务 | 平均余额而非只看期末；资金成本、担保情况和信用减值并列 |
| 管理规模 | 期末与平均、计费与非计费、净值与本金、并购与有机净流入分开 |
| 盈利 | 管理费和业绩报酬、自营和客户业务、审计与管理调整口径分开 |
| 资本 | 法人净资本、风险资本占用及流动性；不把客户资产视为可支配资本 |

净利润对市场水平敏感与股票价格对预期敏感也有区别。即使实际收入增长，若增长低于此前估值中隐含的要求，行业股价仍可能下跌；本页未取得相应估值与事前预测，不能据事后盈利解释某天股价。

## 历史与带归属判断

**2024年中国券商案例，2025年4月披露。** 首创证券公布全年营业收入24.18亿元、归母净利润9.85亿元，分别增长25.49%和40.49%。其代理买卖股票基金交易额6635.61亿元、同比增长30.40%，年末融资融券余额（不含息）28.90亿元。数字显示公司同时暴露于交易与融资，但利润增长不能仅归因于成交；其资管、投资等业务还需分别核算。[S-C-SECTOR-03-01](#S-C-SECTOR-03-01)

**2024年全球资管案例，2025-01-15披露。** BlackRock全年AUM桥接如下，单位均为十亿美元，保留原表百万美元换算后的三位小数：

| 项目 | 金额 |
|---|---:|
| 2023年末AUM | 10008.995 |
| 2024年净流入 | 641.351 |
| 并购带入 | 73.949 |
| 市场变动 | 992.964 |
| 汇率换算 | −166.008 |
| 2024年末AUM | 11551.251 |

相加勾稽成立。AUM增加1542.256十亿美元，其中净流入641.351，显然不能将全部增量称为客户新投入资金。同期公司营业收入204.07亿美元，增长14%；公司说明市场对平均规模、有机费收入与并购等均有贡献。[S-C-SECTOR-03-02](#S-C-SECTOR-03-02)

**较晚结果：2025全年，2026-01-15披露。** BlackRock报告年末AUM约14万亿美元，全年净流入6980亿美元；收入增长19%，但GAAP营业利润下降7%，调整后营业利润增长18%。公司将两种利润口径分化联系到并购相关非现金费用和非现金捐赠，本文未据调整口径替代GAAP结果。这说明规模扩大不能绕过费用及合并口径直接推断利润增长。[S-C-SECTOR-03-03](#S-C-SECTOR-03-03)

**当时的专业判断与本库推演分开保存。** 2025-01-15，BlackRock管理层预期已完成及拟议收购会扩大私募市场和数据能力；这是当时经营展望，不是对2025收入增速的量化承诺。[S-C-SECTOR-03-02](#S-C-SECTOR-03-02) 本库于2026-10-30作条件推演：未来一至四个季度，若成交增加但费率压缩，券商经纪收入改善可能弱于成交；若市场上涨且净流入持续，资管平均计费资产会逐步抬升，但低费产品迁移及成本增加可能限制利润。能改变判断的观察是有效费率、分产品净流入、平均计费资产和经营费用，而不是单一总AUM。未取得中国行业当时调查与2026最新结果，故不写“市场一致预期”。

## 涉及的关系

[存款迁移的债市传导 R-CHINA-12](../20_mechanisms/存款迁移的债市传导.md)把本对象列为正式参与节点：居民和企业改变存款与资管产品配置后，管理人根据合同、久期与流动性需求配置债券。产品新增资金能否成为债券净买入，须扣除赎回、现金留存以及其他资产配置；本页的AUM分解是读懂该机制的前提。

经纪量价、自营损益和管理费模型保留在本对象，不增设行业化经营核算机制。交易商融资约束的多轮市场反馈由[保证金驱动的流动性螺旋](../20_mechanisms/保证金驱动的流动性螺旋.md)解释，此处仅作为业务边界入口。
