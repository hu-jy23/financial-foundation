# 百度

> 执笔：`/root/resume_b045`，GPT-6-Astra，medium。制作日2026-10-30；资料截止2026-08-18，财务覆盖至2026Q2。2024比较数据采用后来官方报告所列历史值。

## 概念定义

百度是从中文搜索及在线营销发展出AI云、AI应用和自动驾驶业务的上市技术集团。搜索和信息流把用户的信息需求连接到内容及广告主，云把算力、模型和软件能力提供给企业，萝卜快跑（Apollo Go）则把自动驾驶技术用于真实道路出行。三者分别面对流量与广告回报、企业交付与基础设施利用率、道路许可与车队运营等约束，不能用一个“AI用户数”概括其经济性。

百度按美国公认会计原则（US GAAP）报告，财年截至12月31日。集团合并报表包括爱奇艺；百度一般性业务（Baidu General Business）和集团不是同一主体。2026Q2一般性业务收入251.83亿元、爱奇艺62.87亿元，减分部抵销1.45亿元后才得到集团313.25亿元收入。[S-C-TECH-32-02](#S-C-TECH-32-02)

## 概念详解

### 搜索广告面对的是信息入口迁移

传统搜索连接“用户提出需求—平台排列相关结果—商家付费获得展示或点击”。对广告主而言，流量价值取决于点击后能否带来订单或有效线索，而不是查询量本身。搜索内容的相关性与可信度影响用户是否继续使用；广告质量和展示负载又会影响这种体验。因此，短期多卖广告与长期保留用户之间存在权衡。

内容应用、交易平台和独立AI助手都可能直接回答用户需求，使用户减少从通用搜索跳转到外站。百度将AI引入搜索，可以改善答案体验，也可能改变原有广告位置和点击路径。若用户直接取得答案，原来的点击量可能减少；若AI能帮助用户完成更复杂的任务，平台又可能提供新的营销服务。AI广告增长与传统广告下降可以同时发生，不能把前者全部当成新增市场。

分析广告业务可近似写成“有效商业请求量×商业化率×每次商业化收入”。三项分别描述有商业意图的需求、其中实际展示／转化为广告服务的比例及单位收入，不能用App月活替代全部三项。2026年6月百度App MAU为6.44亿；这是使用规模，不是付费客户数，也不是广告需求强度。[S-C-TECH-32-02](#S-C-TECH-32-02)

### AI云与应用不是同一种收入

AI云基础设施向客户提供算力和相关部署服务，收入随客户工作负载、合同及用量增长；文库、网盘等AI应用则把模型能力包装成终端功能，商业化还依赖付费转化和续费。模型能力有助于吸引客户，但企业最终还要解决数据接入、权限、安全、稳定性和成本问题。开放模型与其他供应商的竞争也可能压低单位调用价格，使使用量增速高于收入增速。

服务器采购形成现金流出，设备投入使用后逐期折旧；模型研发与员工报酬通常先进入费用。用增长很快的云收入抵消下降中的广告收入时，集团利润不一定保持不变，因为两种业务的成本结构不同。2025年公司解释，AI业务成本上升使集团收入成本增加，而传统业务收入下降；这给出了结构转型的实际案例。[S-C-TECH-32-01](#S-C-TECH-32-01)

2026Q2，AI Cloud Infra收入73亿元，同比增长50%，但环比下降17%；其中GPU Cloud收入同比增长283%。GPU Cloud原称AI加速器基础设施订阅收入，是AI Cloud Infra内的一个子项。283%不能代表全部云收入增速，也不能代表AI应用增长；当季AI应用收入25亿元，同比增长3%。公司将子项改名的注释必须与序列一起保留。[S-C-TECH-32-02](#S-C-TECH-32-02)

### 自动驾驶要从技术指标走到每车经济性

萝卜快跑的业务单位是可提供服务的车队和行程。软件技术减少对车内驾驶员的依赖，但车辆采购、折旧、充电、清洁、维修、保险、远程支持与调度仍需要资源。获准测试、获准无安全员测试和获准商业收费是不同状态；进入一个城市也不表示能在全城、全天候收费运营。

**本库分析框架**：单车每日贡献约等于“付费行程数×每程净收入−随里程和行程变化的成本−车辆及当地运营固定成本”。如果空驶增加，车队公里数可以增长而收入不同比例增长；提高利用率可以摊薄车辆成本，却受服务范围、需求密度和等待体验制约。单车贡献转正也不等于包含总部研发后的整个自动驾驶业务盈利。

2025Q4，百度披露340万次全无人运营行程；截至2026年2月累计向公众提供行程超过2000万次。2026年8月披露业务足迹达28个城市，累计自动驾驶里程超过3.5亿公里，其中全无人超过2.4亿公里。这些是运营规模指标，不是营业收入、付费订单占比或净利润。Q2披露分别说明伦敦、瑞士的道路测试、迪拜商业运营及香港全无人测试，不能合并成28城全部商业化。[S-C-TECH-32-01](#S-C-TECH-32-01)、[S-C-TECH-32-02](#S-C-TECH-32-02)

## 观测口径：同一业务可以有两种分类

2025Q4，公司把原Baidu Core重新定义为Baidu General Business，内部再区分AI业务、传统业务和其他。2026Q2同时提供“AI／传统”管理口径与“在线营销／其他”收入性质口径。两张表是交叉分类，不是可相加的独立分部。

| 2026Q2一般性业务管理口径 | 收入，人民币亿元 | 读取方式 |
|---|---:|---|
| AI Cloud Infra | 73 | 云基础设施，GPU Cloud为其中子集 |
| AI Applications | 25 | AI应用 |
| AI-native Marketing Services | 26 | AI原生营销，仍有营销属性 |
| AI业务合计 | 125 | 四舍五入合计误差存在；约占一般性业务50% |
| Legacy Business | 104 | 主要为搜索、信息流等传统广告 |
| Others | 23 | 其他管理分类 |
| 一般性业务合计 | 252 | 精确财务表为251.83亿元 |

同季按收入性质，在线营销服务131亿元、其他121亿元。AI原生营销包含在营销活动中，不能在131亿元外再加26亿元。AI业务约50%的分母是一般性业务，不是集团313.25亿元；若读成集团50%，会把爱奇艺影响漏掉。这些AI及运营数据来自公司未经审计内部管理账目，精度和分类解释不同于完整财务报表。[S-C-TECH-32-02](#S-C-TECH-32-02)

## 财务、调整利润与现金流

以下集团金额单位均为人民币亿元，负数为亏损或现金流出。

| 指标 | 2024全年 | 2025全年 | 2026Q2单季 |
|---|---:|---:|---:|
| 收入 | 1331.25 | 1290.79 | 313.25 |
| GAAP经营利润／亏损 | 212.70 | −58.23 | 30.24 |
| 经营现金流 | 212.34 | −30.13 | 34.36 |
| 资本开支 | 81.34 | 120.73 | 113.90 |
| 自由现金流 | 131.00 | −150.86 | −79.54 |

来源：[S-C-TECH-32-01](#S-C-TECH-32-01)、[S-C-TECH-32-02](#S-C-TECH-32-02)。2025年的161.90亿元长期资产减值使GAAP经营结果明显转负；剔除这一项后的经营利润约103.7亿元，与公司四舍五入披露104亿元一致。但这仍不等于Non-GAAP经营利润约150亿元，因为后者还调整股份薪酬和并购无形资产等项目。减值虽不是同额当期现金支出，却代表原资产预期可回收价值下降，不能从经营叙事中消失。

2026Q2，集团Non-GAAP经营利润37.85亿元，可由GAAP经营利润30.24亿元加股份薪酬7.09亿元、并购无形资产摊销及减值0.52亿元得到。进一步加折旧及其他摊销23.65亿元，得到调整后EBITDA61.50亿元。设备投入增加时，EBITDA不承担当期折旧，但设备仍然需要现金采购和未来替换，因而不能用61.50亿元代表股东可用现金。[S-C-TECH-32-02](#S-C-TECH-32-02)

百度披露自由现金流为经营现金流减资本开支。Q2为34.36−113.90=−79.54亿元。剔除爱奇艺后，经营现金流30.96亿元、资本开支113.70亿元、FCF为−82.74亿元；爱奇艺贡献的3.20亿元正FCF使集团负值较小。研究搜索、AI云资金回收时，应避免把集团现金流直接当成这些业务的独立现金流。

公司称2026年6月末“总现金及投资”为2831亿元，其中包括受限现金、长期定期存款及调整后的长期投资等。这个管理指标不能当作全部随时可用的现金，更不是扣除负债后的净现金；投资市值变化也不能直接解释为经营现金流。[S-C-TECH-32-02](#S-C-TECH-32-02)

## 本对象的历史与预期

**2024—2025：收入结构变化快于集团收入。** 2026年发布稿回列，AI业务收入从2024年的270亿元增至2025年的400亿元，同比增长48%，其中云基础设施由148亿元增至198亿元、AI应用由98亿元增至102亿元、AI原生营销由24亿元增至98亿元。集团同期收入却下降3%。因此，业务迁移与旧收入流失是同时存在的，不能以AI增速替代集团增长。[S-C-TECH-32-01](#S-C-TECH-32-01)

2025年集团经营现金流为负30.13亿元，全年FCF负150.86亿元，但下半年经营现金流已转正。这里全年与半年的方向不同；只保留“现金流转正”会掩盖年度资金消耗。2025Q4新分类也是分析断点，2024的AI数据是后来内部管理口径比较值，并非本页取得的2024原始发布版本。

**2026-02-26管理层计划。** 百度宣布授权最多50亿美元回购，期限至2028-12-31，并首次引入股息政策，首笔股息可能于2026年末前支付。金额是授权上限，不是已花出的现金；“可能支付”不构成确定分红承诺。当天李彦宏把AI云、应用、原生营销和萝卜快跑视作长期价值来源，但所读稿没有提供集团收入增长或自动驾驶盈利的确定季度目标。[S-C-TECH-32-01](#S-C-TECH-32-01)

**2026-08-18的新观察与计划。** Q2 AI业务收入125亿元，同比增长25%，但环比下降8%；一般性业务同比下降4%，在线营销同比下降19%。经营现金流连续第四季为正，与资本开支增加导致FCF为负并不冲突。财务负责人何海建还表示，香港双重主要上市转换预期在2026年内生效，前提包括股东及港交所批准；本页未核其后审批和实施结果，保留为当时有条件计划。[S-C-TECH-32-02](#S-C-TECH-32-02)

**本库条件推演，制作于2026-10-30，观察未来四至八季。** 若AI云付费需求与应用续费能够持续增长，且收入贡献超过传统广告收缩和新增设备折旧，集团可能完成利润来源转换。若AI收入主要替代旧广告，或云客户收入增长仍需要更快的资本投入，则AI占比上升也可伴随利润和自由现金流压力。自动驾驶需另看收费行程、车辆利用率及包含研发的利润，不能借搜索现金余额推定其已经自我融资。本页不使用8月18日后信息检验上述情景。
