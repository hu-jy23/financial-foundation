# 碳排放权与碳价格

> 执笔：`/root/full_b024`，GPT-6-Astra，medium。制度资料核至2026-07-17欧委会提案说明；中国全年交易数据截至2025年，欧盟价格样本为2024年。动态说明页于2026-10-28访问，未提取当日行情。

## 概念定义

碳排放配额是在特定排放交易制度下，由主管部门创设、分配并允许用于履约的排放单位。受监管企业按规定监测、报告并接受排放核查，再交回相应配额完成清缴。碳价格是取得一单位合格排放工具的市场价格，常以本币／吨二氧化碳当量表示。它使排放带来可观察的机会成本，并使减排能够节省配额或产生可出售的盈余。[S-C-COMMOD-16-01](#S-C-COMMOD-16-01)

“碳排放权”不是永久拥有大气容量，也不是任何国家、年份或项目的凭证都能互换。配额、项目减排信用、碳税和企业内部碳价分别对应不同制度。本页以欧盟EU ETS和中国全国碳市场解释主要差异，不把某一市场价格当作全球统一碳价。

## 概念详解

### 排放义务怎样转为配额需求

监管首先规定覆盖主体、设施、气体和排放边界；企业依核算规则得到年度核查排放量，再与可用于该年度的配额、结转和抵销资源比较。交易解决企业间缺口分布不同的问题：减排成本较低者减少排放并出售余量，减排较贵者购买配额。如果两者面对同一价格且可自由交易，边际减排成本趋向接近，从而用更低总成本完成共同约束。

这一经济逻辑依赖测量、履约和交易规则有效。错误排放数据会直接改变应清缴数量；不清缴的代价过低会削弱购买意愿；允许使用的旧配额和减排信用会改变当期供给。因而“碳价上涨”可能反映约束收紧，也可能来自履约集中、可卖配额不足等状态，不能脱离制度直接判断减排雄心。

### 总量控制与强度控制改变不同的约束

EU ETS以不断下降的总量上限限制覆盖范围内配额供给。拍卖和免费分配是同一总量内部的分配方式；免费发放不意味着相应排放脱离总量约束。欧盟说明，配额可以交易，也可保留供以后使用，故当前价格还反映跨期稀缺性。[S-C-COMMOD-16-01](#S-C-COMMOD-16-01)

中国2025年发展报告描述的全国市场则以强度控制为基础，发电行业采用基准线法免费分配。可用一个**简化教学式**表示：

\[
A=bY,\qquad E=eY,\qquad G=E-A=(e-b)Y.
\]

\(Y\)为产出，如兆瓦时；\(b\)为基准排放强度，\(e\)为实际排放强度，单位均为吨／兆瓦时；\(A\)为分配配额，\(E\)为排放，\(G\)为净缺口，单位吨。实际规则另有机组分类、供热、修正系数和年度核定，本式不替代法规计算。[S-C-COMMOD-16-04](#S-C-COMMOD-16-04)

在这个简化制度下，产出增长会同时增加排放和分配量，因此约束首先落在单位产出的排放效率，而不是预先固定的全市场排放总量。新纳入更多行业也不会自动提高价格：新增履约需求要与新增免费配额一起计算。

### 免费配额、现金支出与机会成本

假设某企业年产100万兆瓦时，实际强度0.9吨／兆瓦时，基准0.8吨／兆瓦时，没有结转、抵销或其他调整，则排放90万吨、免费配额80万吨、缺口10万吨。若碳价80元／吨，净买入支出为800万元，平均每兆瓦时8元；把90万吨全部乘80元得到7200万元，会高估这项净购入现金支出。

但“免费”不等于“没有边际减排收益”。在产出和配额不变时，每减少一吨排放便少买一吨或多卖一吨，价值仍为80元。若增加一单位产出会同时获得新增免费配额，则产出边际上的净碳成本接近 \(P(e-b)\)，而非 \(Pe\)。若配额是固定历史分配、不随产出变动，该抵消就不成立。两种制度下同样的市场价格，可能对应不同的减排激励、产出激励和现金压力。

算例只是本页推导，未计税费、交易价差、提前购买、持有成本和履约工具限制。减排设备还需比较投资额、使用寿命和未来碳价路径，不能用某日现货价格直接决定长期项目盈利。

### 碳价为什么并不只由年度上限决定

需求来自核查排放和对未来履约的准备，受工业产出、天气、发电结构及燃料价格影响。供给来自拍卖、免费分配、可结转余额和可用抵销工具。即使总量长期收紧，当前减排较快、产出较弱或拍卖节奏前移，价格仍可能下跌。

欧盟市场稳定储备（MSR）根据流通配额总量调节拍卖供给，并不直接承诺固定碳价。把配额暂时收入储备与永久失效也不同：前者保留将来可能释放的数量，后者取消未来使用权。欧委会2026年4月提出停止有关失效机制的修改，仍须与已生效规则区分，不能把提案自动写成实施结果。[S-C-COMMOD-16-03](#S-C-COMMOD-16-03)

### 配额与减排信用的边界

配额由监管制度在覆盖范围内创设；项目减排信用依据相对基准线的核证减排产生。信用质量需要核对额外性、基准线、核查以及是否重复使用。信用可以用于自愿目的，也可能按特定条件抵销履约，但绝不天然等同配额。中国2025年发展报告分别讨论配额市场与国家核证自愿减排量（CCER）市场：2023排放年度有58家重点排放单位使用647.27万吨CCER抵销清缴，说明两者存在受规则约束的连接，而非价格必然相同。[S-C-COMMOD-16-04](#S-C-COMMOD-16-04)

## 本对象的历史与带归属的预期

**2005—2019：从试行价格到跨期供给管理。** 欧盟2005年启动ETS。第一阶段配额发放超过排放，且不能结转到第二阶段，2007年价格降至零；这说明价格需要可执行的稀缺性，而非只靠“建立市场”的名称。2008年危机后排放需求低于原先预期，配额盈余继续积累，MSR于2019年开始运行，以规则化的拍卖数量调整处理这种不平衡。[S-C-COMMOD-16-01](#S-C-COMMOD-16-01)、[S-C-COMMOD-16-03](#S-C-COMMOD-16-03)

**2023年修法、2024年欧盟价格表现。** 按欧委会2025-12-11更新的上限说明，2023年改革使2024—2027年线性减量因子为4.3%、2028年起为4.4%，目标是覆盖排放到2030年比2005年减少62%。这些百分比施用于参考上限，不是每年把当年剩余额简单乘以95.7%；还存在一次性调整与航运扩围。[S-C-COMMOD-16-02](#S-C-COMMOD-16-02)

ESMA于2025年10月发布的2024年市场复盘显示，EUA现货年均价约65欧元／吨，较2023年下降22%，2月底低至约51欧元／吨。其解释是电力脱碳使需求较弱，以及拍卖量增加；2024年拍卖量5.99亿单位、同比增加15%。这是监管机构对当年驱动的解释，不是单因素因果估计。它与长期上限收紧并不矛盾：近端供需和供给时点也在变。[S-C-COMMOD-16-06](#S-C-COMMOD-16-06)

欧委会2025-12-03判断，EU ETS电力和工业设施排放比2005年约低50%，当时认为2030年目标仍在轨道上。它同时记录2024年拍卖收入388亿欧元。排放下降是覆盖样本的结果，不能全部归因于碳价，也不是欧盟全部温室气体减排幅度；收入更不等于社会总减排成本。[S-C-COMMOD-16-07](#S-C-COMMOD-16-07)

**2021—2025：中国由发电市场走向扩围。** 全国碳排放权交易市场2021年7月启动，2024年5月《碳排放权交易管理暂行条例》施行，2025年3月正式把钢铁、水泥、铝冶炼纳入。生态环境部2025年报告说明，新行业2024排放年度按实际排放量分配，原则上没有配额缺口；2025—2026年度以整体盈亏平衡、较小企业盈缺率起步。这说明扩围首先建立排放管理与履约能力，不等于当年即施加大额净购买压力。[S-C-COMMOD-16-04](#S-C-COMMOD-16-04)

报告还将发电行业2023、2024排放年度履约截止分别设为2024、2025年底。2023排放年度发放52.15亿吨、核查排放52.44亿吨，缺口0.29亿吨、占应清缴量0.55%；行业总缺口很小，仍可能有企业明显短缺，因为盈余分布与交易意愿不同。2024交易年配额成交1.89亿吨，第四季度占79%，年末综合收盘价97.49元／吨；这组数据反映履约集中性，不能把成交量当作实际排放。[S-C-COMMOD-16-04](#S-C-COMMOD-16-04)

**2025年结果，2026年1月1日公开。** 生态环境部统计，2025年全国市场纳入3378家重点排放单位，配额成交2.35亿吨、金额146.30亿元，年均交易价62.36元／吨、年末收盘价74.63元／吨。同期完成的是2024排放年度清缴，应清缴81.94亿吨、完成率约99.99%。覆盖对象扩张后，不能把81.94亿吨与此前纯发电行业规模之差当作同口径排放增长。[S-C-COMMOD-16-05](#S-C-COMMOD-16-05)

**目标、提案与条件推演。** 中国2025年报告转述政策目标：2027年基本覆盖工业主要排放行业，2030年基本建立以配额总量控制为基础、免费与有偿分配结合的市场。这是政策建设目标，并非2030碳价预测。欧委会说明页记录2026-07-17提出ETS定向修订，涉及投资支持、免费分配等；本页只记录提案阶段，未声称相关条款已经立法。[S-C-COMMOD-16-04](#S-C-COMMOD-16-04)、[S-C-COMMOD-16-01](#S-C-COMMOD-16-01)

本库于2026-10-28的条件推演是：未来数年若配额约束相对真实排放更紧、结转和抵销供给有限，净缺口企业成本及减排收益会提高；但产出下滑、低碳电源增加或政策释放额外配额，可以抵消近端价格压力。扩围、新上限和拍卖比例应结合实际分配方案评估，不据政策方向给出单一目标价。

## 观测与经济联系

| 观测口径 | 解释价值 |
|---|---|
| 市场、币种、配额年份与履约适用性 | 决定所报价格究竟购买什么权利；EUA与CEA不是同一资产 |
| 现货、期货、收盘价、成交均价 | 到期、融资与流动性不同；年末收盘不能替代全年实际采购成本 |
| 核查排放、免费配额、结转、抵销及净买入 | 将碳价转为企业现金需求与边际成本；只有价格无法算利润影响 |
| 覆盖行业和排放边界 | 扩围、核算方法变化会造成统计断点 |
| 成交量、持仓与清缴量 | 配额可多次转手，交易量不等于减排量；衍生品名义量也不等于新增排放 |

碳价与[煤炭与焦煤](../10_concepts/C-COMMOD-05.md)、[天然气与LNG](../10_concepts/C-COMMOD-04.md)共同决定发电燃料的可变成本。排放较高的燃料受到更大的单位燃料碳成本，但能否切换取决于设备和燃料供应。对[电力与公用事业](../10_concepts/C-SECTOR-04.md)，净成本能否进入电价取决于定价制度、调度和配额安排，不能把燃料碳成本逐元转写成利润损失。

对[铝与电力成本](../10_concepts/C-COMMOD-07.md)，直接生产排放与购电中包含的间接成本可能并存；核算边界应避免重复计算。企业承担成本、消费者支付更高价格、政府取得拍卖收入以及其他企业获得配额出售收入，是不同的分配结果。未明确边界前，不能把配额交易额视为经济净损失。
