## 关系制作任务示例

**任务：为“财政融资—国债发行结构—市场久期承接—期限溢价”搜集一组材料。**

先检索教材的期限结构／久期章节和原始研究，再找财政部发行材料、实际买方结构、公告前分析及事后复盘。列出有贡献的具体文章／章节、访问状态、实读范围和相互分歧；解释每份资料服务哪一段逻辑。只取得目录的书保留为候选，尚未核实的预期写清缺口。完成后交主agent筛选，再展开精读。

**任务：补“黄金的机会成本机制／其他相关逻辑1”的某次能源冲击。**

给定用户提供的一篇分析和对应日期区间，研究：（1）它如何论证实际利率变化，采用何种期限和口径？（2）哪些主体明确谈及货币信用或储备配置，原话发表于何时？（3）对黄金的预期是什么，依赖哪项条件，后续证据是否改变判断？先核对文章中的事件事实，再补缺少的前后记录。找出这条逻辑所涉及的重要数字，例如文中实际采用的利率口径、购金量或专业预测；核读原文及图表，缺失再定向检索，并说明未取得的原因。保留作者与本库各自的定性推演，具体情境需要的解释充分写出。产物是这条逻辑的连贯更新、已有Event中的对应内容或适合独立维护的事件，以及来源阅读笔记。

## 主agent合并时

先核对ID、名称和范围，再逐份读正文，优先检查材料论证是否被保留，以及节点组的逻辑、历史和预期是否连贯；再核对关键来源与ID/链接。遇到材料不足，保留具体缺口，避免用笼统背景填满章节。对同一材料的修正同步到引用它的逻辑。通过后同步两份正式目录、JSON索引中的路径、正文状态和实际逻辑组，保留稳定ID；未通过的草稿不标为complete。节点选取不因本次制作而重新打开。

## 写作与运行要求（v5）

任务单另附：实际输入版本、保存任务文本的路径、已指定的模型／thinking 档位（未指定则如实记录）、目标读者所需的解释深度。注明哪些段落须采用、可改写或只作参考，分别处理不同文档的审阅意见。

正文先完成解释：概念讲清含义与构成，机制讲清主体、约束和传导过程，再接必要条件。基础概念无需一律写成长篇教程；也不能依赖 agent 的先验把关键关系省略。逐段检查主语、指代、术语和前后衔接，改掉连续防御性限定与只有标签的因果跳跃。

提交时说明每份文件采用旧稿、新稿或作了哪些编辑，并保留未完成事项。主 agent 按[审阅清单](REVIEW_CHECKLIST.md)逐篇验收，不能以批量改版本号代替正文审阅。

## Event／Source 任务的额外要求

先说明完整内容单元及拟归属位置，按实际材料考虑合并、附入或独立建条目；对象／关系范围沿用已确认目录，课程术语按实际内容解释和归属。课程原页与图表可以直接嵌入，不要求额外复述。原文件、页码、图像路径和已读范围有对应记录。原页清楚时保留原页；已有重要数据从关系页回收到事件正文，避免核心内容只能向外跳转才能读到。

事件正文按材料组织，不套用七字段预期摘要。连续论述和共享事件优先整组交给同一执笔者。资料不足时注明实际范围，不以扩写无来源背景假装完整。审阅需检查划分是否破坏原文思路、图表是否完整可读、作者归属是否明确，以及旧 ID 和来源入口是否仍能定位。
