# Concept／Mechanism 文件命名

生效：2026-10-29。

正文文件采用正式目录的定稿标题：`10_concepts/期限溢价.md`、`10_concepts/港股市场.md`、`20_mechanisms/黄金的机会成本机制.md`。文件名不再添加节点ID或英文尾缀。

- YAML中的`id`是稳定标识；`title`与正式目录名称保持一致。目录、关联节点、逻辑组和审阅记录继续用ID识别节点。
- 标题中的Windows文件名禁用字符`/ \ : * ? " < > |`在文件名中换为对应全角字符，标题本身不改。例如标题`A/H溢价`对应`A／H溢价.md`，标题`原油与Brent/WTI`对应`原油与Brent／WTI.md`。
- 保留标题中的空格；Markdown链接中含空格的路径放入尖括号，程序索引存原始路径。不要自行加ID、英文翻译或改变标题。
- 同一目录发现文件名冲突时先核对节点范围，不能覆盖既有文件。节点改标题时保留ID，并同步文件名、全部路径引用、两份List、JSON索引和任务路径。

## 索引与批量制作

`catalog_index.json`中每个节点的`planned_path`给出目标文件名；`path`仅在已有经审阅正文时填写。两者均以`00_start/`为相对路径基准。`status: pending`包括尚未写作和已有待审稿，`complete`表示已有经审阅正文。

全量制作任务的`50_reviews/FULL_BUILD_20261028/PATHS.json`、各批`TASK.md`和`ASSIGNMENT.json`沿用相同目标路径。新作者从这些记录读取文件名，不再用`<ID>.md`拼接。ID和模型分工不受改名影响。
