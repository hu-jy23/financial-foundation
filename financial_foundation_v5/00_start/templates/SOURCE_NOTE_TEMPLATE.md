# 材料出处与阅读记录

新建独立笔记时填写以上元数据并删除提示；合并来源登记可以用内部来源ID，不必为每篇材料单建文件。复制后按实际状态填写，未读材料不能标为已读。

记录材料 ID、原题名、作者／机构、日期或版本、取得方式、原文地址或原文件、具体页码／章节／图表，以及实际读取日期和范围。未读、未下载和未核实部分如实标明。

## 材料已经进入哪里

链接到 Event、对象、关系或课程材料集中的具体位置。保留完整连续论述的入口及页码；清楚的原页已嵌入时，无需再写一份重复摘要。

## 阅读笔记与延伸

按实际需要保存作者的问题、前提、推理、证据与结论，以及分歧和可继续探索的问题。已有正文充分承载的内容使用链接引用。零散图表可附在合适的内容单元下，材料位置和原图出处在此登记。

## 后续阅读与核实

写清需要再读的章节、尚未取得的图表或原始版本，以及具体核实问题。记录作者原判断和后补说明各自时间。延伸链接用于探索，不把只找到入口的资料标为已经读完。
