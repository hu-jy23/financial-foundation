# 事件或分析材料名称

先判断这份内容适合独立条目，还是应附入现有对象、关系、事件或课程论述。若适合独立条目，围绕材料本身组织正文。复制后按真实进度填写状态。日期可以使用区间；材料集使用event_collection，纯分析可采用analysis_note；按实际内容选择，不虚构单一事件发生日。

正文保留充分的背景、经过、事实、图表、讨论、预期及后续材料。标题与顺序由论述决定，可用自然段、列表、表格和原页图片。明确事件可以先介绍经过；已经清楚的课程原页可直接展示。没有的环节无需凑齐。

原页／图表示意（替换为实际相对路径）：

```markdown
![图或课程原页的简短名称](../../assets/source-id/page-01.png)
```

清楚的原页只标页码和来源即可；无需额外重复解释。FAQ、评论、反思可接在同一文件的相应段落后面。保留作者的筛选和推理，后续补充标明日期及作者。关键数值与测量口径随叙述保存。

末尾或相应段落提供 Source 入口、相关对象／关系链接及具体未完成事项。详细组织原则见[Event／Source指南](../EVENT_SOURCE_GUIDE.md)。模板中的图像路径是示意，复制到实际目录后重新核对。
