# Event、Source 与图文材料的组织规则（v5）

更新：2026-10-25。适用于现有事件材料和新接入的课程资料；初步建图使用已确认的163项对象与71项关系目录。

## 内容的职责

Event 库独立积累可阅读的事件及分析材料。事件经过、背景、关键数字、当时预期、评价、FAQ、反思、相反意见与后续进展均可保存。材料已经精炼时优先保留完整内容与论述顺序；不要把它再次压缩成关系页的证据摘要。

Source 保存出处、原材料、实际阅读范围、阅读笔记与延伸探索入口。进入正文的内容应能直接阅读，出处提供追溯。延伸研究可以通过来源链接继续展开。原始材料的保留状态如实记录：本次课程 PDF 有本地原件，早先网页资料多数只保存链接及核读记录。

对象和关系正文继续承担定义、解释、机制、历史与预期。它们可以引用 Event 内容或附上相关图表，不必为每张图额外建立文件或候选节点。

## 先识别完整单元，再决定归属

切分依据问题、论证和后续维护需要，逐例判断。一个明确事件及紧随的评论通常一起保存；一段按顺序展开的专题论述可以用内部章节组织；持续发展的事件可按时间追加。使用同一个文件不表示它们是同一次事件，材料集应明确各章节的范围。

图表、单条数据或简短话题先寻找已有的对象、关系、事件或完整分析作为归属。暂无合适位置时，保留在原课程或专题段落中。内容足以独立成立、有明确边界且值得持续维护时，再创建独立条目。不要按页码、每张图或每个新术语制造小条目。也不为追求少文件而合并无关内容。

这里的“独立条目”指材料的维护单元。Event／Source文件及课程章节不计入已确认的234个对象和关系节点；建立新材料文件不自动扩充建图目录。

课程的阅读锚点用于定位，不等于新增图节点。P20–29 保留为连续论述；P23–26、P27–28 是其内部章节，P29–30 保存当时推论，P31 定位到伊核协议。财政图表将来可附在财政赤字等对象或相关机制下；出现“弗格森定律”仅提供一种可能入口，其存在不决定图表必须如何归属。P17、P28 的选编与历史分期整体保存。尤其P17承载老师对关系历史中重要节点的筛选及组织，阅读时同时识别其选择依据和关系演变，不能只抽出几个孤立事件；正式整理时可与相应关系的时间线相连。

## 图文表达

主文件使用 Markdown，图片用标准语法与相对路径引用；资产放在 `assets/`，避免依赖临时截图地址。清楚的整页直接嵌入即可，只补页码和出处，不强制追加摘要、长图注或同义转述。局部图能够独立理解时可裁切，保留标题、坐标、单位、图例和必要注释；裁切不替代完整原件。

原 PDF 作为 Source 保留，可恢复原始清晰度与上下文。正文图片可放大阅读；本次课程原页以 1920×1080 嵌入。图内数值不以不可靠 OCR 自动变为已核实数据。检索可用文本层、短标题与必要文字转录补充，图表、批注和箭头含义仍以原页核读。

HTML 可作为需要更好阅读导航时的展示层；本轮不维护另一份手工正文。是否采用 HTML 取决于实际阅读需要，MD 嵌图已经能够承载图文。

## 作者、时间及后续更新

原材料事实、引用他人的观点、作者评论、课堂测算和本库补充须能辨认。整段署名、原页来源或局部说明即可，不强制逐句打标签。重要的核实问题附在相应位置，保留原文版本，后续修订单独说明。

预测和评价保留形成时间、对象、期限及条件。后来观察按日期追加；短期结论作为历史判断保留，后续依然可以有价值。无需为每个事件填写一套“截至时间—预期—新增证据—判断变化”字段。

同一内容有一个主要维护位置，通过稳定 ID 和章节链接复用；多个关系可以从不同角度引用。迁移条目时保留 ID 到新章节的映射，检查已有引用和来源入口。
