# 节点选取与命名原则

更新：2026-10-25。用于解释已确定目录的取舍，并指导后续明确提出的范围变更；本次163个对象和71个关系的入选结果保持确定。

## 对象应当保存什么

对象是金融中真实存在、具有具体研究意义、值得独立积累认识的事物、制度、状态或实践。可定价、可用一个数字衡量都不是必要条件；套息交易、资产流动性、美联储独立性同样可以有独立内容。

“材料里需要解释的词”与“值得作为节点积累的对象”应分别判断。常规测量方法、逻辑范畴和浅显背景通常在用到时交代。“尽量详细”要求入选内容讲充分，并不要求把每个术语都建页。

用户提出的两个反问应结合起来理解：这个对象能写什么，是否只剩一句定义？它与其他对象的联系是否接近零，或者几乎什么都能接？前者检查有没有独立知识内容，后者检查有没有具体、可辨认的金融联系。可无差别套到任何事物上的概念，即使能够扩写长文，也可能过于平凡。这些是判断方法，不是字数、篇幅或节点度数的硬阈值。

经济重要、经常出现在新闻中、能找到数据或举出很多案例，都不足以单独证明建页价值。用户已排除名义与实际GDP、GDP平减指数、潜在产出、家庭消费、储蓄率、企业投资与资本开支、库存与库存周期、产能利用率、贸易余额与净出口。需要这些知识时，在相关论证中解释即可。

判断仍须落实到具体条目。用户回补净息差、金融周期、农产品、社会融资规模、宽基ETF，并保留战略储备与能源安全；不能据此整类恢复指标、统计量或资产分类，也不能按这些类别整类排除。回补名单和其他明确取舍见[项目记忆](CONVERSATION_MEMORY.md)。

## 关系应当保存什么

关系连接具体对象，保存值得独立解释的金融过程。其内容可以是约束下的传导、反馈、风险转移、制度作用或有实质含义的分解与比较。应能说清主体、约束、作用过程、条件及历史中的表现。

沿用对象筛选中的平凡性判断：一般的“新信息改变判断”“成本变化影响利润”，给常识加一个行业名，或把同一过程换一组资产反复立项，通常不能形成独立关系。公式、复杂术语或较长的参与对象名单也不自动构成入选理由。是否已有对象详解或已选关系足以承载，需要一起考虑。

未入选的关系仍可作为正文中的解释、案例或讨论。把内容接入已有页面，不表示恢复该节点。

## 归属与拆分怎样判断

对象页说明事物是什么、如何观察、怎样演变；关系页说明若干对象如何相互作用。例：基差与基差交易拆开后，前者承载价差本身的含义和口径，后者承载交易过程及条件。准备金利率／利率走廊、金融周期／系统性风险积累与扩散也分别有独立解释职责。

这些是用户明确采纳的三组拆分，不是把所有带“与”的对象一律拆开，或把所有交易一律迁到关系。五项已采纳迁移及未采纳建议以[项目记忆](CONVERSATION_MEMORY.md)和[迁移记录](../50_reviews/CATALOG_MIGRATION.json)为准。

## 关系名称怎样表达

名称应直接表达机制或研究范围。已有明确机制名时可用“财富效应”“金融加速器”“基差交易”；无需把其常见作用对象和结果全部接到后面。

“与”的取舍取决于两边的实际关系。重复机制内涵、罗列松散话题或机械附加结果时可以简化；具体反馈、比较、分解和跨对象联系则可以保留。例如“主权信用与银行资产负债表反馈”保留了关键状态和传导载体。

压缩名称须保留原义：通胀预期不能换成通胀，ETF份额变化不能换成资金流，资产减值不能换成技术淘汰，HIBOR不能无声扩成全部港元利率。标题质量、内容价值、独立建页资格分别判断；恢复名称不改变勾叉。
