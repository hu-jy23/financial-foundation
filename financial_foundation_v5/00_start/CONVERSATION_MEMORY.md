## 对象选取的思想

对象用于保存值得独立积累的金融认识；关系连接对象并解释过程。可定价、可量化不是必要限制；套息交易、资产流动性、美联储独立性也可以有独立意义。

“能写什么、能超过一句话吗”和“有多少对象与它有关系，是否接近零或无穷”是判断平凡性的启发式。只剩定义、常识扩写，或可以无差别地套到任何事物上，都缺少独立建页价值。不得机械设字数或节点度数阈值。

经济重要、能写长文、能列出案例和传导路径，都不足以立项。用户明确排除名义与实际 GDP、GDP 平减指数、潜在产出、家庭消费、储蓄率、企业投资与资本开支、库存与库存周期、产能利用率、贸易余额与净出口。给一般分析维度加行业限定也不能自动获得资格。

同时不能按“指标、统计量、资产大类”整类排除。用户明确回补净息差、社融、金融周期、农产品和宽基 ETF；判断要落实到本项目中的具体研究对象。回补这些例子不构成恢复其他常规指标的授权。

未入选为节点的变量和知识仍可充分写入正文、事件或来源。只需一段口径说明的量，不因此新建条目。旧 ID 登记用于追溯，不能当作隐式节点或待制作任务。
