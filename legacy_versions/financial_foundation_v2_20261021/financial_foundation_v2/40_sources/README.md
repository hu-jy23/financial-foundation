# 材料工作区

当前有三组已读公开资料登记：[概念](SOURCES_CONCEPTS.md)、[黄金](SOURCES_GOLD.md)、[国债供给](SOURCES_FISCAL.md)。它们记录出处、阅读位置、论证层次、引用对象及局限。对应的事件／观察在 `30_events/`。

用户的专业宏观PPT、书籍与博客尚未提供。获得材料后，每份有深度的材料用[阅读笔记模板](../00_start/templates/SOURCE_NOTE_TEMPLATE.md)记录“问题—前提—推理—证据—结论”，再链接到相关逻辑。可按材料数量逐步增加原文、阅读笔记、待研究问题等子目录，无需先建空目录树。

原材料按授权范围保存；本包只提供自己的归纳、少量必要事实与原文链接。来源登记表是材料生态的入口，后续读书与PPT精读应积累更完整的论证笔记。
