# 金融认知 Map 基础包 v2

制作：2026-10-21。包含 **349 个概念／对象目录项、175 个有效关系／机制目录项，以及四份完整样例**。其中概念已写2份、待制作347份；关系已写2份、待制作173份。原目录中的信息去重与时间隔离两项移至通用规范，在关系清单末保留原ID及迁移说明。

## 从这里开始

1. 读[批量制作标准](00_start/AUTHORING_STANDARD.md)，确定 node 与 edge 的写法。
2. 看[黄金的机会成本机制](20_mechanisms/R-GOLD-REALRATES_real_rates_gold.md)和[国债供给的定价机制](20_mechanisms/R-FISCAL-LONGYIELD_fiscal_long_yields.md)，了解如何按节点组组织逻辑、历史、预期。
3. 从[概念清单](00_start/CONCEPT_IMPORT_LIST.md)与[关系清单](00_start/MECHANISM_IMPORT_LIST.md)选择下一批ID，用[任务单](00_start/BATCH_TASK.md)分派。
4. 将用户材料按页码／章节读入[材料工作区](40_sources/README.md)，以具体问题补研究，再更新相关逻辑。

## 索引与后续维护

[catalog_index.json](00_start/catalog_index.json)同步清单ID、名称、优先级、状态、路径及拟连接节点。两份完整关系还保存按正文提取的 `logic_groups`，各组的含义仍由Markdown中的详细论证表达。候选路径为null；本包没有为其批量生成空文档。

制作新文件后更新候选状态、路径和相关入口。候选节点组只是起点，可随材料调整；ID稳定，标题可改。合并或暂缓某个条目时保留旧ID的去向说明，避免已有引用失效。

解压后从本README阅读即可，文件使用相对Markdown链接，也可作为笔记目录继续编辑。四份模板用于复制，模板占位内容不属于知识库事实。本轮未制作可视化应用、交易策略或行情接入。

## 材料边界

本轮未收到用户的宏观PPT、书籍与博客原文，样例使用已读公开资料。各页资料截止不同，更新日期不代表实时市场状态。历史预期标明主体与日期，本库条件推演标明后来整理的属性；研究机构观点和官方指引均保留原归属。

本轮由主agent完成标准、模板、黄金关系及整包审阅，三个subagent分别完成目录、两份概念和国债供给关系。主agent阅读四份正文、核对关键原始资料，并对节点映射、公式单位与来源时点提出修正。
