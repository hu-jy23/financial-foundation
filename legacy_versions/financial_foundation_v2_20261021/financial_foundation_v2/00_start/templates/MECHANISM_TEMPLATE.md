# 关系名称

## 概念定义

用一个完整段落讲清这项关系是什么。

## 概念详解

充分说明关系含义与讨论范围，衔接已有基础节点；各节点之间的具体论证留在下列逻辑里完整展开。

<a id="logic-1"></a>
## 核心逻辑1：一句直接的逻辑名称

**关联节点／节点组**：节点A、节点B、节点C（附ID和文件／候选清单链接）。

**时间段**：机制适用时期；本次证据实际覆盖区间。

**详细逻辑**：这些节点如何共同作用？各自做了什么？在哪些条件下方向或强度会变化？用充分段落解释，保留材料中的关键推理。

**该逻辑的时间线**：

> 截至时间｜当时状态｜谁对什么、哪个期限有何预期｜新增证据｜判断变化｜后续结果｜来源

记录相关事件以及对本条逻辑的含义。共享事实链接独立event，后续结果注明较晚日期。

**该逻辑的预期**：

主体及信息截止；关注变量及期限；预期及条件；哪些新观察会改变判断；若偏离可能影响哪些节点。区分作者预期、市场隐含量和本库条件推演。缺口写成具体研究问题。

<a id="logic-2"></a>
## 核心逻辑2：按需要增加

沿用上一条的五部分。该条历史与预期紧跟自己的详细逻辑。

<a id="logic-3"></a>
## 其他相关逻辑1：按需要增加

补充路径、限制或竞争解释，同样写关联节点、时间段、详细逻辑、时间线和预期。没有证据的分支可以暂不建立，提出问题后再制作。

列材料工作区入口、证据覆盖截止及具体缺口。
