# 金融认知库写作标准 v0.1

编制日期：2026-10-20。用途：供后续 Codex / subagent 扩展概念、机制、事件和材料工作区。本批为来源核查后的初始样例；用户宏观 PPT、指定书籍与博客尚未提供，后续应据此调整章节结构与论证。

## 1. 文档粒度与身份

- 一份概念文档回答一个有边界的问题；对象、机构、指标、制度可分别标注 subtype。
- 一份机制文档保留一条可讨论的核心命题，可有多个参与者和多条传导渠道。明确各参与者是冲击、状态、媒介、结果还是混杂因素。
- 稳定 ID 与标题分离；ID 不因标题改写而改变。文件名使用 ASCII；正文与标题用中文，重要术语附英文。
- 完整正文优先于摘要堆积。公式须说明变量、单位、期限和成立条件；数值示例须注明“假设算例”。
- 正文可用 `[[文件名]]` 建立知识链接；待建节点必须能在导入清单找到。已存在文件的正式引用优先用相对 Markdown 链接，方便离开 Obsidian 阅读。

## 2. 最小 frontmatter

```yaml
id: C-IR-REAL
type: concept
subtype: economic_variable
title: 实际利率
aliases: [Real interest rate]
status: reviewed_seed
author_role: main_agent
created: 2026-10-20
knowledge_as_of: 2026-10-20
market_snapshot_as_of: null
source_ids: [S-ROOT-01]
related_ids: [R-GOLD-REALRATES]
```

`knowledge_as_of` 只表示文档知识核查时间；`market_snapshot_as_of` 表示市场状态的观测截止。缺少实时报价或共识资料时填 null，不能把写作日期冒充市场快照。

## 3. 概念文档必备内容

1. 一句话定义与适用范围。
2. 概念详解、经济含义与必要公式。
3. 相近概念的边界，至少三个易混点。
4. 观测方法：指标定义、单位、期限、来源、发布延迟、修订或代理偏差。
5. 相关机制与该对象的角色。
6. 历史记录或关键观察：至少两个具体案例；使用统一历史格式；允许预期缺失。
7. Agent 应提取什么，以及什么信息缺失会阻止判断。
8. 待验证问题与逐条可追溯来源。

## 4. 机制文档必备内容

1. 核心命题、论证层次、适用范围。
2. 参与对象及角色表。
3. 分步骤的经济逻辑；说明价格水平、变化、收益之间的差别。
4. 成立条件、不同期限、竞争机制、反例和失效条件。
5. 按核心对象组织的详细逻辑与历史；共享事件引用独立事件记录，避免全文重复。
6. 预期模型：主体、变量、期限、概率/范围、信息集、证据强弱。Agent 判断与市场共识分别存储。
7. 可形成的信号与验证方法，标为待检验假说；不宣称已验证 alpha。
8. 历史案例、证据来源、当前缺口。

## 5. 统一历史格式

> 截至时间｜当时状态｜谁对什么、哪个期限有何预期｜新增证据｜判断变化｜后续结果｜来源

表格或逐项段落均可，字段不能丢失。附加字段可包括：`event_time`、`source_published_at`、`available_at`、`recorded_at`、`record_mode`、`update_type`。

- `record_mode`: contemporaneous（当时记录）、retrospective（后来重建）、hypothetical（假设算例）。
- `update_type`: state_change（现实状态）、belief_revision（预期）、mechanism_revision（机制认识）、measurement_revision（数据修订）。
- 后续结果只在结果已发生且来源可用时填写；事前快照中必须为空。
- 找不到事前共识就写“未核实”，不得用事后叙事反推市场当时知道什么。
- 文档 latest 是截至明确日期的摘要；不得静默覆盖旧判断。可以用追加修订记录替代原文重写。

## 6. 论证与来源标准

使用这些标签帮助阅读：`[定义/制度]`、`[会计恒等式]`、`[条件性理论]`、`[经验结果]`、`[作者解释]`、`[本库推断]`、`[待检验假说]`。

- 来源可挂在 event/observation 后作 hook；材料目录另维护作者、时间、URL、章节/段落、版本、引用位置、阅读状态和局限。
- 优先原始统计、央行/财政部/交易所说明、原始论文；博客保留作者归属及分歧。
- 写作前实际打开关键来源。不能把搜索摘要当全文，也不能声称读过未获取的 PPT 或书。
- 只归纳必要内容，不复制整篇材料。外部来源使用可点击 URL；来源 ID 在文末或独立来源表中解析。
- 历史官方声明可证明政策动作，不能单独证明市场意外程度或资产价格的因果归属。
- 现有实证关联可支持研究动机；因果、样本外预测和可交易收益各自需要证据。

## 7. 交付与审阅

交付真实正文，不能仅填模板。建议概念 2,000–3,500 中文字、机制 2,500–4,500 中文字，长度服从信息量。至少 4 个已打开的相关原始来源；其中要有适用边界或方法来源。文末保留明确的数据缺口。

主代理与 subagent 使用相同标准，不要求文风完全一致。审阅检查：定义、机制、条件、历史、预期时间、来源、可观测性、可检验性、可维护性。比较是对本次产物的编辑判断，不代表模型能力的受控实验。

## 8. 本批样例与任务分工

- 主代理：`10_concepts/C-IR-REAL_real_interest_rate.md`。
- 主代理：`20_mechanisms/R-GOLD-REALRATES_real_rates_gold.md`。
- subagent 1：`10_concepts/C-IR-TERM_term_premium.md`。
- subagent 2：`20_mechanisms/R-FISCAL-LONGYIELD_fiscal_long_yields.md`。
- 各作者写自己的来源文件；subagent 可在独占事件子目录创建事件文件，不能改他人正文。主代理保留其初稿，并在审阅记录中列出必要修正。
