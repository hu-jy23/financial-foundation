## 交给后续 Codex 的任务边界

先读取标准和四份样例，保持现有稳定 ID。新概念先检查别名、定义和已有条目，避免重复。遇到复合条目，按独立检索需求创建子页，并保留原主题页的角色。关系正文必须列出条件和参与者角色。

导入用户 PPT 时，先登记文件版本和页码，再逐章提取概念、机制、案例、作者推断与反例。把这些材料与现有内容核对，保留分歧；不能把资料未涉及的内容伪称为课程观点。

每次加入事件都保存“截至时间｜当时状态｜谁对什么、哪个期限有何预期｜新增证据｜判断变化｜后续结果｜来源”。未找到事前预期则保持缺项。当前四份文档均未建立实时市场快照。

`catalog_index.json` 是本次导入目录的机器可读副本，供任务分配使用。后续编辑以 Markdown 清单为主，并同步更新索引；它尚未包含全量机制参与对象或已验证的图边。
