## 材料分工

- 政策原声明：确定动作和发行方表述。
- 调查与 TBAC 汇总：确定特定主体当时怎样预计，并另核实公开时间。
- 研究论文：提供条件性机制、识别方法和反例边界。
- 统计与交易序列：后续采集，用于检验预测，当前尚未填入。
