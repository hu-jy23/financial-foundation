## 材料生态的后续目录

- `raw/`：用户有权提供的 PPT、书籍摘录和原始博客文件；保留文件指纹与原路径。
- `notes/`：逐章阅读笔记，记录概念、论证、适用条件、反例、与已有机制的冲突。
- `claims/`：必要时拆出可重复引用的具体命题，标作者、原文位置和证据层次。
- `versions/`：网页更新或数据修订的版本说明；遵循可得时间。
- 本批尚无用户指定 PPT/书/博客原文件，不创建空白来源来冒充已读材料。

从来源到概念/机制是归纳过程；同一材料支持多个对象，同一命题可由多个材料支持。出处 hook 指向本表或来源笔记，不替代原文阅读。
