# 批量制作任务单

将下列任务填好交给一个subagent。只提供本批所需文件；返回文件路径和少量审阅要点。每次可以制作几个紧密相关节点或一至两条关系，任务大小服从材料数量。

```text
任务类型：材料搜集／精读／概念／关系／补证据／审阅
负责ID与标题：
输出目录及独占文件：
参考标准：00_start/AUTHORING_STANDARD.md
参考成品：指定一份最相关样例
关联候选ID：从catalog_index.json选取
已有材料：指定PPT页码／章节／文章／来源笔记（可为空）
主动搜集任务：需要补齐的理论、制度、历史案例、竞争解释和事前预期；先查ACQUISITION_SHORTLIST
署名：记录本任务执笔agent与后续审阅者
历史信息截止：
优先回答的具体问题：
1.
2.
3.
完成条件：真实正文＋来源hook＋必要独立事件；关系的每条逻辑独立附时间线和预期。按对象／逻辑判断重要数字并主动搜集；缺失写明具体量、已查来源和原因。保留定性推演及必要事件解释，不强制逐字段排版，不预设下游agent需求。
汇报：文件路径、主要发现、未解决问题、需要主agent判断的地方；不粘贴全文。
```

## 关系制作任务示例

**任务：为“财政融资—国债发行结构—市场久期承接—期限溢价”搜集一组材料。**

先检索教材的期限结构／久期章节和原始研究，再找财政部发行材料、实际买方结构、公告前分析及事后复盘。列出有贡献的具体文章／章节、访问状态、实读范围和相互分歧；解释每份资料服务哪一段逻辑。只取得目录的书保留为候选，尚未核实的预期写清缺口。完成后交主agent筛选，再展开精读。

**任务：补“黄金的机会成本机制／其他相关逻辑1”的某次能源冲击。**

给定用户提供的一篇分析和对应日期区间，研究：（1）它如何论证实际利率变化，采用何种期限和口径？（2）哪些主体明确谈及货币信用或储备配置，原话发表于何时？（3）对黄金的预期是什么，依赖哪项条件，后续证据是否改变判断？先核对文章中的事件事实，再补缺少的前后记录。找出这条逻辑所涉及的重要数字，例如文中实际采用的利率口径、购金量或专业预测；核读原文及图表，缺失再定向检索，并说明未取得的原因。保留作者与本库各自的定性推演，具体情境需要的解释充分写出。产物是这条逻辑的连贯更新、独立事件和来源阅读笔记。

## 概念批量任务示例

**任务：制作黄金、黄金ETF持仓与流量两个节点。**

参考实际利率节点；分别讲清对象本身的定义、详解和数据口径，解释实物、ETF份额、基金持金量、AUM与净流量的关系。明确哪些是价格驱动的余额变化、哪些是申赎，关系机制通过入口链接。已有ID直接复用，不另造同义节点。

## 主agent合并时

逐份读正文，优先检查材料论证是否被保留，以及节点组的逻辑、历史和预期是否连贯；再核对关键来源与ID/链接。遇到材料不足，保留具体缺口，避免用笼统背景填满章节。对同一材料的修正同步到引用它的逻辑，但无需为百来行文档预先增加拆分系统。

## 写作与运行要求（v4）

任务单另附：实际输入版本、保存任务文本的路径、已指定的模型／thinking 档位（未指定则如实记录）、目标读者所需的解释深度。注明哪些段落须采用、可改写或只作参考，分别处理不同文档的审阅意见。

正文先完成解释：概念讲清含义与构成，机制讲清主体、约束和传导过程，再接必要条件。基础概念无需一律写成长篇教程；也不能依赖 agent 的先验把关键关系省略。逐段检查主语、指代、术语和前后衔接，改掉连续防御性限定与只有标签的因果跳跃。

提交时说明每份文件采用旧稿、新稿或作了哪些编辑，并保留未完成事项。主 agent 按[审阅清单](REVIEW_CHECKLIST.md)逐篇验收，不能以批量改版本号代替正文审阅。
