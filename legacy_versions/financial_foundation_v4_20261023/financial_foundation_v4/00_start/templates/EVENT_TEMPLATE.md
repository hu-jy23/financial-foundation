# 事件／观察名称

以下标签为信息提示，可合并成连贯段落。按相关对象／逻辑保留重要数字及其含义，具体情境复杂时充分说明；事实、外部展望与本库推演标明归属。

**截至时间**：当时信息集的截止。

**当时状态**：可核查的事实或被观察的作者判断。

**谁对什么、哪个期限有何预期**：具体主体、变量、期限及出处；保留重要数字和有价值的定性判断。重要量缺失时，先定向搜集，再写明缺项、已查来源及未取得原因；未完成搜集要如实标明。

**新增证据**：新事实、数据或公开观点。

**判断变化**：记录哪项认识改变，详细关系解释链接对应逻辑。

**后续结果**：单独注明结果日期与来源；尚未覆盖就说明。

**来源**：原文URL／材料ID、页码或定位；明确作者观点与事实的区别。

整理为正文时，先交代这次事件的具体变化及其对相应逻辑的含义，再写有必要的限定。共享记录保留可复用事实，各关系页自行解释作用；关键事实修正时检查引用处。
