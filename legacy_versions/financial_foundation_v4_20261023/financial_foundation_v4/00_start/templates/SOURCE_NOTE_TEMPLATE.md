# 材料阅读记录

- **材料ID、标题、作者／机构**：
- **出处与位置**：URL或获授权原文件；页码、章节、图表。
- **发布日期、版本、读取日期**：无法确认的字段留明示缺口。
- **服务的概念／关系／逻辑组**：链接目标。

## 材料的论证

作者的问题 → 前提 → 推理 → 证据 → 结论。按需充分展开，保留解释深度。可少量引用原话并注明页码。

## 如何进入Map

哪些内容补概念定义、哪些补关系逻辑、哪些形成事件或当时预期；链接已写入的位置。

## 分歧、适用边界与后续问题

记录作者论证的条件、相反解释以及需要另查的问题，避免只摘一句结论。

说明原文如何从前提得到结论，摘出必要的中间推理；不要只收集结论与限制。记录实际已读位置、未读部分，以及可用于概念解释或机制论证的具体内容。
