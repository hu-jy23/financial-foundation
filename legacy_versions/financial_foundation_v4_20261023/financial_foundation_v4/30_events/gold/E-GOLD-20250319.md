# 2025年3月FOMC与预测调整

**截至时间**：2025-03-19 14:00 EDT。

**当时状态**：目标区间维持4.25%—4.50%；声明称经济前景不确定性增加。

**谁对什么、哪个期限有何预期**：FOMC参与者对2025年预测中位数：GDP增长1.7%（上次2.1%），PCE通胀2.7%（上次2.5%），年末政策利率3.9%（上次同值）。

**新增证据**：SEP Table 1同时修订增长、物价展望。增长/通胀为Q4同比，利率为年末目标区间中点，不能直接相减成同期限预期实际利率。

**判断变化**：这是政策制定者的条件预测。未取得会前完整市场预期，无法据此量化市场意外。

**后续结果**：2025-06-18声明仍维持4.25%—4.50%。本记录未核对金价事件窗口。
