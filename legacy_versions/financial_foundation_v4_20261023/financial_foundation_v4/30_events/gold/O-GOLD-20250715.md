# 2025年中黄金宏观预期快照

**截至时间**：2025-07-15；报告多数历史数据截至6月30日。

**当时状态**：WGC记录美元计价黄金上半年上涨26%，同时描述利率区间波动。

**谁对什么、哪个期限有何预期**：以6月30日信息为基础，WGC对2025下半年给出三组条件假设：基准情景年末前降息50 bp，金价约+0%至+5%；条件恶化情景降息100—150 bp，金价约+10%至+15%；风险缓和情景利率不变至上升50 bp，金价约−17%至−12%。利率变化参照当时4.25%—4.50%区间，金价幅度按报告正文“下半年相对当前水平”表述保存，图注另说明估值框架采用年度均价，两个口径不自行换算。基准情景还描述十年名义国债收益率持平或略降，未给出同期限实际利率数值路径。这些是机构汇总与模型情景；Bloomberg／Oxford Economics底层调查尚未取得。

**新增证据**：作者把美元、不确定性和投资需求共同纳入解释。

**判断变化**：用于建立有出处的预期快照；其模型结果不构成实际利率单独的因果识别。

**后续结果**：本条未以全年事后涨幅评价该情景。
