# 材料工作区

当前有三组已读公开资料登记：[概念](SOURCES_CONCEPTS.md)、[黄金](SOURCES_GOLD.md)、[国债供给](SOURCES_FISCAL.md)。它们记录出处、阅读位置、论证层次、引用对象及局限。对应的事件／观察在 `30_events/`。

用户目前拥有老师的宏观PPT；该文件尚未读取。教材、课程、研究文章与博客由研究agent主动搜集。先看[资料搜集与阅读方案](ACQUISITION_SHORTLIST.md)：其中区分推荐材料、实际抽读范围与后续精读任务，候选材料尚未自动成为节点／关系的证据。

每份有深度的材料用[阅读笔记模板](../00_start/templates/SOURCE_NOTE_TEMPLATE.md)记录“问题—前提—推理—证据—结论”，再链接到相关逻辑。按机制维护成组阅读入口，并保留不同作者的解释。可按材料数量逐步增加原文、阅读笔记、待研究问题等子目录，无需先建空目录树。

原材料按授权范围保存；本包只提供自己的归纳、少量必要事实与原文链接。来源登记表是材料生态的入口，后续读书与PPT精读应积累更完整的论证笔记。

## v4 的阅读与整合说明

阅读记录须保留解释所需的中间推理，不能只积累结论和警告。此次两篇重写使用既有来源 ID；新增核读位置及范围见[本次 Astra 核读记录](../50_reviews/ASTRA_RUN_NOTES.md)。该记录是实际阅读范围的补充，不表示所有候选材料已读完。来源条目、独立事件与正文允许详略不同，涉及同一事实的口径必须一致。
