# 2025年央行黄金与美元储备预期调查

WGC调查于2025年2月25日至5月20日进行，6月17日发布，共取得73份回复。具体判断数字及其含义见[黄金关系的相关逻辑](../../20_mechanisms/R-GOLD-REALRATES_real_rates_gold.md#logic-3)。调查反映受访群体对储备结构的判断；全球储备判断与本机构储备判断分别保留。

部分题目为自愿回答，各题作答人数有差异，不能一律以73作为分母。调查未联系受制裁央行。未取得个体原始答卷及发布日页面存档；本条按当前可访问的原机构页面重建，不从比例推断全体央行的统一立场。后续实际储备变化尚未在本条核对。
