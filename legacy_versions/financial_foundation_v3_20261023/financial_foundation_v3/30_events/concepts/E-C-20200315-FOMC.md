# 疫情初期的政策利率与通胀预期代理分歧

**截至时间**：2020-03-15 17:00 EDT，FOMC 声明发布后。  
**当时状态**：疫情影响经济及金融条件；声明报告市场通胀补偿下降，但调查长期通胀预期变化不大。  
**谁对什么、哪个期限有何预期**：FOMC 预计将目标区间维持在 0–0.25%，直至确信经济度过冲击并重新迈向就业和物价目标；没有承诺固定日期。市场事前逐期限利率与通胀预期未取得。  
**新增证据**：声明宣布紧急降息，并在同一信息集中区分两类通胀预期代理。  
**判断变化**：本库推断：政策利率、市场通胀补偿和调查预期描述不同对象，仅凭降息不能确定整个实际利率曲线的变化。  
**后续结果**：未采集事件后的 TIPS 报价、调查与流动性序列，未判断实际利率变化幅度。  
**来源**：[S-CV2-06，FOMC 原声明正文第 3–5 段](https://www.federalreserve.gov/newsevents/pressreleases/monetary20200315a.htm)；背景见[概念来源登记](../../40_sources/SOURCES_CONCEPTS.md#S-CV2-06)。

本记录支持[实际利率 C-IR-REAL](../../10_concepts/C-IR-REAL_real_interest_rate.md)的测量辨析。声明中的“市场通胀补偿下降”不能替代“纯通胀预期下降”；也没有提供单一期限的事前实际利率计算所需全部输入。
