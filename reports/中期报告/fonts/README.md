# 英文等宽字体

`sftt1095.pfb`是CM-Super 0.3.4的SFTT1095字体，与英文开题报告中嵌入的等宽字体一致。原文件未修改，供pdfLaTeX直接嵌入，避免依赖系统是否安装完整CM-Super包。

来源：[CTAN字体文件](https://mirrors.ctan.org/fonts/ps-type1/cm-super/pfb/sftt1095.pfb)；[完整上游包与字体源文件](https://ctan.org/pkg/cm-super)。取得日期：2026年11月12日。
