# 首轮测试结果

**agent0（仅prior）100/100；agent1（prior＋graph）100/100。10题全部打平，没有观察到graph带来的内容得分增益。**

本轮题目把新闻的具体主体、时点、市场基线与预测期限抽象掉，主要测了概念机制的条件化说明，未形成面向现实事件的预期任务。题干提示较多进一步造成天花板。即使删去提示，也不能据这组概念题判断graph的事件解释与预期能力。下一轮采用[事件预期测评标准](事件预期测评.md)。

## 怎么做的

从206篇中以种子20261104分层随机抽10篇，每篇选一组重要原因—过程—结果。抽样在查graph覆盖前完成，未替换文章。题目和参考答案在派出答题者前锁定；[材料清单](材料清单.md)可定位原文。

两位答题者均为不继承本次对话的新会话，派遣参数相同：`gpt-6.1-sol`、`high`。agent0只获得题目；agent1额外获得冻结graph，包含165个Concept、75个Mechanism及已有事件和说明。两组均禁止联网和查看原文、答案；agent1只经有访问记录的工具查图。本轮没有设置操作系统级网络或文件沙箱。

独立评审接收每题分别随机排列的A/B答案，去掉引用及资料条件，再按预登记的四个维度评分。没有按引用数量加分。参考的是给定情境下的经济逻辑，允许合理反驳原文或说明净方向无法确定。

## graph带来了什么

- agent1进行了54次工具访问：26次检索、27次读取、1次目录列举，读过25个不同文件，其中包括3份说明文件。工具累计返回约35.8万字符，含JSON格式及重复检索结果。

- 提交的25处引用全部能够在所标行范围定位，并有对应读取记录。这证明出处可追溯；引用存在本身不证明覆盖了该题全部专门机制。

- 答案增加了一些具体展开：Q05给出CPI权重的量纲正确算例；Q06指出延寿主要避免旧供给退出；Q09提醒期限缩短会改变累计操作周转量口径。盲评认为这些细节没有形成主要机制正确性的分差。

- agent0也完整处理了长期合同与融资、炼厂联合产出、单位成本与边际成本、政策提议与生效、黄金数量与估值等问题。这些题可以由模型自身知识和题干充分解决。

## 哪些地方值得继续检查

agent1在8题中声明未找到专门情境条目。其中包含不同性质的情况，不能直接转成8个新增节点：

- **已有机制可以迁移**：Q09的隔夜换锚、Q10的铂金ETF，已有利率操作、贷款传导、实物ETF和可用库存框架可用。缺少具体新事件记录不等于缺少解释机制。
- **需要更专门的关系解释**：Q03的长期采购承诺与项目融资、Q05的炼厂联合产品和开工反馈、Q06的延寿／重启／新建供给路径、Q08的平台访问权与智能体单位经济。可以进一步检验已有页能否承载，尚未据此修改graph。

## 测试本身的问题

1. **任务属性错位。** 题目移除了现实事件的主体、时间与检验窗口，不能考察“谁在何时依据什么信息，对什么标的形成了什么预期，以及后来如何修正”。
2. **题干提示过多。** Q05已给炼厂联合生产和CPI权重；Q08已给增长、访问、成本与变现瓶颈；Q09明确声明没有降息或增量投放。很多题又直接提醒不能作哪种过度推断，容易引导出高分答案。
3. **只做了单次10题。** 单一模型、一个盲评员，本次100分不代表所有答案已经被客观证实。原新闻中的机构分析也未在本轮重新事实核验。
4. **测的是给定事实后的解释。** 事件检索、知识缺口识别、跨页消解矛盾、历史预期更新等能力尚未纳入本轮。图的组织和持续积累价值不能从当前分差直接推出。
5. **检索代价需要单列。** 本轮得分相同，graph组增加了阅读与工具开销。该开销也受本次检索工具和使用策略影响，不能全部归因于正文篇幅。

评审另指出两处参考项口径：Q04按“对应实物数量不变”理解，不额外要求代币发行量不变；Q10不强求题目未要求的追涨反馈。两组均按同一原则给分；原参考答案保持锁定，评审意见另存。

后续以真实事件为单元，保留具体主体、信息截点、市场基线、标的与预测期限；原文机制和后来结果分开管理。使用正向预期、逆向解释、选择题及逐步提供新信息的更新题，检验预期形成与修正。首轮保留为概念解释校准记录。
