# 本轮测试输入

本轮检验制作思想能否迁移到不同文章，以及子概念／子关系何时值得注册。每篇6次独立试作，共12次。正式graph只读，所有输出写到本实验目录。

先读维护目录的ARTICLE_AUTHORING_CHARTER.md，再读本目录SUBSTRUCTURE_DISCUSSION.md与四份测试版说明。随后读正式00_start的README、PROJECT_PLAN、CONVERSATION_MEMORY、BATCH_TASK、FILE_NAMING、对象与机制形成记录和目录、模板；四份测试版替代同名正式说明。查看当前repo及相关正文。纲领控制问题与方法，测试补充控制新增子层级，旧说明提供其余要求；最新用户指示优先。

每次都独立通读指定文章、查看支撑解释的图片、对照相关旧页。不要读取本轮其他agent的输出，也不要把之前AI CDS草案当作答案。允许注册或不注册子层级，必须给出具体理由；不要求凑任何一种成品。

交付一份可读分析与一份供报告整理的JSON：说明文章的问题、选取关键论述并分析、提出组织选择、比较注册与不注册的方案，并写一段能体现自己选择的内容样稿。样稿应展开最有价值的一处解释；无充分依据时保留具名判断或明确假设。JSON只是汇总接口，不是正文模板。不要只复述纲领或交派工方案。

共同证据范围是本地原文、图片和现行graph；本轮不额外抓取资料，不把转引数字写成已外部核实。既有图的来源可帮助理解，但不能声称已回查全部原件。所有运行继承完整上下文；AI案例在前文已有讨论，因此本测试不能视为盲测或独立模型验证。
