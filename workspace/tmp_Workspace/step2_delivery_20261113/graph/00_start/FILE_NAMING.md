# Concept／Mechanism 文件命名

正文采用正式目录的定稿标题：`10_concepts/期限溢价.md`、`20_mechanisms/黄金的机会成本机制.md`。文件名不添加节点ID或英文尾缀。

- YAML中的`id`是稳定标识；`title`与正式目录名称一致。目录、关联节点和逻辑组使用ID识别节点。
- 标题中的Windows禁用字符`/ \ : * ? " < > |`在文件名中替换为对应全角字符，标题本身不改。例如`A/H溢价`对应`A／H溢价.md`。
- 保留标题中的空格；Markdown链接中含空格的路径放入尖括号，程序索引存原始路径。
- 同目录文件名冲突时先核对节点范围，不能覆盖既有文件。
- 改标题时保留ID，同步文件名、全部引用、两份正式目录与JSON索引。

## 索引路径

`catalog_index.json`中的`planned_path`是目标文件名，`path`是正式正文路径，两者以`00_start/`为相对路径基准。制作或维护任务从索引读取路径。

`status: pending`表示尚未完成主审，`complete`表示已有经审阅正文。状态与实际正文一致。
